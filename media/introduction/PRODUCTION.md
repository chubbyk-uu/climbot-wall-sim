## 开场试听稿

如果让一台机器人沿着墙面移动，把沿途拍到的照片，变成一张可以放大查看细节的墙面地图，需要解决哪些问题？

这就是这个项目正在做的事情。从规划覆盖路线，到控制机器人运动，再到自动拍照和图像拼接，把整个墙面巡检流程连接起来。

你现在看到的是仿真环境。机器人需要在重力作用下保持贴墙，沿着规划好的路线扫描。采集完成后，分散的照片会被校正、对齐，最后拼成一张完整的墙面图。

接下来，我们就从一趟巡检任务开始，看看这条流程是怎样工作的。

## 配音制作

- v1 无音轨；用户随后要求加配音，v2 使用在线中文合成，只发送介绍文案。
- v2 全片采用统一中文男声；先验证开场短段，再生成完整旁白。
- 备选在线工具为 edge-tts；它通过 Microsoft Edge 在线语音服务生成音频，
  并非本地模型。发送文案之前确认用户允许在线合成；可用性以实测为准。
- 每段单独合成，保留原始音频、字幕时间与声音配置；逐段调整英文缩写和数字读法。
- 后期统一音量，保留句间停顿；背景音乐暂不添加。
- 工具装入外部数据根中专用 venv，不改变 ROS Python 环境。

## 出片检查

- 每项量化结论关联对应数据组；旧平场证据与新平场演示不混称同一次实验。
- “巡检域内 feature 零漏拍”不能改成“整面墙每个像素全覆盖”。
- 不将仿真验收描述为真实机器人性能，不将简化法向力称作真实吸附机构验证。
- 所有录屏检查用户名、私人路径和无关窗口；术语字幕校对，试听完整音轨。
- 交付 MP4、独立中文字幕、封面与中文发布简介；发布由用户操作。
