# S0：旧结构基线、验收合同与静力交叉检查

日期：2026-10-17。分支：`feature/pressure-suction`。

本批完成旧模型输入冻结、34 工况轮压复测、S0 实验合同与离线静力工具。
**新底盘、三风机负压插件及压力传感器尚未实现，S1 布局尚未完成。**
本批不是新结构吸力设计或真机性能验收。既有控制测试的时钟／清理缺陷已修复，
首次速度超限的直接原因仍单列打开，见下文。

## 2. 冻结的旧模型

数值由渲染后的各 link 质量、位置和惯量合成，包含旋转后的驱动轮惯量与平行轴项。
与计划原先的手算质量／重心一致。

| 参数 | 当前旧模型 |
| --- | ---: |
| 总质量 | 16.5 kg |
| 重心 x／y／离墙高度 | -0.0524242424／0／0.1091515152 m |
| 世界重力／自重 | 9.81 m/s²／161.865 N |
| 恒力 | 世界 -X 方向 400 N，canonical chassis_link 原点 |
| 作用点（base 坐标） | (-0.110, 0, 0.085) m |
| 轮距／轮半径 | 0.430／0.080 m |
| 球轮 x／半径 | -0.330／0.050 m |
| 驱动轮摩擦系数 | 1.1 |
| WheelSlip 横向／纵向柔度、标称载荷 | 0.208／0.069、133.3 N |
| 物理步长／接触传感器频率 | 1 ms／1000 Hz |

历史计划筛查用了 `g=9.807`，本批读取实际世界的 `9.81`。旧算例与旧证据不改写；新增计算
与实验用实际配置，轴向门槛因此有约 0.03% 的差异。
新增工具测试单独以历史 `9.807` 复现原 review 五个轴向算例，防止几何与数值口径混淆。

## 3. A 组轮压实测

每 15° 一个静止航向，共 24 个；每姿态稳定 0.5 s 后测 2 s。另含四方向行走和制动、
正反各一整圈转向：共 34 个工况、102 条逐接触统计。行走 0.15 m/s、5 s，制动 2 s，
转向目标角速度 0.6 rad/s。

| 接触点 | 全批最低法向载荷 | 对应工况 |
| --- | ---: | --- |
| 左驱动轮 | 84.201427 N | 逆时针原地整圈转向 |
| 右驱动轮 | 84.201517 N | 顺时针原地整圈转向 |
| 球轮 | 75.610224 N | 朝下行驶后的制动 |

旧测量器的 `passed=true`、`no_lift_off=true`，球轮相对旧 60 N 门槛的余量为 15.610224 N。
左右驱动轮最低值比 2026-08-24 的记录约高 0.008 N，球轮差异小于 0.000002 N。
这是原有**事件统计口径**下的复现，不证明全部物理步均无丢样。

执行器测量退出码为 0；清理通过，partition 中残留进程为 0，未触发补杀／异常清理说明。
启动仅有旧恒力，不涉及负压就绪、安装支撑撤除或风机动作；这些仍须在 S3/S4 实现验收。

实测文件：[A 组摘要](a_loads_summary.json)、[逐工况 CSV](a_loads.csv)、
[执行与清理记录](run_summary.json)、[输入与渲染摘要](baseline_summary.json)。

## 4. 解析模型与独立实测对照

使用渲染模型合成的重心、实际重力和已冻结的旧作用点／球位，预测 A 组 24 个静止航向的
三个法向反力。没有根据实测调重心或作用点，未使用转向数据拟合静力公式。

| 对照量 | 结果 |
| --- | ---: |
| 比较数量 | 72 个工况／接触点均值 |
| 法向力 RMSE | 0.614007 N |
| 最大绝对误差 | 0.985230 N |

计算仍采用目标航向，而旧摘要未保存实际稳定姿态，转向到位容差为 1°；因此不把约 1 N 的
差异全部归因于接触求解误差，也不能依靠本对照确认瞬态行为。工具另以独立 Newton/Euler
力与力矩平衡、旋转／合成惯量和原 review 算例校验符号与解法。

## 5. 逐轮摩擦圆的全静态航向诊断

以下全部沿用**旧 16.5 kg、旧重心、旧 0.43 m 轮距**，只改变压力中心和球位。
按 S0 首版 `S=1.5`、`μ=1.1`、球轮至少 10 N；没有裙边、动态或新质量。
1° 全周扫描，并在极值附近细化到 0.1°；没有声称解析求得连续航向的精确全局极值。

侧向时计入重心偏离驱动轴产生的静态偏航力矩，左右轮差动纵向力约 ±19.734 N。
驱动轮横向分配不可由刚体静力唯一确定，因此分别报告：

- 摩擦圆可行域下限：存在某种横向分配可行，并不表示实际轮胎必然采用它；
- 首版按轮压比例分配：以各轮完整切向需求核查裕量，需要 S3 独立测量验证。

| 情景 | 压力中心 x／球位 x（m） | 仅轴向 S=1.5（N） | 全静态可行域下限（N） | 全静态按轮压比分配（N） | 一侧最不利航向 |
| --- | --- | ---: | ---: | ---: | ---: |
| 仓库旧结构 | -0.110／-0.330 | 411.4 | 459.2 | 492.2 | 51.0° |
| 旧压力中心＋圈内候选 | -0.110／-0.240 | 543.4 | 598.6 | 635.2 | 53.6° |
| CAD 中心＋图纸外伸球位 | -0.141／-0.410 | 402.1 | 452.4 | 487.9 | 49.6° |
| CAD 中心＋圈内候选 | -0.141／-0.240 | 713.6 | 786.0 | 834.1 | 53.6° |
| CAD 中心＋后移参照 | -0.141／-0.310 | 509.4 | 567.2 | 606.9 | 51.5° |

有镜像等价的不利航向；表中只列扫描首先取得的一侧极值。
在旧质量下，`-0.240 m` 候选并不因轴向算例恰好通过就具备全航向裕量；`-0.310 m`
也尚未核对圈内球座／布卷三维净空。表格不冻结球位，不直接选择风机。
`400 N` 在新候选上的失败是诊断结果，不调整摩擦系数来使它通过。

计算证据：[严格 JSON](static_screening/screening_summary.json)、
[全部航向与细化样本](static_screening/headings.csv)。正式新结构需在 S1 加入新质量／惯量、
真实压力轮廓、CAD 不确定度、裙边压差／机械反力和运动包络后重新求解。

## 6. 软件回归与仍打开的问题

初次完整 `-j8` 基线共 1391 tests，0 errors、3 failures、67 skipped；其中是两个不同断言
加外层 CTest 失败计数，不能解释成三个独立物理缺陷。确切断言与节点记录已保存为
[首次失败摘录](regression_initial_failure.txt)，日志源摘要见 [回归审计](regression_summary.json)。

1. `test_capture_heartbeat_does_not_modulate_scan_speed` 得到最大速度
   `0.21046448658564493 m/s > 0.205 m/s`。单独执行及随后完整并行执行通过，首项根因仍未定位；
   未降低并发、放宽速度门限或改控制器，也未将其归为“时间噪声”。
2. 上述断言发生在取消动作之前，失败后 fixture 析构没有等待取消活动 Goal。下一测试被节点
   以 `another task is active` 拒绝，源码与同一日志证实这条连带关系。
3. 在补入独立历史交叉检查后的完整 `-j8` 中再次失败：1434 tests、0 errors、2 failures、
   67 skipped。这次是巡航样本为零及外层 CTest 计数；目标刚接受便因里程计无效退出。
   共用的 tracker 没有重启，但每个测试客户端都从零发布 `/clock`，旧里程计与新时钟代次
   交错；初始五次发布还没有保证 DDS 已匹配。

新增离线分析测试覆盖三接触的独立力／力矩平衡、惯量坐标变换、静态偏航、摩擦圆分配差异、
400 N 失败诊断、无效几何与独立历史实测等，共 42 项工具测试，已经接入 `colcon test`。

提交 `c09e6be` 修复测试夹具的时钟代次、真实订阅匹配和异常清理，统一整数纳秒拆分。
新增两个确定性节点回归：实际销毁／重建客户端验证时钟延续；故意抛出巡航断言并验证 Goal
已取消。取消终态由真实 Action 服务器返回，没有伪造 result。控制器与运动阈值均未改。
对应确认案例见 [INCIDENTS #17](../../docs/INCIDENTS.md#17-复用节点却重置测试时钟失败断言还会留下活跃任务)。

回退时钟继承的负对照确定失败（`0.0 != 0.02`）；把异常取消恢复为顺序执行的负对照也失败，
修复后的真实节点用例通过。负对照的非零退出是预期结果，不计作产品套件失败。

时钟修复后并行检查第一轮通过、第二轮又暴露强制恢复测试的初始 Start 拒绝：管理器内部
Action 客户端的 discovery 不能由测试自己的 `wait_for_server()` 代替。提交 `3429e17`
先验证服务器不存在时的拒绝，再仅对“尚未发送 Goal”的 discovery 拒绝作有期限等待；
其他拒绝不重试，原有 SIGKILL／强制恢复验证保留。确认案例见
[INCIDENTS #18](../../docs/INCIDENTS.md#18-测试客户端发现-action-server不代表管理器内部也已发现)。

最终在 `3429e17` 的干净 `src/`／`tools/` 上，保持 `--executor parallel --parallel-workers 8`，
**连续 8 轮均为 1436 tests、0 errors、0 failures、67 skipped**。完整 stdout/stderr 分轮留在
`/tmp/climbot_suction_s0_stress_ready_20261017_<1–8>.log`，正式 JSON 记录每份日志哈希。
当前产品物理／控制源码相对 `c2acf17` 没有变化，`src/` 的差异只有测试注册和两个夹具；
本轮不运行新负压模式、控制八工况或图像全链路，不把软件套件通过外推为新模型验收。

不把连续通过当作该观测的因果解释。较早的回归审计 JSON 是修复前快照，当前状态以本节
及[最终验证摘要](regression_validation_summary.json)为准，不改写原始失败记录。

## 7. 阶段边界与下一步

S0 的输入冻结、旧轮压基线与实验规则已有可复查产物；新吸附验收 V-01～V-08 仍未通过。
下一步 S1 需先给出新底盘／腔体、圈内球座和密封圈的可制造几何假设，重新计算相机长支架、
质量／惯量和整机包络，再扫描压力中心、球位及尺寸不确定度。新结构各轮载荷合格后才进入
风机／裙边选型和 S2 核心实现。暂定值须保留敏感性范围，不拿本批旧质量算例代替新结构。

供电线缆的自重与拉力、真机材料参数及风机曲线均未实测，不在本批结论内。
