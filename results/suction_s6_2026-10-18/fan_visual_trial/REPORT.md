# Gazebo 风扇旋转显示试验

2026-10-18。用户要求尝试在吸附时看见风扇旋转；持续 Goal 保持暂停，本记录只验显示组件。

五秒实际 Gazebo 窗口录像（本地附件：`results/suction_s6_2026-10-18/fan_visual_trial/fans_running.mp4`）。预览为私有 Mesa、原 DDS 墙面、Gazebo GUI 与
RViz 同开。三个风扇叶片在护圈内独立旋转；显示转速在归一化速度 1 时为 0.6 转／秒，刻意
放慢以免帧率混叠得像静止或倒转。现有风机模型只有归一化速度，没有实测 RPM，本显示值
不能当作风机性能数据。

实现订阅既有 `/suction/ground_truth/state` 的 `fan_speed_0/1/2`，按消息的仿真时间
积分显示角；停机跟随模型的一阶减速，暂停没有新的仿真时间就不转，reset／generation
变化清零。只在 GUI 的 PreRender 渲染线程修改三处叶片 visual 的局部旋转。没有增加刚体、
关节、力矩或发布轮子 TF，不修改相机传感器渲染和 RViz。只对候选负压入口加载，旧结构与
无风机状态的 B0 不加载此插件。

[状态与画面核查](summary.json)：固定相机，对三处叶片圆环区域比较录像第 8、13、19 帧，
差值超过 15 DN 记为变化；此像素统计是本次人工近景核查的辅助，不作为产品质量门限。

| 操作 | 实际状态及画面 |
| --- | --- |
| 三台运行 | 三个区域均有明显变化；归一化速度均约 1 |
| 关闭 fan_0 | 1.2 s 后速度约 6.3e-5；右侧对应区域变化像素为 0，另外两处仍旋转 |
| 恢复 fan_0 | 速度恢复约 0.99994，三个区域均重新变化 |
| 暂停仿真 | 仿真时间停在 83.43 s；三个叶片区域均零变化 |
| 恢复现场 | 已取消暂停，三台风机均恢复 enabled，保留近景预览 |

停止一台也确实改变现有物理模型腔压：记录从约 8404 Pa 降至 4177 Pa，再恢复至 8404 Pa。
该短时静态演示没有临时支撑，没有 runtime_failed；它不证明停机后的运动安全，也不是新的
风机故障验收结论。三台运行时另做 35 s 原生时钟观察，排除首 20 s 后平均 RTF
`1.0000000142`，时钟、无暂停及 1 ms 物理步检查均通过。该窗口是短静态诊断，不能代替
S6 双 GUI 正常运动／完整拍照任务的平均 RTF ≥ 0.95。

SDF／URDF 去除 visual 后与 `1bb48c1` 的实际预览资产完全相同。物理质量与惯量未改变，
上阶段待办仍按原顺序执行。构建／完整 -j8 的记录见 [checks.json](checks.json)；第一次检查
发现 import 排序与 C++ 缩进两处格式问题，修正后复验，不隐藏首次失败。完整日志在 `/tmp`。
