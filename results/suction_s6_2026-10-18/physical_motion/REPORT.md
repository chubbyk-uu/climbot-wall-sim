# 新提手质量下的原生运动与故障复验

2026-10-18。S6 前置复验，源提交 `413cd89`；15.518481 kg 暂定机械预算，平墙、刚性轮。
本批不改写旧质量的 S5 历史结果，不调整风机、裙边、控制或验收阈值。

| 范围 | 组数 | 结果 |
| --- | ---: | --- |
| 三种运动 × 八初始航向 × 同插件 B/C | 48 | 正常运动全部通过逐轮载荷／摩擦裕量等检查 |
| 停机数 × 独立漏口 × 倒灌参数的受约束压力台架 | 36 | 流量平衡、独立压力参考、恢复和单调性检查通过 |
| 自由机器人停机／漏口脉冲 | 5 | 如实记录失去逐轮裕量、接触与恢复边界，不要求故障时仍能保持 |
| 1 ms／0.5 ms 压力与风机响应收敛 | 2 | 原数值收敛门槛通过 |
| 合计 | 91 | 698 项主检查、139 项独立原始数据审计全部通过 |

正常运动最不利点为 `mixed_270_fan_ode`，实测单轮摩擦裕量最低 **1.58645997 ≥ 1.5**。
该组压差最低约 8404.442 Pa；这是冻结曲线／正常受控漏口下的验证点，不宣称已经搜索出
新质量下的全局最低可行压差。旧质量的 7.50 kPa 经验下限不能直接移用。完整逐组量见
summary.json（本地附件：`results/suction_s6_2026-10-18/physical_motion/summary.json`）、[独立审计](independent_audit.json)和
运动／故障边界图（本地附件：`results/suction_s6_2026-10-18/physical_motion/motion_and_failure_boundary.png`）；图已打开核对。

自由故障中，关闭一台 1 s、关闭两台 0.15 s 分别在仿真时间约 3.276／3.084 s 开始不满足
某项逐轮载荷／裕量要求，随后恢复腔压；这不等同于全程保持安全裕量。
三台全停 20 ms 的本组试验没有触发该违例；三台全停 1 s 约在 3.056 s 开始违例，
失去接触后，重新启用三机仍只有约 30.39 Pa，未重新密封。没有再次启用启动支撑或恒力。
台架三机全停的压差归零只是压力子模型结论，不能证明自由机器人能够保持。

本批自由工况没有触发运行域异常；它不否定先前 GUI 演示中发生的压缩超限，两者机械
碰撞代理和初始状态不同。异常可观测性用独立的显式域退出红绿试验验证，不能以某次翻倒
恰好不触发异常代替该回归。完整翻转／撞地吸附物理仍不在有效结论内。

原始逐步压力、接触及逆动力学共 230 个压缩文件、806931559 字节，已按原字节归档至数据根，
登记于 统一索引（本地附件：`results/suction_s6_2026-10-18/data_artifact_index.json`）；工作输入保留至完整 S6 通过后再清理。
可用 `python3 results/suction_s6_2026-10-18/replay/restore_pressure_records.py --restore` 恢复／校验。
完整诊断日志在 `/tmp/climbot_s6_physical_motion_r2_20261018.log` 与
`/tmp/climbot_s6_physical_motion_r2_audit_20261018.log`。

复现入口：先以本提交源码构建，然后在新的输出目录执行
`python3 tools/validate_vacuum_motion.py --output NEW_DIRECTORY --stage all`，再执行
`python3 tools/audit_vacuum_motion.py NEW_DIRECTORY`。须 source ROS 工作区并启用本地私有 Mesa；
每组实际映射已记录。S0 旧输入除了用户要求的两份精确 GUI 源版本外保持字节一致，
获准差异的旧／新哈希和世界 XML 的非 GUI 等同性另有记录。

该批是无 GUI 的原生物理复验，**不作为双 GUI 实时率或完整 S6 通过证据**；后续仍有
用户批准的九组 GUI 控制、受影响的传感／侧滑及实际采集和 CUDA 拼接链。
