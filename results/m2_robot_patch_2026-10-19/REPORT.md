# M2 整车起伏接触：三角网降速的定位

2026-10-19。前一阶段球轮滚动／T1 已提交为 `1079039`，未推送。
本阶段接入 1.2×1.2 m 代表区域、同源裙边间隙及球轮代理面。
先定位明显降速，随后按明确的驱动轮跨缝近似通过一次整车短试验；未扩整墙或重跑 S6。

## 结论

**本次明显降速的主要原因已定位到驱动轮与起伏三角网的接触表示。**
同一柔性轮、同一密封圈模型、同一固定压差和动作，去掉板缝后只更换驱动轮接触表示，
行程从 0.120458 m 恢复到 0.609097 m。球轮始终使用同一代理网格，没有随此对照改表示。
这不是柔性轮单独导致，也不是通过减小裙边摩擦或提高吸力解决的。

以下为真实原生 Gazebo 结果，步长 1 ms、9 s 模拟，动作均按撤除支撑后的时间对齐：

| 工况 | 实际行程 | 状态 |
| --- | ---: | --- |
| 真实板缝三角网＋刚性轮 | 0.389246 m | 驱动轮过缝，球轮未到横缝，未通过 |
| 同源板缝三角网＋柔性轮 | 0.143065 m | 未完成越缝，未通过 |
| 仅起伏三角网＋柔性轮 | 0.120458 m | 没有板缝仍明显降速 |
| 同源起伏原生高度场＋柔性轮 | **0.609097 m** | 运动诊断门槛通过；**本工况没有物理板缝** |

最后两组使用相同 ±2 mm 上限、200–800 mm 模态范围、种子 20261019 的连续源场，
同一源码、球轮代理、轮胎参数、裙边、三风机定义、固定压差 8404.442641 Pa、运动指令与步长。
板面三角网间距 10 mm；高度场 257²／16 位，按既有 N/(N−1) 合同补偿范围，
高度偏置放在模型位姿，不依赖已知失效的 heightmap/pos。
不同碰撞表示采用各自采样与量化，不声称离散网格逐点相同。

## 排除误导线索

按各自撤除支撑后 2.2–4.2 s 的稳态指令段比较：

| 测量 | 仅起伏三角网 | 原生高度场 |
| --- | ---: | ---: |
| 左／右轮实测转速 | 4.210526／4.210526 rad/s | 4.210526／4.210526 rad/s |
| 对应指令轮缘速度 | 0.2 m/s | 0.2 m/s |
| 车体平均向上速度 | 0.033010 m/s | 0.168695 m/s |
| 左／右平均接触点数 | 10.45／10.02 | 1.09／1.38 |
| 左／右平均轮压 | 231.55／228.73 N | 222.24／237.90 N |
| 球轮平均轮压 | 497.96 N | 498.50 N |
| 裙边平均法向反力 | 145.17 N | 144.80 N |
| 裙边平均向上运动阻力 | 3.63 N | 14.47 N |
| 球轮平均向上运动阻力 | 0.66 N | 6.08 N |

轮子确实按指令旋转；密封圈法向反力基本一致，恢复运动后裙边和球轮的阻力反而更大。
所以不需要靠调低这些阻力、改变弹簧参数或调高风机曲线来解释运动恢复。
三角网多接触约束伴随明显数值性滑移，与本机私有参考 4W 的
`docs/issues/ROUGH_ROAD_RUNTIME.md` 已记录问题一致。
**这里确认到接触表示层面，不冒充已经定位 ODE 内部具体源码行或证明仅由接触点数量决定。**

## 实现和过程

- `build_assets(..., surface_patch=...)` 仅接受显式代理球和 fixed_pressure B 模式。
  新增网格／高度场控制属于诊断入口，不是已部署的整墙或默认采集选项。
- 原三角网诊断中驱动轮／车体／止挡碰真实源面，球轮碰 r−ρ 外扩面，使用非零 1／2 掩码；旧平面碰撞被移除。
  视觉使用真实源网格，代理面没有视觉。未开启纹理、相机或 GUI，不产生拍照／RTF 结论。
- C++ 插件加载同源模态和沟槽，查询实际局部间隙及间隙变化率；公式仍只有 C++ 一份。
  SDF 字符串规范化会破坏多行 YAML，改用同内容的一行 JSON／YAML flow 文档，已补回归。
- 离线源采样补入验证点，避免将球帽采样误差误判为网格误差；起伏令代理谷线轻微偏移，
  只在谷底 0.4 mm 窄带用 0.025 mm 采样，其余槽内 0.1 mm、板面 10 mm。
  真实网格 17205 顶点，球轮代理 34225 顶点，面重心相对采样外扩源误差约 0.00635 mm。
  该数值只描述离线采样表示，不是连续源球轮轨迹的整体验收。
- 原生观察器补实测轮速和轮心位姿。PostUpdate 的命令组件可能已由 DiffDrive 更新为零，
  判别执行效果依据物理关节实测转速，不能据该后相位组件误判没有下发命令。

所有正式运行核对实际私有 hashfix ODE 库映射，私有 Mesa 环境与前阶段一致。
本轮只做 4 个 9 s 场景及一个复用软轮场景的 4 s 转速诊断，未展开矩阵或长采集。
初始化前的几何／串行化失败不列为有效物理结果；已清理其可重建中间场景。

## 驱动轮跨缝近似：一次 9 s 整车结果

`--soft --native-heightmap`，不加 `--smooth-control`。源面包含完整的十字板缝，
开口 5 mm、深度 3–5 mm 缓变、起伏上限 ±2 mm；高度场独立取同源 `roughness()`。
球轮碰完整源的代理网格，裙边插件与视觉保留完整槽形；全平坦起伏则用顶面等高的箱体替代零高差高度场。

| 指标 | 结果 |
| --- | ---: |
| 模拟时长／步长 | 9 s／1 ms |
| 解除支撑时刻 | 0.957 s |
| 行程 | 0.613485 m（冻结门槛 0.45–0.70 m） |
| 三轮跨过源缝位 | 左／右／球轮全部通过 |
| 最长失触 | 各 1 步（门槛≤2步） |
| 止挡接触、启动／运行故障 | 均无 |
| 左／右／球轮法向峰值 | 263.14／285.63／1028.60 N |
| 固定压差 | 8404.44 Pa，未重调 |
| 插件每步耗时均值 | 52.70 μs（不是整机实时率） |
| 本地几何生成耗时 | 1.72 s |

三轮轨迹均越过源面横缝坐标；驱动轮使用跨缝近似，**不代表驱动轮碰过真实凹槽几何**。
球轮仍碰真实槽形代理网格。三轮均曾出现单步 0 N，球轮峰值约1029 N；
当前门槛只检查运动、接触连续性和故障状态，逐轮载荷／冲量留到 T2，不据此宣称稳定载荷已通过。

近似适用于宽度≤5 mm、无板间台阶的板缝：R47.5 mm 驱动轮理想省略下沉
0.06584 mm（正交）／0.13176 mm（十字对角），顺缝时47 mm轮宽可跨越。
这些数值不是任意动态姿态的误差保证。车体／2 mm止挡也碰跨缝面，止挡误差不能用轮子下沉界约束；
本次正常运行止挡反力为0，压到底且止挡落缝的故障近似仍需声明。
此前0.1 mm离散下沉是特定台架的单步结果，不能视为1 ms仿真的通用精度下限。

相关生成器／表面测试72项通过，覆盖完整源与仅起伏PNG分工、掩码、SDF序列化及全平面退路；
Python样式检查通过。只执行上述一次9 s模拟，没有重复矩阵；无需为仅格式调整重跑。
