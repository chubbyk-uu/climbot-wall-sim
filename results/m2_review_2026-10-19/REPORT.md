## ODE 配置与 M1 对照

原 T0 的 no-libccd 上游／补丁 A/B 仅证明哈希修复的因果，不能当作发行版等价证据。
本轮核对 Ubuntu `2:0.16.2-1.1build1` 的 `debian/rules` 与上游 Autoconf 分派：双精度、
系统 libccd、共享库、内部断言及具体 CCD 开关对齐，SONAME 为 `libode.so.8`。
发行版 `--enable-libccd` **不包含 box-cylinder**，CMake 必须显式关闭该项。

首次打开所有 CCD 开关的私有库，在 straight_270 出现驱动轮短暂失载，判为失败；
对齐 box-cylinder 后才重做正式对照。上游 CMake 的目标名大小写、custom 头文件路径、
Ubuntu ccd 导出目标名三个构建错误在配方中显式处理，未因此修改碰撞算法。
构建记录见 [build_profile.json](build_profile.json)，含源包、补丁、库和发行版打包文件哈希。

[三组 M1 对照](ode_comparison.json)：straight_270、turn_000、mixed_270，各跑系统库和
私有库，包含起步静止。三组原逐轮安全检查通过，最小三轮法向载荷、最低压差及最低摩擦裕量
的系统／私有差异均为 **0**。每进程记录实际 ODE/libccd 映射；这不证明所有碰撞组合等价。
M1 默认仍使用系统库，私有库仅由 M2 显式选择；T3 前再决定最终部署范围。未对外提交上游 issue/PR。

原对照运行在提交前的工作区；不把它冒称为干净提交上的运行。摘要保留原源提交、
`run_source_dirty: true`、探针二进制哈希、六组生成输入哈希和后续可复现源码检查点。
此前五份 T0 报告保留原始配置／失败结论，源码、补丁、探针与报告现已分别提交。

## 裙边压到底

将“超过最大压缩就锁死插件”改为：弹性项在最大压缩处饱和，四段无摩擦原生刚性止挡
由求解器承担额外载荷；不加高刚度显式弹簧，不把原生反力再次施加到车体。
`skirt_stop_previous_normal_n` 是上一物理求解的接触反力，和插件本步裙边施力分列。
止挡只有碰撞代理，不增加质量或视觉部件；正常预压下不接触，不封堵沟槽。
负安装间隙、倾角超出支持域、非有限值及求解错误仍显式失败，不作无依据外推。

隔离台架关闭三轮碰撞，以明确标记的 bench 支撑抵消重力，验证原生止挡承载；
不是自由整车运动验收。完整结果见 [seal_stop_summary.json](seal_stop_summary.json)。

| 步长 | 稳态最低压差 | 最低止挡反力 | 最小安装间隙 | 运行失败 |
| --- | ---: | ---: | ---: | --- |
| 1 ms | 8403.674 Pa | 1010.901 N | 11.999982 mm | 无 |
| 0.5 ms | 8403.671 Pa | 1010.901 N | 11.999996 mm | 无 |

两者压力与反力收敛，压到底后压力持续更新。原有暂停、reset、域退出故障可观测性回归仍通过。
早期 GUI 三机全停演示触发过压缩超限；S6 正式运动复验没有运行域异常，其失去接触后无法
自动重密封的记录独立成立，见[原报告](../suction_s6_2026-10-18/physical_motion/REPORT.md)。
T2 尚需把新表面、柔顺轮、止挡接触的载荷／力矩账本在同一步观测下联调，本轮不宣称完成。

## 唯一表面实现与诊断高度场

高度／粗糙度／沟槽公式集中在 `wall_surface_core` C++ 库，Python pybind 批量调用。
保留既有 NumPy 种子实现用于离线生成八个模态，`resolved_yaml` 序列化实现后的参数，
C++ 直接读这些参数，不重复抽随机数。几何探针将解析参数与原配置一起保存。
运行查询不解析 YAML、不读文件、不分配工作对象；不提供 Python 几何公式回退。

独立 C++ 梯形槽坐标／法向基准与迁移前冻结的 102 点参考共同通过，覆盖起伏、裂缝、
圆角与倒角；另测数组广播和重载解析参数。128 点 Python 批查询平均约 **9.36 μs**，
见 [surface_query_benchmark.json](surface_query_benchmark.json)。这不是实际整车插件耗时或双 GUI RTF 证据。

旧诊断高度场的 6～8 mm 重复支撑带已修正：采用与粗／细网格均对齐的 25 mm 条带，
仅将严格内部下沉；各片共用量化区间，交界节点一致。契约测试检查旧重叠带已在顶面以下、
条带／交汇块边界编码完全相同。采样总量不增加；但该高度场仍未通过球轮动态接触，
不作为默认部署或已验收退路，也不重用历史 16 mm 条带的性能结论。

## 漏气边界、需求来源和旧模型

冻结现有风机曲线。按原刚性平墙的 6100 Pa 筛查线，支持的最大等效漏口约 **301.686 mm²**。
保守地在原 180 mm² 正常受控漏口之外增加连通板缝截面：5 mm 开口／4 mm 槽底、3～5 mm 深，
单处 13.5～22.5 mm²，四处最深组合共 90 mm²。总 270 mm² 时稳态约 **6617.423 Pa**，
额外剩余约 **31.686 mm²**。详见[预算](leak_budget.json)及 `tools/check_m2_leak_budget.py`。

这是未覆盖通道的几何预算，不是裙边贴合模型或真机测量；共用开口不重复计数，
±2 mm 起伏可贴合时不凭空增加漏口。裂缝、真实贴合失效、动态和软轮新载荷由 T2 另验，
不足时报告边界，不逐工况重调风机或压低泄漏。

[干净输入重算](physical_model/summary.json)来自干净提交 `752e1a1`，`source_dirty: false`，
149 种瞬时状态组合、59898 个采样状态，质量 15.518481 kg；名义解析结果与历史计算逐项一致：
6100 Pa／800.8873 N。配置中的 `requirement_source` 已改为此摘要，旧脏输入报告仍保留历史身份。
最不利名义状态为航向 41.6°、v=0、a=0.7 m/s²、ω=-1.2 rad/s、α=0，属于保守执行器能力
包络，不是规划器实际运动曲线。重算仍是 M1 刚性平墙参考，不能代替 M2 耦合需求。

退休的 `model.sdf.xacro`、`climbot.urdf.xacro` 按原字节移至 `tools/testdata/legacy_contract/*.txt`，
不再作为运行模型安装。旧输入核对仍比较冻结字节；仅 simulation YAML 注释／格式变化允许
在完整解析配置不变时通过。已修正底盘配置标题与 WheelSlip 历史参考注释，标定数值未改变。
