# 负压、裙边与逐轮载荷模型

M1 平墙模型的方程与建模边界；起伏墙和柔顺轮的现行实现见 [M2 模型](../m2/MODEL.md)。

## 4. 等效物理模型

### 4.1 三风机与单腔压力

三个风机在相同腔压下分别计算流量并相加。固定档位表示固定目标转速；实际抽气流量仍随压差
变化。每个风机保留独立启停状态和转速响应，不能直接分配三个固定吸力。相同风机并联不会
叠加零流量最高压差；密封良好时少一台对压差影响可能很小，停转影响须与漏气及倒灌通道一起评估。

首版设计路线是**准静态工作点＋风机转速的一阶响应**：每步以当前几何、漏气和风机转速求
质量流量平衡，记录残差、工作分支与求解容差。曲线须给出合法区间和稳定分支；无根、根不唯一
或越界时明确处理，不能任取工作点或改回恒力。

同时保留等温容积 ODE 作为独立动态参考或显式可选模式。以腔内绝对压力 `p_c`、外界压力
`p_a` 和有效容积 `V` 表示：

```text
Δp = p_a - p_c
准静态：Σ进入腔体的质量流量 = Σ离开腔体的质量流量
容积 ODE：d(p_c V)/dt = R T (Σ进入腔体的质量流量 - Σ离开腔体的质量流量)
平面合力：F_pressure = Δp × A_effective
```

S2 从容积与工作点附近的流量斜率估算压力时间常数，和风机启停、轮胎运动及漏气变化的时间尺度
比较；“约 2 ms”目前只是 review 估算，不作为已测参数。若快速开口／接触事件不满足时间尺度
分离，使用受控子步、解析或隐式 ODE 并记录实际模式，不以准静态跳变冒称真实压力响应。

风机曲线、漏气通道与容积变化使用一致的质量流量定义，体积流量换算时注明对应压力和密度。
裙边间隙、局部开口、残余漏气以及停转风机通道共同决定进出气量。停转通道是否有止回能力目前
未知，默认不得假定关闭后仍完全密封；对其等效通流面积做敏感性验证。

孔口的有符号平方根在零压差附近需有限导数正则化，例如
`f(Δp)=Δp/(Δp²+ε_p²)^(1/4)`；`ε_p` 单位为 Pa，公开其取值、目标工作区间误差和敏感性结果。
不能用任意截断把零点变成不明来源的漏气阈值。

全部风机停转且理想零漏气时，准静态平衡没有唯一解；应按显式配置保留封闭腔的气体状态或
拒绝该组合，不能直接强制恢复环境压力。动态参考须保证绝对压力为正，并允许压缩腔体时向外
排气；不得靠大幅裁剪压力掩盖数值不稳定。
机器人离开墙面或裙边越过墙边后，应由真实开口导致失压，避免保留远距离吸引。

### 4.2 密封圈接触、摩擦与漏气

首版用周圈采样点上的弹簧和阻尼近似裙边压缩，在 Gazebo System 中计算等效接触力，避免一开始
引入大量小刚体和关节。先用实际间隙、自由形状、压缩行程和贴合能力求接触状态，再求压缩反力。
模型假设 H1：按用户定性经验，轻微起伏在暂定可贴合范围内只改变压缩分布与轮载，
不因高度变化本身额外增加漏气。贴合幅值／空间尺度／速度的阈值尚无实测数据，全部标为
provisional；H1 用于 M2 建模，不以同一规则产生的“基础漏气不变”作为实机有效性证据。

贴合接触时，裙边法向载荷除机械项外还需考虑唇口压差项，可采用等效表达：

```text
N_skirt = [k δ + d δ_dot + β(contact_state) Δp A_lip]_+
A_effective = ∫ pressure_weight(s) dA_projected
```

`A_lip` 为唇口环带投影面积；接触带内的压力从腔压向外界过渡，位置权重决定有效面积和压力
中心。有效边界位置与 `β` 均为 provisional，但必须来自同一份受压面／传力模型，不能独立任取
后把同一唇口载荷扣两次。只在实际接触部分传递墙面反力；离墙后按开口状态计算，不保留虚假
接触支撑。用分区合力与力矩核算检查整体平衡。

漏气依据是裙边实际无法贴合后留下的残余开口，以及是否存在贯穿接触带、连接腔内外的通道。
分别记录沟槽深度、宽度、方向和裙边跟随／跨越能力；孤立凹点不自动等于贯通漏口。残余基础
漏气与缺口漏气分开。轻微起伏与深沟槽分别试验，不能用起伏 RMS 或任一采样点离开参考平面
直接放大漏气面积。

M2 柔性随形、非零漏气下稳定吸附的目标与验证见 [独立计划第 4 节](../m2/MODEL.md#裙边压力与耦合)。


从可贴合到不可贴合的过渡必须连续：在暂定过渡带内平滑计算残余间隙、有效通道面积和
唇口载荷权重，不能在幅值阈值处从基础漏气直接跳到整段开口。过渡带宽度及正则化参数均有
单位、来源和敏感性范围，不用平滑掩盖深沟槽的实际通流截面。M1 先用受控间隙缓慢开合验证
这套子模型；M2 再用真实表面／贴合状态驱动它。独立做阈值两侧的双向细步扫描和缓慢升降，
检查面积、流量、负压及裙边力在唯一稳定工作分支内连续；缩小扫描步幅、物理步长并加密周圈
采样，核对收敛及有无数值分支往返切换。真实动力学滞后与数值抖动分别解释，容差在试验前冻结。

切向摩擦由该处接触载荷和滑动速度计算；用有界、连续的近零速度处理，避免静止抖动或向运动
方向注入能量。支撑的抗内卷作用以受限的裙边形状与行程近似，外观压缩与物理压缩使用同一状态。
压缩到底后需明确处理硬限位，不能让底板穿墙。正则化摩擦在静止附近可能蠕变，静态牵引预算
不依赖它提供保持力；运动时需计入随裙边法向载荷变化的拖曳。

裙边接触选择一条施力路径：若采用插件等效接触，该圈不能再通过另一套碰撞产生同一份反力。
驱动轮、内置万向球轮和硬壳仍由 Gazebo 接触求解。球轮在圈内不代表它形成独立压力区或必然
漏气；按实际结构扣除占据的腔体容积，只有真实连通外界的安装通道才计入漏气。现有墙缝主要
是视觉纹理；真实沟槽漏气测试见 [M2 计划](../SUCTION_M2_PLAN.md)，采用同源、具有明确截面的开口／凹槽或密封通道模型，不能从
纹理明暗推导物理间隙。M1 采用声明面积的受控密封通道，M2 才验实际沟槽及起伏随形。

### 4.3 合力、力矩与轮子载荷

压力作用由实际受压面及第 4.2 节的压力权重积分得到合力与加权压力中心，转换至世界坐标后
施加相应合力与力矩；仅在压力分布对称等条件下压力中心才与几何中心重合。新模型不能永久
固定沿世界 `-X` 施力，也不能把压力作用点直接设为某个风机位置。
插件采用 `Link::AddWorldWrench` 带 `_offset` 的重载：力／力矩用世界坐标，作用位置用 link
坐标。三参数版本作用于 link 原点；使用 offset 后不能再次叠加同一份 `r×F`。显式扭矩仅用于
尚未由偏置力表达的纯力偶。B/C 使用同一套施力函数及压力中心。

单腔第一版压力均匀；某一边漏气首先改变整腔压力，不凭空制造三个局部负压区。倾斜／剥离行为
由受压面方向、裙边接触力、重力和轮系接触共同产生。

静态垂直墙面下应满足法向平衡：

```text
N_左驱动轮 + N_右驱动轮 + N_内置球轮 + N_裙边 ≈ F_pressure 的墙面法向分量
```

总吸力应以[逐轮逆动力学](../SUCTION_S1_METHOD.md)需求反算。需测量各接触点的法向载荷、整机力矩平衡及侧滑，
核对现有 WheelSlip 标称载荷与新载荷范围的适用性。若重新表述标称载荷，应同步检查柔度与
标称载荷的比值，避免无意中改变轮胎等效特性；旧标定不直接冒充新结构标定。裙边和球轮承担
的载荷必须进入计算，不能用未说明的额外推力补回。
