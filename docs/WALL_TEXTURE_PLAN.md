## 1. 目标与范围

优化墙面贴图烘焙：增加裁块的随机旋转、镜像和局部复用限制，减少邻近不同墙面位置复制同一
纹理的情况，并用实际相机及拼接链路验证。在现有平墙上独立交付。P2-06 的拼接门限在现有贴图上
推导和检验；采用新资产的采集／拼接另留证据，不能沿用旧贴图的通过结论，也不改写旧资产、
标定与归档。

首版沿用现有 `Concrete044D` 的 8K 素材，`2.5 m` 是项目声明的源覆盖尺度，不是实物测量值。
按每边 `8192 px` 计算，源采样间距约 `0.305 mm/px`；当前相机在名义 `0.275 m` 距离、
`fx=960 px` 下的针孔采样间距约 `0.286 mm/px`，两者接近，实际输入尺寸及哈希在审计时确认。
烘焙选择 `0.25 mm/px` 时，每边输出约 `10000 px` 仅表示更密的网格，插值不增加真实细节，
不能据此判定 8K 素材不够用或强制更换。先以实际渲染、清晰度和匹配结果判断适用性；若局部
重复仍严重，优先检查单源裁块复用和候选选择；只有现有素材方案确实无法满足需求时，
再讨论额外素材。当前没有增加或混用第二种素材。

## 2. 方法

目标是减少**不同墙面位置**间的人工复制纹理。同一物理区域被相邻照片拍到时，重叠纹理仍须
一致；墙面只离线烘焙一次，不按帧随机生成或改变材质。保留混凝土的粒度、弱纹理区及合理的
亮度／频谱分布，避免靠密集标记或高频白噪声制造容易匹配的独特特征。

专项开始前的 [烘焙工具](../tools/bake_wall_texture.py) 按固定种子随机裁块，通过重叠误差容差带选取
候选，再用最小误差接缝及窄带羽化拼合；但 `choose_patch` 没有邻域复用约束、旋转或镜像，
manifest 也只记录裁块数量而非逐块来源。本轮已增加显式 `--randomize` 入口和来源 sidecar，
默认旧烘焙路径保留。随机种子及大窗口 NCC 合格仍不等于实际匹配已去重，以下完整流程继续作为要求：

1. **按实际重叠匹配定义局部范围**。生产流程先用位姿投影足迹筛候选，再只匹配交集内的
   特征；结合共享相机、拍照步距、相邻扫描带和正常定位误差选择局部减复用范围。
   不仅避开紧邻 DDS 块，也不把两幅完整图像的并集或人为远距对齐当作实际匹配窗口。
   当前无全局回退；远距强制候选只作辅助诊断，允许非邻近位置偶尔复用，不要求全墙唯一。
2. **增加可复现的随机变换**。首版默认使用 8 种无损二面体变换（`0/90/180/270°` 旋转 ×
   是否镜像）；变换本身只重排像素，不额外重采样，源图到目标物理尺度的缩放另行记录。
   连续旋转角 `θ∈[0°,360°)` 保留为可选配置，同样先用现有素材试验，不以更高分辨率原图
   作为准入条件。启用时从原图坐标组合旋转、镜像、尺度及裁剪，尽量一次完成几何重采样，
   避免先放大再旋转等反复插值；高分辨率素材是可选改进，不将上采样当作新增真实细节。
   清晰度以同一源区域、相同目标米／像素尺度和一致滤波规则下的无旋转结果作配对基准，
   在试验前冻结高频能量／梯度幅值等指标的允许变化，并在最终压缩／渲染图像上复核。
   不要求不同自然裁块的梯度或高频能量相等，也不筛掉正常弱纹理区；若旋转造成明显软化、
   接缝暴露或 SIFT 响应偏差，报告该配置未通过，不用锐化或增加噪声补出特征。
   源素材若含方向性内容——混凝土水平施工缝、模板纹或烘焙进去的明暗方向——任意旋转和镜像会
   产生不像真墙的方向混杂。先统计源素材梯度方向分布；有明显主方向时，限制为保持该方向的变换
   子集（例如只用 `180°` 旋转及沿主方向的镜像），并在最终墙面上核对梯度方向分布与源素材一致。
   变换集合及其分布在调参前冻结，变换先于接缝评分和融合。
   保持米／像素尺度，旋转后仅裁取有效源像素覆盖的区域，不以黑边、周期绕回或复制边缘填角。
   记录变换中心、角度、镜像轴、源坐标及插值方式；底纹的随机变换不翻转文字、标尺等有方向
   含义的诊断标记。多个资产种子给出不同布局，同一配置及种子可再生成同一墙面。
3. **将接缝质量与局部去重同时纳入选择**。维护墙面邻域内有效裁块的源索引与变换记录，
   对同一源邻域的大面积复用施加排除或惩罚；接缝合格的剩余候选中按种子抽样，并抑制少数
   源区域被反复选中。旋转／镜像是随机变体，不能自动算作全新纹理：同时检查变换后及旋转
   容忍的局部相似度，防止同一斑点换个角度仍反复出现。按融合后实际保留的像素与来源权重
   统计复用，不把已切掉的候选区域、同一墙面位置的接缝重叠或 DDS gutter 当作重复缺陷。
   源索引、非零位移自相似和局部特征匹配共同判断；自然均匀的弱纹理相似不直接等于源块复制。
4. **候选不足时显式处理**。优先调整单源候选数量／裁块尺度；额外素材仅作最后手段，并记录参数
   变化及来源哈希；不能静默缩小禁复用邻域或放宽相似度门槛。旋转、调色或改变种子都不能
   代替素材容量检查。保留最小误差接缝、真实邻域 gutter、BC1 mip 连续性及现有内存预算，
   去重指标在最终压缩／渲染结果上复核，不能只检查未压缩的中间画布。
5. **用独立照片和实际匹配器验收**。复用 [渲染评价工具](../tools/evaluate_wall_texture_photos.py)
   的捕获／评估框架，改从 [共享相机合同](../src/climbot_description/config/inspection_camera.yaml)
   读取内参、畸变、安装距离及有效足迹，不把现有固定探针参数直接当作当前机器人相机。
   ORB 探针只作辅助，正式评价使用现有拼接链路的 SIFT、候选筛选和几何验证，并保持匹配参数
   冻结。正样本覆盖真实重叠；负样本覆盖邻近不重叠区域、相邻帧中不同墙面点、源块易复用
   距离；远距强制候选仅作辅助。用相机位姿／射线落点真值评价对应点和估计位姿，不能仅凭
   RANSAC 内点多就判定匹配正确；真值仅进入评价，不提供给正式匹配器。

任务开始时先量化旧资产的局部重复，再冻结邻域、相似度／复用面积、错误对应率、错误位姿
接受率和真实重叠匹配质量的判据。旧／新资产在同分辨率、材质尺度、相机轨迹、曝光和噪声
条件下对照；保留一组调参种子及至少两个独立验证种子，不能只挑最好的一面墙。
报告局部重复距离／面积分布、错误匹配位置、正确位姿误差、弱纹理区表现与接缝情况。
若强约束无法满足，明确报告失败或素材不足，不以提高特征密度、修改拼接门槛冒充改进。

每个新资产使用独立目录和 manifest，保留源素材哈希、物理尺度、种子、角度／镜像分布、
去重范围／阈值、算法版本及逐块变换／来源记录；大规模来源记录可用带哈希的压缩 sidecar。
像素—墙面坐标与相机合同保持一致；可视纹理不产生物理沟槽或漏气。旧资产、标定与归档不覆盖，
新资产先通过现有 `wall_texture` 入口显式验收；2026-10-19 审核后成为采集入口默认值，
单独模型预览仍为纯色墙。平墙结果不直接证明负压计划 M2 起伏墙的
曲面渲染和非平面拼接有效，届时应核对同源表面的纹理映射与几何误差。

## 3. 实施顺序

依次完成旧资产重复性审计与判据冻结 → 带旋转／镜像和邻域复用约束的烘焙 → 小区域渲染与
独立种子评价 → 正式新资产及代表性拼接验收。按第 2 节输出来源／变换记录、旧新对照与
失败样例，再将新资产作为独立视觉配置使用；不并入负压计划的物理组合矩阵。

## 4. 验收

当前口径按用户澄清收敛并在新试验前记录；既有轨迹、采集和拼接门限继续按当前合同执行。

| 验收项 | 判据与证据 |
| --- | --- |
| 纹理随机性与局部去重 | 冻结的旋转／镜像集合生效且同种子可复现，逐块来源可追溯；禁复用邻域内的非物理重复低于冻结门槛，变换后近似复制一并统计；接缝、gutter、物理尺度及压缩后质量合格。旋转清晰度按同源区域的无旋转基准及预定容差验证，保留自然弱纹理，不用噪声补特征；有方向素材符合冻结的方向约束 |
| 渲染与拼接匹配 | 真实相机合同下，以生产足迹候选及重叠区域 SIFT 比较旧新资产，记录错误对应／位姿及改善；正确重叠精度和弱纹理能力不退化。不要求零误匹配，远距强制测试不作为门禁。至少两个独立验证种子保留结果，真值仅作评价，不能只报告内点数或最好种子 |
