# S3 原生 Gazebo 集成与独立观测

> 冻结合同／方法，按文中试验时点与配置解释。保留原路径供工具溯源；当前默认与后续证据见[M2 入口](SUCTION_M2_PLAN.md)和[验收矩阵](ACCEPTANCE.md)。

本阶段为平墙、刚性轮、球轮 x=-0.300 m、20 mm 裙边的候选底盘。S1 的同源生成器输出
SDF／URDF；S2 的纯 C++ 核心由 `VacuumSystem` 调用。旧默认入口及 S0 的 12 个运行输入
保持冻结。新入口为 `ros2 launch climbot_gazebo climbot_vacuum.launch.py`，默认无 GUI、
无相机渲染，属于专项物理入口；完整定位、覆盖与采集链路仍须 S4～S7 验收。

## 运行环境与参考问题

本机 WSL 的新入口、原生测量程序运行包装均复用 `mesa_runtime`：默认 D3D12＋本地
修复版 Mesa 25.2.8，启动前校验完整安装与 Gallium SHA-256，失败不回退系统库或软件渲染。
参数 `mesa:=system`／`gpu_backend:=software` 仅供显式对照，原生 Linux 不注入 WSL 库。
即使 headless，只要相机存在仍要渲染；本阶段另明确关闭相机与 Sensors 渲染系统，不能将
物理短测写成图形验收。测量器保存实际进程四个 Mesa 库的映射归属，记录中省略本机路径。
完整使用规则见 [Mesa 部署](MESA_SETUP.md) 和 [问题记录](INCIDENTS.md)。

本机私有参考包括 4W 项目的 `CAPTURE_MEMORY_GROWTH`、`GZ_SHUTDOWN_CRASH_DUMPS`、
`ROUGH_ROAD_RUNTIME`、`COLLISION_PROXY`，以及轨道车的 `MECHANICS`、`WHEEL_ERROR` 和
WSL 部署说明。采用其教训：正常入口使用补丁 Mesa；服务端／GUI 由既有 supervisor 管理；
逐物理步保留碰撞实体、接触点、法向、深度和两侧力，不能靠低频平均掩盖单步异常；M2
不得用不受校验的三角网或视觉平滑替代真实接触证据。参考文件不是本仓库可移植运行依赖。

## 单一施力路径与 B/C

两组共用相同几何、质量／惯量、接触、裙边采样、启动夹具和代码，只改变 `pressure_mode`。
B 为理想固定压差 8404.442641162896 Pa；C 为三台固定档位风机＋等温容积 ODE。该 B 值
取自已冻结 S2 正常最大漏口工作点，不以新测试结果调参。总基础／受控开口 180 mm²，风机
曲线、倒灌面积和裙边参数仍为 provisional；S2 已知不利参数端点不能因此宣布通过。

物理步 1 ms，压力最大子步 50 μs；根据实际间隙更新容积和开口，子步内线性插值，风机
转速使用精确一阶响应，质量平衡使用 S2 隐式步。B 也从环境压力初始化，但首个运行步由
理想源建立压差。B 只用于受控对照，不能验收真实失压过程。

压力合力沿底盘法向，压力中心由 S2 压力权重积分得到；使用 `AddWorldWrench` 带 link
局部 offset 的重载，压力矩不再加一次。裙边反力／摩擦按世界坐标等效合力和力矩施加，
裙边仅有视觉、没有碰撞；驱动轮、球轮与机壳仍由 Gazebo 接触求解。世界若配置旧
ApplyLinkWrench，插件直接拒绝，不静默叠加。有限墙边界由生成墙面碰撞的同一配置推导。

球轮滚阻是作用在自由转动球体上的连续耗散力偶，系数 0.01、速度正则化 1 mm/s，法向载荷
读取前一步原生接触反馈；绕墙面法向的自旋不加滚阻。静止力偶为零，不给底盘添加静态保持力。
滚阻参数与 S1 同源，力偶单独记录并纳入整车角动量核算。

## 安装夹具、暂停与 reset

安装支撑采用显式托举：在真实整车重心补偿重力，并在压力中心施加 80 N 向墙预压力。
托举全部通过物理外力进入求解器，不改位姿／速度、不锁关节、不关闭重力。预压力允许在
撤除前建立三个原生轮接触，避免约束夹具承担所有载荷造成撤除首步零轮压。

启动门槛按实际姿态、压力中心、重心和裙边静态反力重算，满足每驱动轮 S=1.5、驱动轮
N≥5 N、球轮 N≥10 N，并乘 1.05。初筛发现侧向保持时两轮切向力接近均分，不能沿用
S1 仅按法向载荷比例分配的假设：新启动预算同时检查均分及按法向载荷比例两种假设。
这只是两种分配的保守包络，仍不是任意未知分配的严格上界。历史 S1 结果保留其原假设；
本阶段重算及原生载荷另存，不覆盖旧数据、不调整风机曲线追求通过。

满足压力、墙内覆盖、真实三轮载荷和静稳条件连续 0.5 s 后撤除，记录实际时刻和夹具力矩。
10 s 未就绪则锁定启动失败并保留夹具，直到 reset；正常运行不重新启用夹具或引入低压门禁。
暂停不更新压力、转速、计时和施力状态；reset 重新置为环境压力、零转速、夹具有效，清空
失败／就绪状态，并递增代次。原生测量系统本身实现 `ISystemReset`，确保 reset 后继续观测。

## 独立接触与时间口径

`vacuum_sim_probe` 直接读取物理系统在 collision 上更新的 `ContactSensorData`，不以插件
预测轮压作为实测。按 collision id 选择机器人一侧，记录两侧原始力、点、法向和深度。
本机 gz-sim 8.15.0 的这一原始 ECM 消息没有 header 时间戳，torque 字段也未填充；零值
原样保存，不伪造传感器时间戳。每行关联同一步 PostUpdate 的仿真时间及 iteration，报告
样本期望／实际数量、重复时间及接触有效性。接触矩独立用实际接触点对底盘原点计算。
这些是逐步物理数据，不冒称 ROS 接触传感器话题的采样和传输验证。

整车线动量／角动量独立遍历所有原生 inertial links，使用实际质量、世界姿态、重心速度及
世界惯量求和。外力包含重力、压力、裙边、夹具、接触及球轮滚阻；同时报告力／力矩均值和
动量积分残差。以 N 解释原生力，冲量另乘物理步长；不得拟合一个缩放量使其平衡。

Gazebo 在运行时对缓存姿态采用 1e-6 容差，暂停后首个迭代虽不执行物理 Step，仍可能
从后端刷新较新的姿态。测量器分别记录暂停边界刷新量，再对后续各暂停迭代严格比较姿态
与全部负压状态，不通过放宽容差隐藏物理运动。源码依据为官方
[Physics.cc](https://raw.githubusercontent.com/gazebosim/gz-sim/gz-sim8_8.15.0/src/systems/physics/Physics.cc)。

## 预注册验收

正式命令：`python3 tools/validate_vacuum_sim.py --output results/新目录`，使用已构建工作区。
先提交源代码再生成结果，保存版本、源文件／二进制哈希、实际 Mesa 映射、运行输入和逐步
压缩 CSV；长日志保存在 `/tmp`，不提交。普通测试及完整 -j8 套件另记结果与日志位置。

- B/C 各测 0/45/90/135/180/225/270/315°。从撤除首步检查三轮持续接触、载荷底限、
  逐轮要求和原生摩擦圆裕量；稳态窗口固定为撤除后 2～62 s，不能掩盖撤除即失稳。
- 均值法向残差 ≤2% 压力合力，均值力矩残差 ≤0.02 F_pressure ℓ_ref，保持原冻结合同。
  报告逐步原始残差、轮压预测差异和位姿漂移，夹具六维施力在释放后必须为零。
- C 的 45° 重复 0.5 ms 步长，与 1 ms 的稳态压差及各轮均值差异 ≤2%；它不替代 S2
  压力瞬态子步收敛或 S5 故障／运动收敛。
- 独立运行暂停／reset／重启与低压启动超时，失败仍保留诊断。B/C 世界结构由契约测试
  核对只改变压力源。不得据静止证据关闭运动、压力传感器、完整采集、起伏或柔顺轮验收。
