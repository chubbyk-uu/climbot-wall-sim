## 目标与边界

```text
G4 原始归档 → P1 预处理 → processed-run → 局部匹配 → 位姿图 → hard-cut 母版
                                                               └→ 真值评价与原尺寸检查
```

- 原始 run 与 processed-run 只读；每阶段发布到新的不存在目录。
- 第一版只支持已知平面 `wall, z=0`、固定焦距和灰度相机；不包含曲面、自动对焦、运动模糊
  补偿或在线增量拼接。
- Gazebo 墙面 DDS 和 feature 真值只能被渲染后的独立评价器读取，绝不能进入候选、匹配、优化
  或拼接像素归属。
- pose-only 与 optimized 使用相同帧、网格、分辨率、插值和 hard-cut 规则；唯一变量是优化位姿。

## 不可变产物合同

| 项目 | 当前合同 |
| --- | --- |
| 帧身份 | 跨 run 使用 `(source_run_id, frame_index)`，不可只用文件名 |
| 位姿初值 | 曝光时刻 EKF 相机位姿与冻结外参 |
| 投影 | rectified 像素光线与 `z=0` 相交；优化变量仅 `δx, δy, δyaw` |
| 绝对先验 | 从归档 `6×6` 协方差显式提取 `x/y/yaw` 子空间 |
| 正式母版 | `0.25 mm/px` 无损 tiled BigTIFF；JPEG 预览不得用于量测 |
| hard-cut | 每像素选择源图边缘距离最大者，平局取稳定帧序较早者 |
| 可追溯性 | 每阶段记录代码状态、参数、上游哈希和自身产物哈希；正式摘要校验五阶段、五条链接 |

`work-dir`、特征缓存和临时 tile 可重建，不是结果证据。预算不足时只能降低 worker 数并告警；
不能把软内存预算表述为硬上限。并发只能改变耗时，不能改变边、位姿或输出像素。

## 算法链

1. 校验 processed-run 的图像哈希、标签、相机模型、安装快照、位姿和协方差，拒绝 NaN/Inf。
2. 投影每帧米制足迹，只为正面积相交的照片对建立候选。
3. 在预测重叠区执行特征、双向一致性、RANSAC 和固定尺度 SE(2) 估计；接受和拒绝均留原因。
4. 以 EKF 先验和视觉相对约束做鲁棒稀疏位姿图；孤立帧保留先验并显式标出。
5. 分块渲染 pose-only / optimized、覆盖、不确定度、差分、稀疏接缝和预览。
6. 渲染完成后独立量测绝对锚点、尺度、航向、局部残差、接缝跳变及 off-seam 基线，并导出
   truth / pose-only / optimized 原尺寸 tile。

任何预检、缓存、worker 或写入失败都不得发布 completed 结果。

## P2-06 验收域

验收域是冻结任务的 `coverage_region` 多边形：它代表规划器承诺覆盖的区域，不等同于物理可达
域，也不是运行检查器时由操作者另行输入。检查器沿
`mosaic manifest → processing manifest → archive manifest → frozen task` 回溯，并逐环校验
SHA-256。矩形和梯形都使用多边形内点判定；非有限顶点、不与拼接域相交或域内 feature 像素为
零均直接报错，不能真空通过。

三层判据量测对象不同：

| 层 | 判据 |
| --- | --- |
| 规划 | `minimum_nominal_coverage_ratio ≥ 0.95`，量巡检域面积的名义足迹覆盖 |
| 采集前预检 | 实际离散曝光覆盖全部相交 feature 的声明几何 |
| 拼后验收 | `coverage_count.tif` 中巡检域内 feature 像素零漏拍 |

诊断墙有 5 个 feature 按设计伸出巡检域，因此域外缺口不作门禁要求；这不表示它们不可拍到。
检查器另按冻结计划连续 SCAN 足迹和 `motion_region` 安全位姿相机包络分类，只用于解释域外
像素。当前第 1 组的域外未覆盖像素为 439,116，其中 32,504 在计划 SCAN 足迹内；全部落在安全
位姿包络内，但“包络外为 0”受拼接域构造限制，不能当作独立可达性证据。

## P2-06 正式结果

五组采集使用同一墙面和冻结任务，每组横 680 + 纵 660 = 1,340 帧。第 2、3、4 组带完整
`render_environment` 并用于推导门限；第 5 组在门限提交后采集，只用于独立检验；第 1 组缺少
渲染工况记录，只作旁证。正式摘要见[结果索引](../results/README.md)。

推导组实测最大值和冻结门限：

| 指标 | 推导组实测最大 | 门限 | 第 5 组 |
| --- | ---: | ---: | ---: |
| 巡检域内 feature 漏拍 | `0` | `= 0` | `0` |
| 绝对锚点偏差 P95 | `1.787 mm` | `≤ 2.5 mm` | `1.130 mm` |
| 局部残差 P95 | `0.341 mm` | `≤ 0.5 mm` | `0.143 mm` |
| 尺度误差绝对值 | `26.9 ppm` | `≤ 50 ppm` | `16.2 ppm` |
| 航向误差绝对值 | `0.0029°` | `≤ 0.01°` | `0.0002°` |
| 接缝 / off-seam P95 | `3.50` | `≤ 5.0` | `3.50` |
| optimized 不劣于 pose-only | 通过 | 必须成立 | 通过 |

170 个全分辨率 tile 已人工浏览，未发现重影、拖影或几何覆盖而视觉错误。可见亮度接缝由指标
量到但在门限内；后来将平场靶与被摄墙统一为同一 PBR 光度路径，同一输入 A/B 把 optimized
接缝 P95 从 `7` 降到 `6 DN`，不改写既有正式证据。

这些结论只覆盖同一仿真墙、同一任务几何。第 5 组是一次独立检验，不是换墙面、换任务或实机
上的普遍性证明。

## 已知限制

- 三个推导组存在稳定的约 `+21 ppm` 各向同性尺度偏置（10 m 上约 0.21 mm）。注入验证、贴图
  尺寸、碰撞面、渲染内参、畸变反解和接触穿透均已排除；信号已出现在单帧相机模型/重采样链，
  但缺少同墙面量级的独立标尺继续细分。门限明确包住它，不做经验修正。
- 横向第 96 帧在重复采集中均无 SIFT 关键点，位姿图分量为 `[1339, 1]`。重叠照片覆盖该区域，
  hard-cut 可避开此帧；启用 CLAHE 虽能连通，但特征耗时从约 32 s 增至 218 s、精度收益低于
  0.1 mm，因此只保留为弱纹理墙面的显式选项。
- 结构边 argmax 位移代理会随搜索半径线性变化，在当前墙面上不具判别力，已从正式结论撤下。
  接缝灰度跳变指标保留，并始终同时报告同图 off-seam 基线。
- 真值评价按 tile 流式读取，P2-06 峰值 PSS 为 1.36 GB；不要与 fusion 的 4 GB 软配置预算混为
  同一个资源合同。

P2-06 已于 2026-09-01 关闭；当前没有未关闭的离线拼接仿真门禁。新增墙面、任务几何或实机
数据时，必须重新走独立检验与人工原尺寸复核，而不是复用本页数值直接宣布通过。
