# S2 纯物理核心与隔离验证方法

范围：M1平墙、刚性轮的等效风机、腔压和裙边子模型。核心为
`climbot_gazebo/vacuum_core.hpp`及`vacuum_core.cpp`，只依赖C++17标准库。
YAML文件和`vacuum_core_probe`仅是参数与离线实验适配器，不是Gazebo System。
本阶段不发布ROS压力话题，不释放安装支撑，不宣称新底盘已经行走或真实材料已标定。

当前机械输入为[后移球轮S1](../results/suction_s1_rearward_2026-10-17/REPORT.md)：
x=-0.300 m、20 mm接触带，名义最低工作压差约5.6 kPa；25 mm接触带不兼容当前球座净空。
参数文件`src/climbot_gazebo/config/vacuum_physics.yaml`在正式留出验证前提交冻结。
所有曲线和材料参数均为provisional仿真假设。完整结果另见S2报告。

## 流量与风机

气体为等温理想空气：`p_a=101325 Pa,T=293.15 K,R=287.05 J/(kg K),gamma=1.4`。
所有平衡使用质量流量kg/s。孔口采用理想等熵亚临界／临界表达：

```
r = max(p_low/p_high, (2/(gamma+1))^(gamma/(gamma-1)))
m_ideal = Cd A p_high sqrt[2 gamma/(RT(gamma-1))
                            × (r^(2/gamma)-r^((gamma+1)/gamma))]
```

符号从高压指向低压；过压腔体可向环境排气。零压差处乘
`sqrt(|dp|)/(dp²+eps²)^(1/4)`，因此近零等价于有限导数的
`Cd A sqrt(2 rho_upstream) dp/(dp²+eps²)^(1/4)`。eps=0.1 Pa，扫描0.01/0.1/1 Pa。
实现用expm1处理接近1的压力比，小于1e-8相对压差时用零点渐近式避免相减损失。
这仍是Cd=0.65的等效通道模型，不验证真实布料微通道或任意管路阻力。

每台固定档位风机的目标无量纲转速是0或1；单台全速自由体积流量0.012 m³/s，关断压差
14 kPa，时间常数0.15 s，出口代理面积0.0025 m²。体积流量以**腔内入口状态**定义，乘
`rho_c=p_c/(RT)`换算为质量流量。三台相同曲线不代表真机三台已经测得一致。

```
n_new = target + (n_old-target) exp(-dt/tau_motor)
head_i = n_i² P0_i
Q_out,i = n_i Q0_i max(0, 1-dp/head_i), dp>=0
```

负压差即腔体过压时，前向体积流量保守延拓为`n Q0`，未声称该分支有实测支持。
当dp高于某台当前可提供的head时，通过该风机的被动反流按上游等效压力`p_a-head`的孔口
求解；停转时head=0，退化为实际环境到腔体的通道。默认反流面积为出口的5%，不是止回阀；
另扫0/1/5/20/100%。反流参数同样作用于低转速但尚未停稳的风机，避免“目标关机但转速
仍非零，所以永不倒灌”的漏洞。三台并联相加质量流量，不叠加关断压差。

目前仅支持上述单调稳定曲线，参数限制head<0.45 p_a保证合法气体区间及单调前向分支。
实测曲线若包含失速多分支，须新增分支规则和验证，不能把它直接塞进当前求根器。

## 准静态与容积ODE

准静态解质量平衡`R(pc)=m_leak+m_reverse-m_pump=0`，用有界二分法、1e-7 Pa压差区间
终止，返回质量残差和恢复斜率。没有合法括区、恢复斜率为零或非唯一时显式报错，不回退恒力。
全部风机严格停转、零漏气且反流面积为零时，返回`sealed_retained=true`，保持
`pc_new V_new=pc_old V_old`，不会擅自恢复环境压力。运行中的理想止回／零漏气平台没有
唯一恢复分支，准静态模式拒绝；保留初始气体质量的ODE模式仍可显式使用。

独立动态模式采用等温容积方程的隐式Euler：

```
pc_new V_new - pc_old V_old = RT dt R(pc_new)
```

用正压力括区求解，不裁剪负压或腔压；缩腔可产生大于环境的绝对压力并向外排气。风机
一阶速度精确更新，ODE流量用半步转速。此方法一阶收敛，不能把“隐式稳定”当作时间精度
通过。状态全部显式传入／返回，库内没有隐含旧压力或时钟；dt=0的ODE和转速更新严格保持
状态，暂停时改变容积会拒绝。S3负责整个插件暂停／reset及启动支撑，不以这些纯函数检查
替代Gazebo生命周期实验。

线性腔压时间常数取`tau_p=V/(RT × dR/d(dp))`，从实际工作点斜率计算。
快开口使用ODE子步参考，不为准静态的开口跳变编造有限响应时间。风机启停与快开口的
`t10–90`以实际压差的初末变化定义，阈值交点线性插值；有毫秒级动态时使用100/50/25 μs
或50/25 μs子步，不拿1 ms整数采样比较0.1 ms门限。

## 裙边与单一载荷路径

当前输入是墙面投影点、每段长度、底面至墙间隙、间隙变化率和墙面滑动速度。
正常平行平墙下，压力与接触在同一墙面坐标中输出两份独立wrench；均相对调用者原点。
S3必须将压力受压面与墙面接触各自做正确位姿变换；本阶段的处方微倾斜试验用于积分／
开口检查，不冒充整车任意三维倾斜已验收。

平墙下周圈中线每边32点，按弧长分配总刚度5000 N/m、阻尼40 Ns/m；自由高度22 mm，
最大声明压缩10 mm。超过压缩行程的处方姿态显式拒绝，不做虚假的负间隙支持。S3仍需
落实硬限位／壳体接触及失效处理，不能吞掉该错误继续运行。

机械项为非负弹簧阻尼力，阻尼在压缩接近零时以三次smoothstep退零，避免速度非零时
阻尼在接触边界跳变。压力唇口项和有效受压面共用`phi=0.5`及同一接触权重：

```
A_lip,weighted = sum(phi contact_j band length_j)
A_effective = A_inner + A_lip,weighted
N_lip = dp A_lip,weighted
N_contact,j = max(0, N_mechanical,j + dp A_lip,weighted,j)
```

压力中心按内区及各唇口单元面积权重求出，压力wrench只计算一次`r×F`；接触wrench另按
各墙面点求和。关闭接触的唇口不保留支撑。滑动摩擦为
`-mu N v/sqrt(|v|²+eps_v²)`，eps_v=0.001 m/s；静止为零、功率非正。
S1的面积、20 N预载及运动拖曳由独立Python模型交叉检查，不能重复扣唇口载荷。

暂定1 mm伸展／失贴过渡：自由高度以内接触权重1，之后以smoothstep降到0；残余开口
`h<=0:0; 0<h<w:h²/(2w); h>=w:h-w/2`连续一阶。漏口面积为弧长乘残余开口。
独立贯通通道用显式`connected`和高度定义，与同处抬起开口取max防重复；孤立坑不直接
变成贯通通道。1 mm不是实测裙边贴合阈值，也不验证H1对真实墙面小起伏的适用范围。

## 标定、留出、故障和数值检查

A_ref=80 mm²、残余基础漏气20 mm²；标定额外开口0/1/2 A_ref，留出0.5/1.5/3 A_ref。
正常允许额外开口上限在正式留出前固定为2 A_ref，不因3倍开口偶然通过而扩大。
工作点标定不算验证。当前曲线的正常合同针对S1名义参数，9 kPa未知量端点单独报告：
若最不利允许漏气下达不到这一端点要求，必须写出，不能把核心数学验证通过说成该端点通过。

独立数学参考采用另一份孔口表达和SciPy Brent求根；动态参考用Radau高精度积分等温质量
方程，与C++隐式Euler比较。这验证方程实现及离散误差，不验证自选参数的真实物理准确性。

记录全部停机组合与5档反流面积，交叉基础及0/1/2/3/6/10 A_ref开口，明确失效边界；
停一台不预设必然失败。风机启动／停机、快速开口、变量容积慢速开合另存时序。
受控间隙正反静态扫描用过渡宽度1/1000和1/2000空间步，检查面积、流量、压力和裙边力
相邻增量及分支一致性；另以1/0.5 ms作往返慢开合ODE与准静态试验，分开报告真实动力学
滞后、阻尼和时间步误差。周圈32/64/128点加密，加入处方微倾斜与平动／转动摩擦，检查
力矩和耗散，不只检查对称姿态。
