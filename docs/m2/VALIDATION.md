更新：2026-10-22。入口见[M2](../SUCTION_M2_PLAN.md)。本页维护当前判据，历史合同与修订理由见
[原验收设计](../archive/m2/ACCEPTANCE_DESIGN_2026-10-19.md)和[T2 修订记录](../archive/m2/T2_2026-10-19.md)。

## 物理与数值

| 项目 | 判定原则 |
| --- | --- |
| 表面一致性 | 源面、视觉、碰撞与裙边查询记录误差／变换；原生接触独立测量，代理几何声明适用范围 |
| 轮胎 | 独立接触载荷核对静挠度、回弹、卸载、重复加载与行程；保持冻结 k/c |
| 压力／牵引 | 新耦合状态重新计算需求；记录逐轮法向与切向力，不把球轮或裙边反力计作驱动轮牵引 |
| 正常保持／运动 | v2 的 50 ms 平均逐轮裕量及逐步瞬时裕量共同检查；失触、低轮载和所有违规计数保留 |
| 裙边止挡 | 正常计分窗口 `skirt_stop_previous_normal_n=0`；缺字段的旧记录不能证明此项 |
| 连续性／收敛 | 贴合失效过渡、周圈采样、时间步长和压力响应分别核对，不以平均值掩盖短时异常 |
| 故障 | 单列失效点；停一机倒灌、全停失密封等边界不宣称通过 |

具体冻结轮载阈值由 [`m2_load_criterion.py`](../../tools/m2_load_criterion.py)
及报告记录。用户确认的 v2 保留 μ=1.1 以复现旧证据；新系数输出显式 μ 的 v3 标识，阈值不变。
新记录读实际 μ，历史记录缺系数则要求显式输入；不得用当前默认猜测历史物理。

## 运动、成像与性能

- 控制／里程计／TF／reset 及 M1 关闭兼容先短测，再完成一组冻结的大面积独立任务。
- 曝光按真实光轴与表面落点评价，保留 1 ms 时序、P95、最大值及超限数；单张最大 5 mm 门槛不放宽。
- 正式 GUI 性能同时运行 Gazebo、RViz 和正常采集，1 ms 步长、1920×1080、0.25 mm/px；
  完整任务平均 RTF≥0.95，报告 10 s 窗口、加载成本和清理结果。软件渲染短测不能替代此项。
- CUDA 拼接明确 `--backend cuda`；检查原生 `execution.effective=cuda` 且 `execution.fallback=false`。
- 真值只用于模拟传感器和独立评价，不输入控制或生产拼接。原图与 producer provenance 不改写。

## 已验证与未验证

T3 的 μ=1.1 双 GUI 整墙、定位标定后的新整墙、μ=0.8 横纵短任务是不同证据范围，详见
[结果索引](../../results/README.md)。降低摩擦没有重开全部整墙、性能或极限故障验收。

M2 图像的错位／覆盖缺口仍在；显式尺度候选有收益，但未达到整幅平墙等级。
唯一整墙仿射未满足预注册改善及背景保护条件，已拒绝，本轮到此停止。
任何新墙面、真机噪声／滑移、任务几何或物理参数变化须重新声明要复核的范围。
