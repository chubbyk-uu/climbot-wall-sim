## 墙面与碰撞表示

表面来源为 [`m2_wall_surface.yaml`](../../src/climbot_gazebo/config/m2_wall_surface.yaml)：

| 部分 | 当前表示／边界 |
| --- | --- |
| 起伏 | ±2 mm，主要尺度 0.2～0.8 m；种子固定、C++ 单一源查询，参数为仿真假设 |
| 板缝 | 宽 5 mm、深 3～5 mm 的渐变槽；槽口、侧壁、交汇和通流截面独立核对 |
| 物理裂缝 | 源配置中少量真实分叉沟槽；视觉裂缝贴花不自动成为物理槽 |
| 驱动轮碰撞 | 仅起伏的原生高度场；省略窄沟槽为显式轮接触近似 |
| 球轮碰撞 | 共心代理球与真实板缝代理网格；保留已验证惯量／滚阻等效关系 |
| 视觉与裙边 | 同一源面的真实起伏与沟槽，几何误差与贴图映射不由碰撞简化反向修改 |

不同表示允许分辨率不同，但不得静默填平决定泄漏的通道。原生高度场边界按后端采样跨度处理；
几何组织正确不单独证明 ODE 接触动态正确。早期重叠高度场、真实三角网驱动轮等失败路线见
[T0 记录](../archive/m2/T0_PROGRESS_2026-10-19.md)与[故障索引](../INCIDENTS.md)。

## 轮胎与状态链

配置见 [`m2_wheel_compliance.yaml`](../../src/climbot_gazebo/config/m2_wheel_compliance.yaml)，
侧向接触及预压解释见[轮胎侧向报告](../../results/m2_t2_tyre_lateral_2026-10-19/REPORT.md)。

- 150 N 实际压缩 1 mm 是隔离台架目标；不能直接以 `N/k` 代替原生测量。
- 刚度约 622068 N/m、阻尼约 1266.20 N·s/m；行程 0～4 mm，预压参考接触载荷 275 N。
- 固定 k/c、球面接触和 1 ms 步长下补充 450 N 上界，实际压缩 3.00 mm、未到止挡；
  校验载荷范围更新为 50～450 N，未重拟合轮胎。
- 法向移动关节在 SDF／URDF 同名同轴，真实 JointState 经 bridge 形成动态 TF；reset 重新初始化。
- 球轮保持刚性；失败的浮动球座不启用，法向柔顺不自动证明真实接触斑或所有切向动力学。

## 裙边、压力与耦合

沿用[负压物理基础](../suction/PHYSICS.md)：周圈机械压缩、压差唇口载荷、有效面积和压力中心
来自同一模型。只有 VacuumSystem 一条施力路径，裙边碰撞不重复承载。

裙边贴合到开口连续过渡，只把贯通内外的残余通道计为额外漏气；孤立凹点不是漏口。
正常通道允许非零流量，在三条固定风机曲线下按质量流量平衡求压力，不能逐工况提风机保证通过。
四段无摩擦刚性止挡的反力另行观测，正常计分窗口必须为零。

轮胎压缩、车身间隙／姿态、裙边开口、负压与轮载共同构成耦合；M1 刚性轮压力下限不直接移用。
暂定风机、裙边、轮胎和重力蠕滑参数仍需真机数据校准，线缆自重与拉力未建模。

## 摩擦、定位与采集

轮胎／墙面配置在 [`simulation.yaml`](../../src/climbot_gazebo/config/simulation.yaml)，
有效 μ 取两侧较小值，当前为 0.8；球轮为独立参数。生成资产、启动需求和现用评测都使用实际 μ。
载荷记录的 schema 3 保存 `recorded_physics_mu`；缺元数据的历史记录重新评分必须显式给系数。

巡航与加减速由共享机器人／控制配置约束，当前巡航 0.30 m/s。轮速里程计含已标定重力蠕滑补偿。
EKF 的 Q 与 0.5 s 延迟历史来自带噪声数据标定；传感器 R／噪声未随拼接候选缩小。
`precision` 仍包含随机噪声，`realistic` 还注入额外外参／时间戳失标，两者不应混作同一验收档。

## 图形与加载

起伏墙依赖经校验的私有 ODE，WSL GPU 依赖共享修复 Mesa；只向对应子进程设置环境，缺库失败。
整墙资产按源定义、纹理和实现哈希缓存，首次生成可需约两分钟。主视图默认对准墙中心、拉远
显示整墙；该 GUI 视角不改变巡检相机标定或照片。墙面频闪未确认根因，暂搁置。
