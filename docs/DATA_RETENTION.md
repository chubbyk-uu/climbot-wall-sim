## 存储边界

- Git：源码、配置、文档、小型报告／摘要，以及用户批准的 README 展示图。
- 本地数据根：`CLIMBOT_DATA_ROOT`，未设置时为 `$HOME/climbot_data`；照片、录包、原生时序、生成资产、母版和逐帧清单不进 Git。
- `/tmp`：日常诊断日志和临时运行产物，重启后可能消失；正式证据须另行归档。
- Mesa／ODE 的共享安装、标定和当前资产是运行依赖，不作为普通缓存清理。

1. 只执行用户当前授权的具体范围；过去一次授权不自动适用于新数据。

4. 删除后核对目标缺失、保留项完整和实际空间变化，追加独立回执与缺失标记。
