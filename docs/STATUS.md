## 当前默认

- 起伏墙、预压柔顺轮、三风机单腔负压；显式 M1 对照为 `wall_surface:=flat wheel_compliance:=false`。
- 巡航 0.30 m/s、1 ms 物理步；轮胎—墙面有效摩擦 0.8，球轮和裙边摩擦独立。
- EKF Q 与延迟历史按现有带噪声输入标定；传感器噪声和 R 未为拼接缩小，仍无零侧滑约束。
- 拼接默认仍为 SE(2)，逐帧尺度显式可选；未采用完整姿态投影或新增整墙仿射。
- 采集使用 M2 同源起伏墙贴图；单独模型／规划预览仍可用纯色。主视图默认整墙居中远景。

参数唯一来源见[接口与配置归属](INTERFACES.md#配置归属)，模型细节见[M2 模型](m2/MODEL.md)。

## 下一步与停止边界

| 事项 | 处理决定 |
| --- | --- |
| 墙面局部频闪 | **用户决定暂搁置**。异常取决于启动，静止视角也可能闪；照片暂未发现异常。驱动更新并重启 WSL 后未复现，后续再现时保留现场，不主动增加重启或渲染参数试验 |
| M2 残余接缝／边缘覆盖 | 本轮停止。唯一整墙仿射未达到预定收益且背景退化，已拒绝；不自动展开局部形变、参数搜索或补采 |
| 资产强杀后的 `.partial-*` 残留 | 已知运维限制，按精确路径核对后处理；不与有效缓存混删 |
| 实机接入 | 取得实测风机、裙边、轮胎、传感器与线缆数据后再标定；硬件急停和实机安全门限独立验证 |
