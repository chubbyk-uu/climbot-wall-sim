## 当前最重要的未关闭门禁

### P2-06：全目标缺陷/接缝检查

覆盖已闭合。`3f422f5` 的联合盲测采集横向 680、纵向 660 共 1,340 帧，在巡检域
（冻结任务 `coverage_region`，`0.55…9.45 × 0.55…7.45 m`）内 21 个与拼接域相交的
feature **零漏拍**；域外另有 `439,116` 像素未覆盖，属于按设计贯穿整墙或伸出安全框的
5 个 feature。域外像素不作要求，但这不是“拍不到”的结论：相机足迹可及墙边 `0.069 m`
处，域外未覆盖像素里有多少落在可观测包络之内需要单独分类，见[拼接计划](MOSAIC_PLAN.md)。
判据取“巡检域内 feature 零漏拍”，由 `inspect_diagnostic_mosaic` 直接输出。
此前记录的 `22.99%` 是不裁剪巡检域的旧口径。

同一组数据的绝对锚点偏差 P95 `1.67 mm`、局部残差 P95 `0.226 mm`、尺度误差 `+17.4 ppm`。
这些数字要到墙面被拍平面与行驶平面重合之后才成立：此前贴图块高出碰撞面 `1.25 mm`，
使整幅拼接带上 `+4566 ppm` 的尺度误差，绝对偏差因此虚高到 `20.62 mm`。

**仍不冻结门限**：只有一组数据，尚未证明这是可复现的分布。需要重复采集。

可复查证据：

- [P2-06 联合盲测摘要](../results/mosaic_p206_blind_2026-08-30_summary.json)；
- [P2 验收项](ACCEPTANCE.md)；
- [拼接设计与验收门禁](MOSAIC_PLAN.md)；
- 历史对照 [P2.7d/P2.7e 摘要](../results/mosaic_p27d_blind_2026-08-27_summary.json)，
  其绝对值受上述墙面几何影响，不可与当前数据直接比较。

新 P2-06 长任务曾暴露偶发定位尾延迟，随后又暴露 GUI 负载下相机 trigger 被全高清图像所在
bridge 阻塞的问题。后者已通过独立 trigger bridge 定位并关闭；默认 D3D12 + Gazebo GUI +
RViz 的纵向动态验收完成 `660/660` 曝光与归档，轨迹、位置、航向和照片足迹覆盖指标均通过。
定位链的 S1 累计稳定性证据仍继续维护，但不再阻塞新的正式采集。根因、A/B 和指标只在
[定位链路偶发断档调查与优化计划](LOCALIZATION_GAP_PLAN.md)维护。
