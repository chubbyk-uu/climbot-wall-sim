# S1 布局与逐轮逆动力学计算

这是 M1 平墙、刚性轮的离线设计方法；不是 Gazebo 动态实验，也不表示风机或裙边已经验证。
候选输入在 `src/climbot_description/config/vacuum_chassis.yaml`；当前启动默认仍读旧 `robot.yaml`。
新旧结构不混用质量参数。相机标定与光心继续从 `inspection_camera.yaml` 读取。

## 输入和几何

坐标原点为驱动轴在墙面的投影，x 向前、y 向左、z 离墙；航向 0° 向墙面右侧，90° 向上。
机身 CAD 外形 426.5×342×85 mm，底面离墙 18 mm；中心 x=-141 mm 来自 CAD 按比例量取，
±5 mm 是读图精度。轮距 435 mm、轮半径暂取估计区间中点 47.5 mm，外宽 482 mm 导出轮宽
47 mm。三个风机位置、尺寸和质量及球座尺寸是仿真候选，没有真机尺寸认证。

候选球轮为半径 12.5 mm 的钢球，x=-290 mm；球座顶部封闭，底板开孔及盖住孔口的法兰使
球轮处于同一个底部腔体内，不把球座安装孔当作连通外界的漏口。小球局部进入底板凹位；
球自由滚动，球座由刚性约束承重，不模拟内部小滚子。将球座直接平移到 x=-240 mm 会挡住
后风机进气；过分后移又会侵入密封带。检查同时包含裙边带宽、±2 mm 安装偏差及进气通道净空。

分项计重：等效铝底板、等效聚合物盖板／导管、两侧内部载荷、转动轮、三个风机、球座／球、
裙边、相机及两个矩形空心铝支架。材料密度、壳厚、内部载荷 8 kg 等均是公开假设；内部载荷
含驱动电机、电池、电路、紧固件及未单独建模的安装件，轮质量不再含电机。内部载荷扫描
6/8/10 kg。完整惯量包含每件自身惯量和偏心项，保留非对角项；不做刚度／强度认证。

相机光心仍为 (340,0,275) mm、机体仍为旧相机代理。支架重新从新机壳连接到相机背面，
因此顶部约 375 mm，而非 CAD 图的 255 mm；这是保留现有成像合同产生的明确偏差。

底腔仅计底面到墙之间的空气，加三个封闭进气导管，扣球与球座占积；上部机壳内环境空气
不计入腔容。三个风机的进气口均通同一个浅腔。风扇叶片、壳内 CFD、排气动量和布料编织
不在 S1 求解范围。轮子为刚体，裙边只输出预览外观，后续由插件提供唯一的等效接触力。

前扩 20/40 mm 是真实增加机身前缘，后缘不动；地板、盖板、支架、质量、腔容和受压面一同
重算。不能只移动压力点。CAD 中心误差移动整个机壳及其后缘安装的球座；球座装配误差另扫。

## 压力与裙边

矩形轮廓长 L、宽 B、接触带宽 w：

```
A_inner = (L-2w)(B-2w)
A_lip = LB-A_inner
A_effective = A_inner + phi A_lip
F_pressure = Δp A_effective
N_skirt = k(free_height-gap) + Δp phi A_lip
```

同一个 `phi` 表达接触带压力过渡与唇口墙面反力，二者不能独立拟合后重复扣除；基准 0.5，
敏感性 0.25/0.5/0.75。当前均匀压差和对称轮廓下，压力中心为轮廓中心。正常接触压缩 4 mm、
k=5000 N/m 得机械预载 20 N。静止时轮系可用法向合力恰为 `Δp A_inner-20 N`，所以固定 Δp
改变 phi 不改变静态轮压，却改变总吸力、裙边载荷和运动拖曳。这是检查单一载荷路径的守恒关系。

周圈接触取带中线，每边 32 个长度加权中点；压力反力与机械预载共用该组点。
每点运动摩擦 `-mu_skirt N_j v_j / sqrt(|v_j|²+eps²)`，eps=0.001 m/s，严格耗散，静止为零，
不把正则化摩擦当作静态保持力。`mu_skirt=0.05/0.10/0.20` 是假设范围。

## 逐轮逆动力学

接触点为 (0,±b,0)、(-d,0,0)，其中 b 为半轮距、d 为轴到球轮距离。按给定瞬时轴心速度 v、
纵向加速度 a、角速度 omega、角加速度 alpha 计算质心加速度：

```
a_origin = (a, v omega, 0)
a_cg = a_origin + alpha×r_cg + omega×(omega×r_cg)
g_body = (-g sin(heading), -g cos(heading), 0)
```

全车质量计入平动惯性；刚体惯量扣除自由球自身的锁定转动惯量，再加球的滚动自转角动量导数。
驱动轮锁定惯量另加绕 +y 轴自转的角动量导数（含转向陀螺项）。球滚动所需惯性切向力为
`-I_ball a_ball / r_ball²`，不把加速球轮当作零切向力。

球轮滚阻取 c_rr=0.01，0.001 m/s 正则化，等效为作用于球心的拖曳；它等价于墙面接触力加
滚阻力偶，其倾覆力矩进入法向方程。静止无球轮保持力。离线求根可作有符号延拓，但任何
法向载荷低于驱动轮 5 N、球轮 10 N 的点均拒绝，不把负接触载荷当成物理解。

以实际压力、裙边、重力、惯性力矩联立三个法向载荷。剩余切向合力与偏航力矩由驱动轮提供：

```
T_left,x  = (T_total,x - M_required,z/b)/2
T_right,x = (T_total,x + M_required,z/b)/2
T_i,y = T_total,y N_i / (N_left+N_right)
mu N_i >= S sqrt(T_i,x²+T_i,y²), S=1.5
```

侧向航向的重心偏置力矩也在 M_required,z 中。另求允许自由横向分配的摩擦圆可行域下限，
但主设计使用法向比例假设；两者都待 S3 独立轮压及接触验证。裙边不参与静态切向平衡。
额外检查 `tau_i = r T_i,x + I_axial wheel_alpha_i + damping wheel_omega_i` 与当前 80 Nm 额度、
轮速与 30 rad/s 额度；驱动轮自身转动惯量不能从电机需求中漏掉。

## 搜索、范围和复算

`design_vacuum_chassis.py` 从当前控制与执行器配置派生正反向行驶、加速／制动、纠偏、
正反转向，以及含零速度／零加速度的额定边界组合。组合满足逐轮轮缘速度 0.45 m/s、
加速度 0.70 m/s² 上限。八种覆盖任务的实际速度／加速度来源相同；本计算**不冒充实际跑过
八工况**，也不构成连续状态空间最优化证明。额外固定种子抽 5000 个内部状态作遗漏审计，
正式运动与轮压仍在 S3/S5/S6 量测。

各配置静态及运动航向以 1° 扫描，所有局部峰值周围 0.1° 细化。敏感性先 5°、所有局部峰值
细化到 0.1°，最不利组合再用 1° 网格重算。压差二分精度约 2e-6 Pa，搜索上限 30 kPa；
仅在正接触域缓存仿射力系数，仍计算非线性的横向比例和摩擦圆。不满足支撑／牵引则显式失败，
不存在回退恒力。电机检查独立于单调求根，避免将过大压差引起的拖曳超额误当“还要增压”。

扫描球轮载荷门槛 5/10/20 N、轮径 45/47.5/50 mm、μ=0.8/1.1/1.3、壳体 CAD 偏差、
球座装配偏差、内部质量、接触带、phi 和裙边摩擦；主要未知项取 32 个交叉端点并用 μ=0.8。
这些离散集合只代表声明的假设范围，不是实机公差保证。各方案同时保留几何拒绝原因。

以全部候选状态逐轮需求的最大值给出最低工作压差，向上取整到 100 Pa 作为名义设计要求。
这是 S2 选择等效风机曲线的**需求输入**，不是已经存在的工作点，也不是风机验证。敏感性最坏
要求另列，不能把名义压差说成覆盖全部未知参数。启动表为落稳后的静态姿态，列出
`1.05 Δp_min`；S3 根据实际安装间隙、释放姿态和支撑动态复核后再冻结启动配置。

复算（输出目录必须不存在，避免覆盖旧证据）：

```bash
python3 -m pytest -q tools/test_vacuum_design.py tools/test_suction_analysis.py
python3 tools/design_vacuum_chassis.py --output /tmp/suction_s1_new_run
# ROS/Gazebo 环境已加载时
# gz sdf -k /tmp/suction_s1_new_run/candidate.sdf
```

输出有分项完整惯量、净空、SDF/URDF 预览、逐状态 CSV、逐配置峰值、敏感性、启动表、
400 N 失败诊断、内部状态审计、图及输入／输出哈希。SDF 不带运动、压力或传感器插件，不能
直接当作已集成机器人；URDF 用固定球轮 TF 表示标称姿态，SDF 使用自由球关节。S3 把同一
描述器接入正式生成链路并独立验证，避免长期维护两个运行模型。此时还需更新规划足迹和裙边
墙缘裕量，保留原 WheelSlip 柔度／标称载荷比值，重新量测侧滑与轮压。
