## 1. 目标与范围

在 Gazebo Harmonic 中，把现有恒定法向力扩展为有抽气、漏气、密封接触和压力测量的吸附模型。
以两个驱动轮各自所需的法向载荷为设计依据，根据新质量、重心、支撑位置、裙边反力和运动
工况重新反算总吸附力与负压。`400 N` 仅是旧结构的历史对照值，不作为新模型的固定目标，
也不是真机吸力测量值。

M1（主交付）包含：

- 根据尺寸图及后续真机结构修订调整底盘、底部浅腔和裙边，两个驱动轮在圈外，底部万向球轮在圈内；
- 三个固定档位风机，共用一个连通负压腔；
- 平墙、刚性轮下，有弹性支撑、压缩回弹、低摩擦和局部间隙漏气的密封裙边；
- 腔压工作点、必要的压力动态、吸附合力与力矩，以及一个带可配置误差的压力传感器；
- 正常行走、转向、局部漏气、单风机停转和全部停转的仿真验证。

M2（独立扩展）再加入同源小起伏／深沟槽墙面及驱动轮法向柔顺性，两者独立开关、默认关闭，
分别标定后再做耦合验收。M1 的 B/C 对照固定为平墙＋刚性轮，不等待 M2 实现；M2 不自动展开
全部场景与故障扫描的笛卡尔积。M1 的局部漏气先用明确面积的受控通道，不依赖起伏墙面。
S0～S6 开发期曾冻结旧底盘并保持旧默认，新负压候选显式选择。S7 已通过并合并 main，
当前默认且唯一可运行结构为新底盘＋负压，旧几何和恒力路径已删除，生命周期见第 5 节。

墙面贴图的局部去重与随机变换已拆为独立任务，见 [WALL_TEXTURE_PLAN](WALL_TEXTURE_PLAN.md)，
不在本分支实施，也不影响本计划的物理验收。

采用等效物理模型：腔内压力先近似均匀，裙边沿周圈离散。叶片三维流场、布料织物、海绵
微结构、铁丝逐根形变和真实材料认证不在本轮范围。真机外场使用的供电线缆本轮不建模：其自重、
拉力及对下滑力和剥离力矩的影响不计入轮压与吸力需求，结论须注明该排除。压力传感器首先用于
观察与记录；首版保持风机固定档位，不引入压力闭环调速。低压运动门禁如需加入，另列控制需求和
验收项。

## 2. 输入事实、图纸解读与待定参数

### 已确认的真机结构

1. 两个驱动轮位于密封圈外，密封圈绕底部腔体闭合。
2. 随动支撑实际采用**底盘下方、密封圈内的万向球轮**。图纸中后伸的支架因强度不足未沿用，
   本轮不能按旧图纸继续在机身后方布置球轮。
3. **风机共三个**，固定档位持续抽气，作用于同一个连通腔体。
4. 密封结构由海绵、弹性细铁丝支撑和外包低摩擦耐磨不透气布组成；支撑用于防止向腔内卷入。
   照片确认裙边挂在机身侧壁底部的铝条上，沿机身外轮廓闭合一圈；安装位置与腔体内缘分开记录。
5. 真机未安装腔压传感器，也没有提供实测负压或风机性能曲线；本轮在仿真中补充传感器。
6. 用户实机经验：裙边能充分覆盖轻微起伏，这种起伏不会增大漏气；深沟槽才会造成严重
   漏气。这是定性经验，尚无定量幅值、空间尺度和沟槽截面数据；将其作为模型假设，M2 实施前
   冻结暂定贴合范围及深沟槽试验范围，不能用模型输出反证这条经验已获定量验证。

### 3.1 旧 400 N 的计算与测量依据

历史提交 `0128f01` 及[状态归档的摩擦饱和分析](archive/status-history/STATUS_2026-08-27.md)
记录了从 `220 N` 提至 `400 N` 的原因：

- 旧底盘质量为 `14.5 kg`，自重约 `142 N`，驱动轮摩擦系数为 `1.1`。
- 旧结构下驱动轮静态合计承担约 `66.7%` 总吸力。`220 N` 时轮压约为
  `45.8 + 100.9 N`，摩擦上限约 `161 N`，仅为自重的 `1.13` 倍；原地转向时载荷转移，
  某些航向下两驱动轮合计轮压降至约 `80.7 N`，摩擦上限约 `89 N`，不足以平衡自重。
- 按旧分配比例估算，静态最低吸力为 `mg / (1.1 × 0.667) ≈ 194 N`。选择 `400 N`
  后，旧底盘的静态总体摩擦裕量约为 `2.06`；计入 `2 kg` 巡检载荷的粗略核算约为 `1.81`。
- [400 N 载荷记录](../results/normal_loads_400N.csv) 的一个静态工况中，左轮、右轮和球轮
  分别约为 `105.781 / 160.885 / 133.334 N`，并非左右各承担 `133.3 N`。
  `133.3 N` 是当时用两驱动轮平均值表示的 WheelSlip 标称载荷，不是每轮所需轮压门限。
- [带相机的载荷复验](../results/normal_loads_g1_camera_2026-08-24_summary.json) 又覆盖了
  多航向、行驶、制动和转向；左右轮各自最低约 `84.194 N`，出现在不同转向工况。

这些数据解释旧参数的来历。新结构的内置球轮、裙边反力、质量与重心都改变载荷分配，不能
继续套用 `66.7%`、两轮均分、自重的一半或历史 `400 N` 作为新设计结论。
`2.06 / 1.81` 是相应旧配置的总体摩擦能力与自重之比，不能视为每轮裕量；较弱一侧以及载荷
转移工况可能先达到摩擦极限。

### 3.2 布局静力初筛与几何来源区分

在统一的驱动轴原点下记球轮 `x=-L`、压力中心 `x=-c`，重心距墙高度为 `h`，自重为 `W`。
不计裙边、平墙、驱动轴朝上的静止筛查为：

```text
α_drive = 1 - c/L
N_drive,total = α_drive F - W h/L
F_min,axial(S) = (S W/μ + W h/L) / α_drive
```

筛查式适用于 `0<c<L`；分担系数非正时应标记布局不适用，不能算出负吸力后继续选型。
`S` 表示该算例要求的逐轮摩擦裕量，左右对称时每轮承担一半轴向需求。这是轴向静止筛查，
不包含横向分配、静态偏航、裙边和动态载荷，不能作为全航向设计吸力。

当前仓库配置重算为 `m=16.5 kg`、`x_cg≈-0.052424 m`、`h≈0.109152 m`，取 `g=9.807 m/s²`、
`μ=1.1`。下表共用这套旧质量与重心，仅更换压力中心／球轮坐标以隔离几何影响；
CAD 尺寸不代表新质量分布已确定。

球座净空与有效面积；需要前移压力中心时应调整腔体形状／位置，例如评估前部扩大，并同步重算
质量与压力面积，不得单独平移施力点制造轮压收益。

S0 的[旧质量静力诊断报告](../results/suction_s0_2026-10-17/REPORT.md) 已加入静态偏航与

`c=0.141 m、L=0.240 m` 的 `S=1.5` 需求在后一假设下约 `834.1 N`，比轴向约 `713.6 N`
更高，最不利航向约 `53.6°`。这仍共用旧质量／重心且不含裙边和动态，只是补充诊断，
不是 S1 新结构的 `F_design`。不能以某个轴向算例通过代替全工况验证。

### 3.3 按每个驱动轮的需求重新确定吸力

1. 冻结新质量、重心高度、两驱动轮接触点、内置球轮位置、裙边支撑轮廓和压力作用中心。
   两驱动轮与球轮应形成有稳定面积的支撑布局，不能因为移入腔体而退化为共线支撑。
2. 对全航向静止、上／下／横向行驶、加速、制动和原地转向，计算或量测每个驱动轮的切向力
   需求 `T_i,required`，包含重力、惯性、裙边摩擦和球轮滚动阻力的影响。侧向姿态下还需平衡
   `x_cg W` 对应的静态偏航力矩；当前质量分布下每轮差动纵向力约 `±19.7 N`，即使没有转向
   指令也存在。不得把被动球轮或裙边承受的法向载荷当作驱动轮可用牵引力。
3. 使用明确的设计裕量 `S_required` 约束每个驱动轮的摩擦能力。第一轮筛查可用摩擦圆：

   ```text
   N_i,required = S_required × ||T_i,required|| / μ_i       i = 左驱动轮、右驱动轮
   N_i,actual >= N_i,required                              # 各工况分别检查
   ```

   `S_required` 及纵横向摩擦模型在 S0 固定并说明依据；旧总体裕量只作参考。转向时还需满足
   所需力矩和摩擦预算，不能仅用两轮法向载荷之和判定通过。刚体静力学不能唯一决定两轮横向
   力分配：先计算摩擦圆可行域，再明确采用的分配假设、保守边界；M1 与刚性轮接触结果核对，
   M2 加入柔顺性后重算。正则化裙边摩擦的静态保持能力
   不计入设计预算，运动阻力计入。
4. 联立整机力与力矩平衡、各接触点非负载荷及裙边机械／压差反力，求满足每轮需求的总吸力。
   M1 固定刚性轮几何，M2 再联立轮胎柔顺性并独立复核，不将 M1 设计值直接作为 M2 结论。
   将最不利工况与动态载荷转移纳入 `F_design`，再计算 `Δp_design = F_design / A_effective`，
   最后选择三个风机的等效曲线和固定工作档位。S1 给出初算，S3 实测后复核，在 S5 前冻结。
5. 若支撑位置或压力作用中心使某个轮子始终卸载，应先调整布局，而不是无限增加总吸力。
   内置球轮必须保持所需支撑裕量，同时避免过度分担驱动轮需要的轮压。

## 4. 等效物理模型

### 4.1 三风机与单腔压力

三个风机在相同腔压下分别计算流量并相加。固定档位表示固定目标转速；实际抽气流量仍随压差
变化。每个风机保留独立启停状态和转速响应，不能直接分配三个固定吸力。相同风机并联不会
叠加零流量最高压差；密封良好时少一台对压差影响可能很小，停转影响须与漏气及倒灌通道一起评估。

首版设计路线是**准静态工作点＋风机转速的一阶响应**：每步以当前几何、漏气和风机转速求
质量流量平衡，记录残差、工作分支与求解容差。曲线须给出合法区间和稳定分支；无根、根不唯一
或越界时明确处理，不能任取工作点或改回恒力。

同时保留等温容积 ODE 作为独立动态参考或显式可选模式。以腔内绝对压力 `p_c`、外界压力
`p_a` 和有效容积 `V` 表示：

```text
Δp = p_a - p_c
准静态：Σ进入腔体的质量流量 = Σ离开腔体的质量流量
容积 ODE：d(p_c V)/dt = R T (Σ进入腔体的质量流量 - Σ离开腔体的质量流量)
平面合力：F_pressure = Δp × A_effective
```

S2 从容积与工作点附近的流量斜率估算压力时间常数，和风机启停、轮胎运动及漏气变化的时间尺度
比较；“约 2 ms”目前只是 review 估算，不作为已测参数。若快速开口／接触事件不满足时间尺度
分离，使用受控子步、解析或隐式 ODE 并记录实际模式，不以准静态跳变冒称真实压力响应。

风机曲线、漏气通道与容积变化使用一致的质量流量定义，体积流量换算时注明对应压力和密度。
裙边间隙、局部开口、残余漏气以及停转风机通道共同决定进出气量。停转通道是否有止回能力目前
未知，默认不得假定关闭后仍完全密封；对其等效通流面积做敏感性验证。

孔口的有符号平方根在零压差附近需有限导数正则化，例如
`f(Δp)=Δp/(Δp²+ε_p²)^(1/4)`；`ε_p` 单位为 Pa，公开其取值、目标工作区间误差和敏感性结果。
不能用任意截断把零点变成不明来源的漏气阈值。

全部风机停转且理想零漏气时，准静态平衡没有唯一解；应按显式配置保留封闭腔的气体状态或
拒绝该组合，不能直接强制恢复环境压力。动态参考须保证绝对压力为正，并允许压缩腔体时向外
排气；不得靠大幅裁剪压力掩盖数值不稳定。
机器人离开墙面或裙边越过墙边后，应由真实开口导致失压，避免保留远距离吸引。

### 4.2 密封圈接触、摩擦与漏气

首版用周圈采样点上的弹簧和阻尼近似裙边压缩，在 Gazebo System 中计算等效接触力，避免一开始
引入大量小刚体和关节。先用实际间隙、自由形状、压缩行程和贴合能力求接触状态，再求压缩反力。
模型假设 H1：按用户定性经验，轻微起伏在暂定可贴合范围内只改变压缩分布与轮载，
不因高度变化本身额外增加漏气。贴合幅值／空间尺度／速度的阈值尚无实测数据，全部标为
provisional；H1 用于 M2 建模，不以同一规则产生的“基础漏气不变”作为实机有效性证据。

贴合接触时，裙边法向载荷除机械项外还需考虑唇口压差项，可采用等效表达：

```text
N_skirt = [k δ + d δ_dot + β(contact_state) Δp A_lip]_+
A_effective = ∫ pressure_weight(s) dA_projected
```

`A_lip` 为唇口环带投影面积；接触带内的压力从腔压向外界过渡，位置权重决定有效面积和压力
中心。有效边界位置与 `β` 均为 provisional，但必须来自同一份受压面／传力模型，不能独立任取
后把同一唇口载荷扣两次。只在实际接触部分传递墙面反力；离墙后按开口状态计算，不保留虚假
接触支撑。用分区合力与力矩核算检查整体平衡。

漏气依据是裙边实际无法贴合后留下的残余开口，以及是否存在贯穿接触带、连接腔内外的通道。
分别记录沟槽深度、宽度、方向和裙边跟随／跨越能力；孤立凹点不自动等于贯通漏口。残余基础
漏气与缺口漏气分开。轻微起伏与深沟槽分别试验，不能用起伏 RMS 或任一采样点离开参考平面
直接放大漏气面积。

从可贴合到不可贴合的过渡必须连续：在暂定过渡带内平滑计算残余间隙、有效通道面积和
唇口载荷权重，不能在幅值阈值处从基础漏气直接跳到整段开口。过渡带宽度及正则化参数均有
单位、来源和敏感性范围，不用平滑掩盖深沟槽的实际通流截面。M1 先用受控间隙缓慢开合验证
这套子模型；M2 再用真实表面／贴合状态驱动它。独立做阈值两侧的双向细步扫描和缓慢升降，
检查面积、流量、负压及裙边力在唯一稳定工作分支内连续；缩小扫描步幅、物理步长并加密周圈
采样，核对收敛及有无数值分支往返切换。真实动力学滞后与数值抖动分别解释，容差在试验前冻结。

切向摩擦由该处接触载荷和滑动速度计算；用有界、连续的近零速度处理，避免静止抖动或向运动
方向注入能量。支撑的抗内卷作用以受限的裙边形状与行程近似，外观压缩与物理压缩使用同一状态。
压缩到底后需明确处理硬限位，不能让底板穿墙。正则化摩擦在静止附近可能蠕变，静态牵引预算
不依赖它提供保持力；运动时需计入随裙边法向载荷变化的拖曳。

裙边接触选择一条施力路径：若采用插件等效接触，该圈不能再通过另一套碰撞产生同一份反力。
驱动轮、内置万向球轮和硬壳仍由 Gazebo 接触求解。球轮在圈内不代表它形成独立压力区或必然
漏气；按实际结构扣除占据的腔体容积，只有真实连通外界的安装通道才计入漏气。现有墙缝主要
是视觉纹理；漏气测试按第 4.4 节新增同源、具有明确截面的开口／凹槽或密封通道模型，不能从
纹理明暗推导物理间隙。M1 采用声明面积的受控密封通道，M2 才验实际沟槽及起伏随形。

### 4.3 合力、力矩与轮子载荷

压力作用由实际受压面及第 4.2 节的压力权重积分得到合力与加权压力中心，转换至世界坐标后
施加相应合力与力矩；仅在压力分布对称等条件下压力中心才与几何中心重合。新模型不能永久
固定沿世界 `-X` 施力，也不能把压力作用点直接设为某个风机位置。
插件采用 `Link::AddWorldWrench` 带 `_offset` 的重载：力／力矩用世界坐标，作用位置用 link
坐标。三参数版本作用于 link 原点；使用 offset 后不能再次叠加同一份 `r×F`。显式扭矩仅用于
尚未由偏置力表达的纯力偶。B/C 使用同一套施力函数及压力中心。

单腔第一版压力均匀；某一边漏气首先改变整腔压力，不凭空制造三个局部负压区。倾斜／剥离行为
由受压面方向、裙边接触力、重力和轮系接触共同产生。

静态垂直墙面下应满足法向平衡：

```text
N_左驱动轮 + N_右驱动轮 + N_内置球轮 + N_裙边 ≈ F_pressure 的墙面法向分量
```

总吸力应以第 3.3 节每个驱动轮的需求反算。需测量各接触点的法向载荷、整机力矩平衡及侧滑，
核对现有 WheelSlip 标称载荷与新载荷范围的适用性。若重新表述标称载荷，应同步检查柔度与
标称载荷的比值，避免无意中改变轮胎等效特性；旧标定不直接冒充新结构标定。裙边和球轮承担
的载荷必须进入计算，不能用未说明的额外推力补回。

### 4.4 同源的小起伏墙面与深沟槽

本节属于 M2，独立于 M1 的平墙负压交付，起伏开关默认关闭。

由一份壁面表面定义生成视觉、碰撞、裙边间隙查询、墙边和沟槽数据，包含坐标变换、尺度、
随机种子、采样、插值规则和内容哈希；不在 world SDF 和插件中分别手填高度或槽口。
不同表示可采用不同分辨率，但必须公开几何误差界。轮胎碰撞可适当简化，决定裙边漏气的
沟槽截面不能因此被填平。

借鉴 `4WIDS_agv` 的同源原生高度场及逐物理步接触记录。该项目曾确认三角网内部边缘产生异常
法向和冲量，且发现 `<heightmap><pos>` 未被物理后端应用；不能只检查生成源一致就宣称摆放正确。
S0 预先登记以下实现顺序、失败条件与退路，M2 的 T0 再用垂直壁面小场景核对实际加载的高度、
法向、变换、边界和碰撞支持：

1. 优先试验原生高度场，经模型位姿旋转到垂直壁面，不依赖已知有后端问题的 `<heightmap><pos>`。
   旋转未生效、实际接触法向不符、穿透或异常冲量等任一项未通过，不进入整车验收。
2. 原生高度场不可用时，显式切换到同源、误差受限的低分辨率三角网格碰撞；视觉与插件仍查询
   同一源场。网格内部边缘也必须通过接触法向和冲量检查，不能因为换了表示就视为问题已解决。
3. 两种真实起伏碰撞均未通过时，允许平面轮系碰撞＋插件按同源解析面查询裙边起伏／沟槽，
   **仅用于裙边／漏气子模型诊断**；配置和结果明确标为代理场景，不验收轮子越过起伏、真实轮载
   转移或 M2 整车耦合。M2 对应项目保持未通过，M1 可独立交付，不静默回退或临时扩张结论。

各表示记录 `e_h=max|h_collision-h_source|`、最大法向夹角 `e_n` 及沟槽通流截面误差；平面代理
也报告对源场的误差，不将它伪装成零误差。S0 冻结误差上限和独立测量方法，T0 核对实际加载
结果；分辨率按轮径、裙边接触带、贴合过渡带和最窄沟槽选取，不照搬道路网格或幅值。
采样与插值误差不得掩盖过渡或填平漏气通道，超限则调整表示或缩小并声明适用范围。

增加类似 `test_wall_world_matches_description.py` 的跨层契约测试，并用实际碰撞／射线或接触
测量作独立核查，拒绝源场、视觉、碰撞与插件查询之间的变换或几何失配。
轻微起伏工况主要验贴合、轮载变化与接触稳定；深沟槽工况单独验通道漏气及失压。

规划安全区还须保证裙边在全部允许朝向和变形范围内留在墙内，按最不利裙边包络和余量内缩
运动区域；仅在能覆盖该包络时才用单一 `edge_clearance` 表示。

### 4.5 驱动轮法向柔顺性

本节属于 M2，柔顺开关默认关闭；关闭时生成原有刚性轮链路，不保留零刚度的自由移动关节。

借鉴 `Subway_scan_bot_sim` 的“车体—法向弹簧移动关节—轮轴—旋转轮”结构，作为轮胎压缩的
等效表示；轴向随本机贴墙法向定义，不直接复制轨道车的世界竖直方向。球轮的滚动支撑与安装
柔度分开处理，初版不无依据给钢球增加同样胎面弹性。

参考项目发现，在其 `1 ms` DART 工况下实际静挠度明显偏离 `N/k`，因此这里按新轮组质量、
法向载荷范围、阻尼和物理步长重新做隔离标定，记录载荷—挠度、回弹和行程限制。轮压用独立
接触测量复核，不仅由同一套 `kδ` 反推。不能把 URDF 接触 `kp/kd` 的存在当作柔性已经生效。

法向柔顺不自动给出真实接触斑、切向弹性和压缩后的有效滚动半径；这些影响按实际需求与
测量另行判断。现有 WheelSlip 描述的滑移与本节法向柔顺分别记录、分别验证。

轮胎压缩→车身离墙间隙／姿态→裙边压缩与开口→负压／载荷→轮胎压缩构成耦合反馈。
先分离标定，再验证耦合平衡与稳定性；不能先冻结刚性轮下的最终吸力，再把柔性作为外观补丁。
M1 的刚性轮吸力结论只覆盖其冻结配置，M2 按新耦合状态另行计算和验收。

现有控制八工况、WheelSlip 侧滑标定（约 `0.46 mm/°`）、EKF 及完整套件在冻结期继续以原有
默认配置作回归基线，不能为新模型改宽其门槛。新底盘的这些专项已在 S6 通过，S7 在实际
几何、物理、控制、传感参数保持冻结时直接复用，只补默认切换／删旧相关检查和一次中等采集／拼接；
门限沿用现有合同，确需修改时说明物理原因并单独冻结，不能因换底盘静默放宽；不冻结历史测试
数量。M1 新几何／轮径的标定适用性单列，
M2 柔顺工况另行检查有效轮径、侧滑及里程计／EKF 影响，旧标定不直接继承为新模型证据。

M2 新增法向移动关节必须在 URDF/SDF 同名同轴，并纳入 Gazebo `JointStatePublisher` 的发布清单。
现有清单只包含左右轮旋转关节；柔顺模式需同时发布两个移动关节的位置／速度，经
`/model/climbot/joint_state` 桥接到 `/joint_states`，供 `robot_state_publisher` 形成
“车体→移动轮轴→旋转轮”的完整动态 TF。验收加载、运动和 reset 后的名称、时间戳、位移及
左右轮 TF 连通性与实际关节状态一致；不能用缺失状态、固定零值或静态 TF 掩盖压缩。

压力传感器首版建议使用 `/suction/pressure`，类型为 `sensor_msgs/msg/FluidPressure`，单位 Pa，
其 `fluid_pressure` 表示腔内绝对压力。同时提供外界压力 `p_a` 的配置／话题和单位；若运行中
变化须有对应时间戳，使下游可重建 `Δp=p_a-p_c`，不混用绝压和表压。
传感器包含可配置的噪声、偏置和延迟，仿真真值单独放在评价通道。传感器故障不应改变物理腔压，
真实状态也不能因方便而直接交给未来控制器。正式 topic、QoS 和故障注入合同在 S4 写入
[INTERFACES](INTERFACES.md) 后冻结。

物理更新使用 Gazebo 仿真时间与物理步长；暂停时停止积分，reset 时重置腔压、风机状态、随机源
和传感器延迟队列。Gazebo 真值只用于物理／传感器仿真和独立评价，不进入定位、规划或拼接算法。
轮速控制仍走现有 `/control/cmd_vel` 与看门狗，压力观测不另建速度指令通道。

这是专项目标，最终默认值须以该速度的实际验收结果为依据。

1. 冻结当前速度基线及实际配置来源，分别统计直线扫描、入线、转向、停稳和图像保存耗时，
   先确认提高直线速度能节省多少完整任务时间。
2. 以 0.22、0.25 m/s 作短路线过渡筛查，再验证目标 0.30 m/s，转向和加减速参数先保留原值；
   0.30 m/s 超过当前 0.25 m/s 限幅，须核对控制／任务等实际速度限制并一致调整，
   重新核定停止距离及机动安全域，不能只提高巡航参数而仍被旧限幅截断。
3. 各候选先用短路线和最不利朝向筛查跟踪／转向／停稳、定位时序及每轮法向载荷和摩擦裕量。
   按实际加速度与裙边拖曳重算吸附需求，不因提速放宽原逐轮安全门槛。
4. 再核对位置触发、曝光绑定、实际照片间距／重叠、保存吞吐和运动模糊适用性；
   相机分辨率、墙面精度及原图完整性保持原合同，不以漏拍或降低精度换速度。
5. 只对筛出的最终候选跑双 GUI 横纵完整拍照、原 CUDA 质量检查及最终完整并行回归；
   完整任务平均 RTF 仍须 ≥0.95。报告实际总耗时收益、失败边界及回退配置，全部通过后才改默认值。

旧验收中后置球轮 `N >= 0.15 F_s` 等结构相关判据只保留为历史基线；内置球轮的支撑要求及
