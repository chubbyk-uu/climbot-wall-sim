# 三风机单腔负压吸附实施计划

日期：2026-10-17。工作分支：`feature/pressure-suction`，起点：`c2acf17`。
当前仅完成方案整理，以下实现和验收均未开始；本计划不改变既有仿真通过结论。

## 1. 目标与范围

在 Gazebo Harmonic 中，把现有恒定法向力扩展为有抽气、漏气、密封接触和压力测量的吸附模型。
以两个驱动轮各自所需的法向载荷为设计依据，根据新质量、重心、支撑位置、裙边反力和运动
工况重新反算总吸附力与负压。`400 N` 仅是旧结构的历史对照值，不作为新模型的固定目标，
也不是真机吸力测量值。

本轮包含：

- 根据尺寸图及后续真机结构修订调整底盘、底部浅腔和裙边，两个驱动轮在圈外，底部万向球轮在圈内；
- 三个固定档位风机，共用一个连通负压腔；
- 有弹性支撑、压缩回弹、低摩擦和局部间隙漏气的密封裙边；
- 腔压动态、吸附合力与力矩，以及一个带可配置误差的压力传感器；
- 正常行走、转向、局部漏气、单风机停转和全部停转的仿真验证。

采用等效物理模型：腔内压力先近似均匀，裙边沿周圈离散。叶片三维流场、布料织物、海绵
微结构、铁丝逐根形变和真实材料认证不在本轮范围。压力传感器首先用于观察与记录；首版保持
风机固定档位，不引入压力闭环调速。低压运动门禁如需加入，另列控制需求和验收项。

## 2. 输入事实、图纸解读与待定参数

### 已确认的真机结构

1. 两个驱动轮位于密封圈外，密封圈绕底部腔体闭合。
2. 随动支撑实际采用**底盘下方、密封圈内的万向球轮**。图纸中后伸的支架因强度不足未沿用，
   本轮不能按旧图纸继续在机身后方布置球轮。
3. **风机共三个**，固定档位持续抽气，作用于同一个连通腔体。
4. 密封结构由海绵、弹性细铁丝支撑和外包低摩擦耐磨不透气布组成；支撑用于防止向腔内卷入。
5. 真机未安装腔压传感器，也没有提供实测负压或风机性能曲线；本轮在仿真中补充传感器。

## 3. 现有实现与修改边界

- [simulation.yaml](../src/climbot_gazebo/config/simulation.yaml) 目前配置 `400 N` 恒定吸力。
- [墙世界](../src/climbot_gazebo/worlds/climbot_wall.sdf.xacro) 用 `ApplyLinkWrench` 持续沿世界
  `-X` 施力；[机器人 SDF](../src/climbot_gazebo/models/climbot/model.sdf.xacro) 将施力原点放在
  `chassis_link` 的机身中心，以维持驱动轮与脚轮的载荷分配。
- [robot.yaml](../src/climbot_description/config/robot.yaml) 的现有机身为 `520 × 440 mm`，底板
  标称离墙约 `35 mm`，整机含巡检载荷约 `16.5 kg`。这些是仿真基线，不是真机称重数据。
- 现有随动支撑已经使用球形碰撞体及 `ball` 关节。本轮应重新核定球轮尺寸、移入底部腔体并
  验证载荷分配和滚动行为，不将它替换成后伸的普通转向脚轮。
- 几何、质量、惯量、URDF、SDF 和规划轮廓必须一致；不能只改外观。新增风机与裙边的质量计入
  整机假设，避免在原底盘等效质量之外重复计重。
- 优先保留现有相机光学模型和安装合同。若为匹配整机包络确实需要移动相机，应显式更新外参、
  足迹、归档快照并重新验收；旧数据继续使用原有快照。

### 3.1 旧 400 N 的计算与测量依据

历史提交 `0128f01` 及[状态归档的摩擦饱和分析](archive/status-history/STATUS_2026-08-27.md)
记录了从 `220 N` 提至 `400 N` 的原因：

- 旧底盘质量为 `14.5 kg`，自重约 `142 N`，驱动轮摩擦系数为 `1.1`。
- 旧结构下驱动轮静态合计承担约 `66.7%` 总吸力。`220 N` 时轮压约为
  `45.8 + 100.9 N`，摩擦上限约 `161 N`，仅为自重的 `1.13` 倍；原地转向时载荷转移，
  某些航向下两驱动轮合计轮压降至约 `80.7 N`，摩擦上限约 `89 N`，不足以平衡自重。
- 按旧分配比例估算，静态最低吸力为 `mg / (1.1 × 0.667) ≈ 194 N`。选择 `400 N`
  后，旧底盘的静态总体摩擦裕量约为 `2.06`；计入 `2 kg` 巡检载荷的粗略核算约为 `1.81`。
- [400 N 载荷记录](../results/normal_loads_400N.csv) 的一个静态工况中，左轮、右轮和球轮
  分别约为 `105.781 / 160.885 / 133.334 N`，并非左右各承担 `133.3 N`。
  `133.3 N` 是当时用两驱动轮平均值表示的 WheelSlip 标称载荷，不是每轮所需轮压门限。
- [带相机的载荷复验](../results/normal_loads_g1_camera_2026-08-24_summary.json) 又覆盖了
  多航向、行驶、制动和转向；左右轮各自最低约 `84.194 N`，出现在不同转向工况。

这些数据解释旧参数的来历。新结构的内置球轮、裙边反力、质量与重心都改变载荷分配，不能
继续套用 `66.7%`、两轮均分、自重的一半或历史 `400 N` 作为新设计结论。

### 3.2 按每个驱动轮的需求重新确定吸力

1. 冻结新质量、重心高度、两驱动轮接触点、内置球轮位置、裙边支撑轮廓和压力作用中心。
   两驱动轮与球轮应形成有稳定面积的支撑布局，不能因为移入腔体而退化为共线支撑。
2. 对全航向静止、上／下／横向行驶、加速、制动和原地转向，计算或量测每个驱动轮的切向力
   需求 `T_i,required`，包含重力、惯性、裙边摩擦和球轮滚动阻力的影响。不得把被动球轮或
   裙边承受的法向载荷当作驱动轮可用牵引力。
3. 使用明确的设计裕量 `S_required` 约束每个驱动轮的摩擦能力。第一轮筛查可用摩擦圆：

   ```text
   N_i,required = S_required × ||T_i,required|| / μ_i       i = 左驱动轮、右驱动轮
   N_i,actual >= N_i,required                              # 各工况分别检查
   ```

   `S_required` 及纵横向摩擦模型在 S0 固定并说明依据；旧总体裕量只作参考。转向时还需满足
   所需力矩和摩擦预算，不能仅用两轮法向载荷之和判定通过。
4. 联立整机力与力矩平衡、各接触点非负载荷和裙边压缩反力，求满足每轮需求的总吸力。
   将最不利工况与动态载荷转移纳入 `F_design`，再计算 `Δp_design = F_design / A_effective`，
   最后选择三个风机的等效曲线和固定工作档位。S1 给出初算，S3 实测后复核，在 S5 前冻结。
5. 若支撑位置或压力作用中心使某个轮子始终卸载，应先调整布局，而不是无限增加总吸力。
   内置球轮必须保持所需支撑裕量，同时避免过度分担驱动轮需要的轮压。

对照采用 A（旧几何＋恒力 `400 N`）、B0（新几何＋恒力 `400 N`，仅作载荷诊断）、
B（新几何＋重新计算的恒力 `F_design`）与 C（新几何＋负压模型）。A/B0 分离几何影响；
B/C 在相同几何、质量和载荷目标下比较吸附模型。B0 不要求强行完成正常任务，必要时只做
静力预测或短时测量。旧几何由基线提交复现，不另维护一份复制的机器人模型。

## 4. 等效物理模型

### 4.1 三风机与单腔压力

三个风机在相同腔压下分别计算流量并相加。固定档位表示固定目标转速；实际抽气流量仍随压差
变化。每个风机保留独立启停状态和转速响应，不能直接分配三个固定吸力。

以腔内绝对压力 `p_c`、外界压力 `p_a` 和有效容积 `V` 为状态量，采用等温质量守恒：

```text
Δp = p_a - p_c
d(p_c V)/dt = R T (Σ进入腔体的质量流量 - Σ离开腔体的质量流量)
F_pressure = Δp × A_effective                 # 平面受压面法向上的有符号合力
```

风机曲线、漏气通道与容积变化使用一致的质量流量定义，体积流量换算时注明对应压力和密度。
裙边间隙、局部开口、残余漏气以及停转风机通道共同决定进出气量。停转通道是否有止回能力目前
未知，默认不得假定关闭后仍完全密封；对其等效通流面积做敏感性验证。

压力积分要处理小容积和大开口造成的快速均压，保证绝对压力为正，并允许压缩腔体时通过通道
向外排气。预期可使用解析更新、隐式积分或受控子步；不得靠大幅裁剪压力掩盖数值不稳定。
机器人离开墙面或裙边越过墙边后，应由真实开口导致失压，避免保留远距离吸引。

### 4.2 密封圈接触、摩擦与漏气

首版用周圈采样点上的弹簧和阻尼近似裙边压缩，在 Gazebo System 中计算等效接触力，避免一开始
引入大量小刚体和关节。采样点根据实际几何间隙计算压缩量、压缩速度和有效开口；压缩接触力
只能推离墙面，不产生未经负压模型计算的黏附拉力。

切向摩擦由该处接触载荷和滑动速度计算；用有界、连续的近零速度处理，避免静止抖动或向运动
方向注入能量。支撑的抗内卷作用以受限的裙边形状与行程近似，外观压缩与物理压缩使用同一状态。
压缩到底后需明确处理硬限位，不能让底板穿墙。

裙边接触选择一条施力路径：若采用插件等效接触，该圈不能再通过另一套碰撞产生同一份反力。
驱动轮、内置万向球轮和硬壳仍由 Gazebo 接触求解。球轮在圈内不代表它形成独立压力区或必然
漏气；按实际结构扣除占据的腔体容积，只有真实连通外界的安装通道才计入漏气。现有墙缝主要
是视觉纹理；漏气测试应新增具有明确尺寸的
开口／凹槽几何或显式的密封通道模型，不能从纹理明暗推导物理间隙。

### 4.3 合力、力矩与轮子载荷

压力作用由实际受压面和几何中心计算，转换至世界坐标后施加相应合力与力矩。新模型不能永久
固定沿世界 `-X` 施力，也不能把压力作用点直接设为某个风机位置。

单腔第一版压力均匀；某一边漏气首先改变整腔压力，不凭空制造三个局部负压区。倾斜／剥离行为
由受压面方向、裙边接触力、重力和轮系接触共同产生。

静态垂直墙面下应满足法向平衡：

```text
N_左驱动轮 + N_右驱动轮 + N_内置球轮 + N_裙边 ≈ F_pressure 的墙面法向分量
```

总吸力应以第 3.2 节每个驱动轮的需求反算。需测量各接触点的法向载荷、整机力矩平衡及侧滑，
核对现有 WheelSlip 标称载荷与新载荷范围的适用性。若重新表述标称载荷，应同步检查柔度与
标称载荷的比值，避免无意中改变轮胎等效特性；旧标定不直接冒充新结构标定。裙边和球轮承担
的载荷必须进入计算，不能用未说明的额外推力补回。

## 5. 软件与接口安排

| 归属 | 计划修改 |
| --- | --- |
| `climbot_description` | 共享几何、质量／惯量、内置万向球轮、裙边安装轮廓、压力测量 frame，以及一致的 URDF |
| `climbot_gazebo` | `simulation.yaml` 吸附参数、无 ROS 依赖的 C++ 物理核心、原生 Gazebo System、SDF 与测试 |
| Gazebo launch | 选择吸附模式、传递配置、加载插件、压力与状态桥接；沿用当前在 launch 中组织 bridge 的方式 |
| `climbot_bringup` | 透传启动参数，保证两套覆盖任务入口配置一致 |
| `climbot_interfaces` | 仅在现有标准消息不足时增加有明确单位和风机身份的状态／命令合同 |

拟提供 `suction_model:=constant|vacuum`，此名称目前尚未实现。`constant` 供对照；`vacuum`
由插件独占吸附施力，必须移除旧 persistent wrench。插件缺失、参数错误或数值异常时明确失败，
不能静默回退到恒力。开发初期保留 constant 默认，完成 S6 后再明确记录默认策略。

压力传感器首版建议使用 `/suction/pressure`，类型为 `sensor_msgs/msg/FluidPressure`，单位 Pa，
其 `fluid_pressure` 表示腔内绝对压力；界面中的负压／压差另由 `p_a - p_c` 表示。
传感器包含可配置的噪声、偏置和延迟，仿真真值单独放在评价通道。传感器故障不应改变物理腔压，
真实状态也不能因方便而直接交给未来控制器。正式 topic、QoS 和故障注入合同在 S4 写入
[INTERFACES](INTERFACES.md) 后冻结。

物理更新使用 Gazebo 仿真时间与物理步长；暂停时停止积分，reset 时重置腔压、风机状态、随机源
和传感器延迟队列。Gazebo 真值只用于物理／传感器仿真和独立评价，不进入定位、规划或拼接算法。
轮速控制仍走现有 `/control/cmd_vel` 与看门狗，压力观测不另建速度指令通道。

| S3 Gazebo 集成 | 接入原生 System、单一施力路径、实际间隙和可重复故障场景，建立 C 组并复核每轮载荷及吸力设计值 | 平墙启动、静态平衡、载荷转移、暂停/reset 和施力互斥通过 |
| S4 压力传感器 | 发布测量与独立评价状态，增加三个风机的可重复启停／故障注入，接通 launch 与 ROS bridge | 传感器噪声／延迟、时间戳、失效隔离和入口一致性通过；风机保持固定档位 |
| S5 行走与吸附验收 | B/C 同几何比较，验证正常直行、转向、局部漏气、单机／全部停转与恢复 | 满足第 7 节；压力、载荷、摩擦和运动差异有解释 |
| S6 全链路与收口 | 完整并行套件、现有控制八工况、代表性横纵采集长任务；按几何影响重验定位、采集与拼接，更新文档及默认策略 | 新结果和旧证据边界清楚，正式证据可重建，进程清理完成 |

旧验收中后置球轮 `N >= 0.15 F_s` 等结构相关判据只保留为历史基线；内置球轮的支撑要求及
各驱动轮轮压门限根据新力学计算另行冻结，不能沿用旧比例作为通过条件。

## 7. 验证口径与完成判据

下表中的新增数值是本分支的初始工程目标，实施前在 S0 固定；目前没有通过记录。需要调整时
说明模型或测量原因并重新冻结，不能在看到失败后无说明放宽。既有轨迹、采集和拼接门限继续
按其当前验收合同执行，不用本表替换。

| 验收项 | 判据与证据 |
| --- | --- |
| 结构与参数 | 三个风机、一个连通腔体、两个驱动轮在圈外、万向球轮在底部圈内；关键尺寸与假设均有来源；参数 NaN/Inf、非正容积、无效轮廓等被拒绝 |
| 轮压与吸力设计 | 新质量、重心、支撑几何和摩擦需求下，逐工况验证左右驱动轮各自 `N_actual >= N_required`，满足冻结的牵引／转向裕量；总吸力与目标负压由此推导，不固定为 `400 N` |
| 正常吸附 | 平墙、三个风机固定档位、冻结参数下，稳态平均吸力在重新计算的 `F_design ±5%` 内，且动态轮压满足上一项；同时报告腔压、有效面积、残余漏气和波动 |
| 力与力矩 | 去除安装支撑后静止保持至少 `60 s`；均值法向平衡残差不超过吸附力 `2%`；报告左右驱动轮、内置球轮、裙边载荷及整机力矩残差，无持续倾斜或硬壳穿墙 |
| 数值稳定性 | 纯模型及集成对照 `1 ms` 与 `0.5 ms` 步长，稳态压力、稳态吸力和压力响应时间差异不超过 `2%`；裙边周圈采样加密后关键指标差异不超过 `5%` |
| 漏气因果关系 | 相同转速、固定几何和稳定工作分支上扩大开口，稳态负压与吸力降低；闭合后恢复到相应工作点，完整记录瞬态 |
| 风机故障 | 单个停转、三个依次停转、全部停转分别验证；结果由风机与漏气模型产生，不写死为 `2/3`、`1/3` 吸力；记录停转通道倒灌假设 |
| 裙边行为 | 正常预压下有有限反力与摩擦；局部离墙后接触反力消失且漏气增加；反力不重复计算，摩擦不向滑动方向供能 |
| 传感器 | 测量与物理真值分离；固定种子可复现；均值、方差、偏置、延迟、采样时刻符合配置；传感器故障不改物理状态 |
| 时间与启动 | 暂停不积分、reset 不残留旧状态；从环境压力启动抽气时，使用明确记录的临时安装支撑并在测量前撤除。使用预充负压的测试需单独标记，不能当作启动过程验收 |
| 运动与全链路 | A/B0/B/C 分别保留记录；C 的正常工况遵守既有轨迹门限，报告载荷及侧滑变化；新几何下任务预检、曝光位姿、归档完整性和后处理合同通过 |

故障工况先评价物理响应和已有控制状态，不要求吸附完全消失后仍贴墙，也不把 ROS 零速当作
维持吸附的物理作用。用于测量的安装支撑、初始腔压和任何外部约束均须进入结果配置。

测试按纯核心 → 模型／launch → 短时 Gazebo → 故障场景 → 完整套件与长任务逐层执行。
完整套件保持 `--executor parallel --parallel-workers 8`；新增 launch test 使用工作区唯一
`ROS_DOMAIN_ID`，低频失败按真实缺陷定位。长任务不与高负载拼接或整套测试同时运行。

长任务完整 stdout/stderr 保存唯一的 `/tmp/climbot_<case>_<timestamp>.log`，模拟器、评价器
和任务客户端日志尽量分离；结束后先看退出码和关键指标，失败再定向检索。记录仿真实时因子、
控制／定位接收间隔和插件开销，确认新增模型没有破坏长任务时序；清理并确认所有进程已结束。

## 8. 证据、兼容与后续边界

- 正式证据才写入 `results/`，包含提交、配置、假设、随机源、输入和结果哈希、任务结果与
  测量指标；普通诊断输出留在 `/tmp`。
- 不改写旧原图、标定、processed-run、母版或摘要。新机械几何、相机安装、规划包络或光度
  条件变化后，重新预检并冻结新任务；不要预设新任务仍有旧基线的 `680/660` 张图。
- 若涉及图像几何／光度变化，重新评估标定适用性，并用新采集验证后处理。完整离线拼接与
  GPU 验收显式使用 `--backend cuda`，核对 manifest 的 `execution.backend.effective=cuda`；
  CPU 仅作明确的基线或 A/B，不用 auto 回退作为 GPU 证据。
- 正常工况与故障工况分开给结论；未通过的项目保持打开。新确认的间歇缺陷按
  [INCIDENTS](INCIDENTS.md) 规则归档，不能以重跑通过关闭。
- 第一版证明的是给定假设下的仿真行为。获得真机负压、流量、压缩或摩擦测量后，再替换
  provisional 参数并进行独立校准验证。
