# M1：三风机单腔负压吸附

更新：2026-10-22。S0～S7 已完成。M1 表示平墙与刚性轮的冻结交付；当前默认已是
[M2 起伏墙与柔顺轮](SUCTION_M2_PLAN.md)，不再把 M1 阶段默认写成当前默认。

## 模型与范围

两个圈外驱动轮、圈内万向球轮和三台固定档位风机，共用一个负压腔。裙边采用等效压缩、
唇口反力、摩擦与间隙泄漏，压力传感器提供带噪声／偏置／延迟的独立测量。

- [物理模型](suction/PHYSICS.md)：风机、压力、裙边及合力／力矩。
- [S0 冻结合同](SUCTION_CONTRACT.md)：逐轮设计、分集、启动与误差口径。
- [当前接口](INTERFACES.md#吸附与压力接口)：压力测量、命令、故障、暂停与 reset。
- [M1 历史设计](archive/suction/README.md)：尺寸来源、布局筛选、S0～S7 过程与失败边界。

`400 N` 与旧质量的经验下限只是历史对照，不能用于新底盘；裙边／球轮载荷不能计入驱动轮
牵引预算。风机和裙边仍是仿真等效曲线，未取得真机实测认证，线缆载荷不在模型内。

## 现用诊断

M1 对照显式选择平墙与刚性轮；当前摩擦配置仍生效，要复现历史 μ=1.1 必须另外指定。
同插件固定压差 B 与风机／漏气 C 的入口见[操作手册](OPERATION.md#固定压差与压力故障诊断)。
