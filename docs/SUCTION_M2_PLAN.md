## 1. 目标、边界与真机经验

两个驱动轮在密封圈外、刚性万向球轮在圈内，三个固定挡位风机抽同一个连通腔体。
增加同源起伏／沟槽和轮胎等效法向柔顺，开发期间两个开关独立、默认关闭；分别验证后再耦合，
不展开所有表面、轮胎档位、B/C 与故障的笛卡尔积。

用户经验：密封圈由海绵、弹性细铁丝与不透气耐磨布构成，能柔性覆盖轻微起伏；
遇缝允许漏气，只要风机仍能维持足够负压就稳定吸附。轮胎偏软。
这些是定性来源，未取得风机实测曲线、裙边随形或轮胎载荷—挠度测量。

采用周圈等效柔顺与残余通道模型，不引入织物／海绵有限元、逐根铁丝或叶片 CFD。
H1 假设：可贴合轻微起伏不因高度变化本身增加漏气；适用幅值／尺度／速度仍须标为
provisional，不用模型自身的基础漏气不变反证真机已获定量验证。
不增加压力闭环调速、低压运动门禁或外部线缆载荷模型；超出范围另立任务。

## 2. 墙面参数、表示与计算优化

本节属于 M2，独立于 M1 的平墙负压交付；开发期间起伏开关默认关闭，T3 通过后默认开启。

由一份壁面表面定义生成视觉、碰撞、裙边间隙查询、墙边和沟槽数据，包含坐标变换、尺度、
随机种子、采样、插值规则和内容哈希；不在 world SDF 和插件中分别手填高度或槽口。
不同表示可采用不同分辨率，但必须公开几何误差界。轮胎碰撞可适当简化，决定裙边漏气的
沟槽截面不能因此被填平。

### 2.1 首版表面参数

下表是首版仿真设计输入，不是实机测量。用户确认板面起伏取 ±2 mm，板缝宽 5 mm，
深度在 3–5 mm 内缓慢变化；用户经验是此类板缝下真机仍能稳定吸附。

| 对象 | 首版参数与分布 | 来源与边界 |
| --- | --- | --- |
| 板面起伏 | 相对名义平面 −2～+2 mm，峰谷差不超过 4 mm；平滑随机场，主要空间尺度 200–800 mm | 幅值由用户指定；尺度为暂定仿真参数，记录实际极值、RMS、坡度及种子，不把空间尺度当采样间距 |
| 板缝 | 开口宽 5 mm；深度 3–5 mm，沿缝以约 300–1000 mm 尺度连续缓变 | 深度相对两侧局部板面定义；槽底、侧壁和缝口真实建模，小圆角不吞掉截面；首版无板间错台 |
| 裂缝 | 主裂缝开口宽 0.5–2 mm、深 1–3 mm；沿长度平滑变化，支裂缝逐渐收窄、收浅并在端部闭合 | 暂定仿真假设；现有裂缝仅为中心线素材烘焙，无物理深度及可引用的毫米开口宽度合同 |
| 布局 | 先做横、竖板缝、交汇点及分叉裂缝的小试片；验证后生成整墙。斜向越缝通过机器人航向覆盖，斜板缝仅为后置可选诊断，不是确认过的真机形态 | 板块尺寸／布局、随机场局部坡度上限、采样及误差容差在 T0 首轮试验前冻结，不能看到结果后调宽验收 |

±2 mm 与 4W 当前默认名义幅值相同，替代此前“比 4W 小”的讨论建议。
起伏、板缝、裂缝分别定义，防止在沟槽底重复叠加不一致的深度。
纹理继续使用新版局部减复用素材；真实沟槽与可见裂缝／板缝必须同源对齐，不能在新槽上叠加
旧的填缝画线冒充开口。首版不因此提高或降低 0.25 mm/像素纹理与 1920×1080 拍照分辨率。

3–5 mm 板缝不预设为严重漏气：是否形成漏口由裙边随形后剩余的、连接腔内外的通道决定。
H1 保留为用户经验假设，不能直接写“此范围漏气为零”来保证通过。板缝及裂缝的残余通道
连续形成／关闭，不能将原始槽口面积直接等同有效漏气面积；更宽／更深失效边界另选少量工况。

### 2.2 计算量与加载优化

借鉴本机私有参考 `4WIDS_agv` 的 `docs/ROAD_ASSETS.md`、
`docs/issues/COLLISION_PROXY.md`、`docs/issues/ROUGH_ROAD_RUNTIME.md` 和
`docs/issues/SCENE_LOAD_TIME.md`：大尺度起伏优先原生高度场，显示与碰撞可采用不同精度的
同源表示；避免整墙按最细裂缝宽度铺密集三角网。窄槽采用局部细化或专门槽面，并核对接触
法向／冲量，不能因减面把真实轮子越缝所需几何或裙边通流截面填平。

裙边继续采用插件等效柔顺，避免为海绵、铁丝和布引入大量柔性单元、小刚体或关节。
静态表面在加载时预计算高度查询结构及板缝／裂缝空间索引；每步只查询裙边接触带附近候选，
不扫描整墙网格。窄于基础周圈采样间距的通道，通过接触带与槽线／截面的局部交叠计算或局部
加密捕获，不能让 5 mm 板缝或更细裂缝从采样点之间漏检。加密采用预设误差与工作量上限，
与离线高密度参考对照；达到上限仍不收敛时显式报未达标，不能静默跳过通道。

运行时在 C++ 物理插件内复用缓存和工作缓冲，避免逐物理步磁盘 I/O、ROS 往返和大对象分配；
同一姿态下复用几何查询，但压力相关载荷与实际状态仍逐步更新。准静态压力沿用有界求根与
可验证的前步初值；需动态模型时按已冻结的时间尺度合同处理，不为提速静默改成恒压。
低频观测和日志与物理更新分离，验收需要的逐步证据采用限定诊断窗口／批量缓冲写入，
不得为减少日志遗漏短时失载。任何降采样或缓存更新策略都要证明未漏掉最窄槽口及快速跨缝事件。

4W 的独立 OptiX 精细成像与轻量 Gazebo 显示分离不能直接照搬：本项目相机使用 Gazebo 渲染，
拍照所见表面必须保留已声明沟槽。T0 同时记录冷／热加载时间、几何量、RSS／显存和物理耗时；
T2/T3 验收 Gazebo GUI 与 RViz 同开、正常运动并拍照的整任务平均 RTF ≥0.95。
性能采用同机器、相同启动／相机／日志配置的 M1 平墙基线与 M2 配对，报告整任务平均 RTF、
原生 10 秒窗口分布及新增插件耗时均值／P95／P99，区分几何加载、接触、随形／漏气查询和
压力求解开销；不能仅达到 0.95 就忽略明显性能回退。先用小试片测量并优化，再扩整墙与正式
采集，发现明显回退先定位优化，不用增加无关长任务反复筛查。
从小试片开始定位计算瓶颈，先优化表示与加载，保持物理步长 1 ms 和拍照精度；不得用降低
图像精度、关闭任一 GUI 或只跑纯色墙替代最终性能验收。

借鉴 `4WIDS_agv` 的同源原生高度场及逐物理步接触记录。该项目曾确认三角网内部边缘产生异常
法向和冲量，且发现 `<heightmap><pos>` 未被物理后端应用；不能只检查生成源一致就宣称摆放正确。
沿用 [S0 表面合同](SUCTION_CONTRACT.md) 预定的实现顺序、失败条件与退路；T0 用垂直壁面小场景核对实际加载的高度、
法向、变换、边界和碰撞支持：

1. 优先试验原生高度场，经模型位姿旋转到垂直壁面，不依赖已知有后端问题的 `<heightmap><pos>`。
   旋转未生效、实际接触法向不符、穿透或异常冲量等任一项未通过，不进入整车验收。
2. 原生高度场不可用时，显式切换到同源、误差受限的低分辨率三角网格碰撞；视觉与插件仍查询
   同一源场。网格内部边缘也必须通过接触法向和冲量检查，不能因为换了表示就视为问题已解决。
3. 两种真实起伏碰撞均未通过时，允许平面轮系碰撞＋插件按同源解析面查询裙边起伏／沟槽，
   **仅用于裙边／漏气子模型诊断**；配置和结果明确标为代理场景，不验收轮子越过起伏、真实轮载
   转移或 M2 整车耦合。M2 对应项目保持未通过，M1 可独立交付，不静默回退或临时扩张结论。

### 2.3 几何误差与接触核查

后续接触异常先查两个本机私有参考项目的现行实现、问题记录与回归入口，再决定新增试验；
先区分光学几何修复、碰撞表示修复和已验证动力学结论，避免重复走已有弯路。

2026-10-19 补充核查（只读，参考项目未修改）：

- **4W `eaa576e`**：`tools/fullwidth_road.py` 的板缝采用共享沿缝采样网格，并在交汇处
  同时补齐两组缝口／侧壁节点，防止独立采样留下跨槽长对角面。对应回归为
  `tools/test_road_joint_style.py::test_joint_intersection_has_no_long_diagonal_wall_facets`
  和 `test_buffered_joint_wall_has_no_periodic_twisted_faces`；后者记录旧网格
  94/537 个斜壁面带不应有的横向法向分量。该修复是本项目板缝网格的优先参考，
  不能直接把任意高度自适应 Delaunay 细分当作已解决法向问题。
- **4W 动力学边界**：`docs/issues/ROUGH_ROAD_RUNTIME.md` 的内部边缘异常法向／冲量，
  最终轮碰撞使用原生高度场；上述板缝网格回归证明几何组织正确，不单独证明 ODE
  板缝接触已通过。`docs/issues/COLLISION_PROXY.md` 已有细裂缝光学保留、轮碰撞省略
  的显式代理策略，与本项目已授权的窄裂缝简化方向相符，不能扩大到省略板缝。
- **轨道车 `cf5cfbd`**：`src/ssb_tools/ssb_tools/stage_b_scene.py` 的 `lip_profile`
  ／`junction` 实现斜倒角、两端圆角、交汇局部网格，并对两缝取较大深度而非叠深；
  `docs/design/MECHANICS.md` 记载 3 mm 倒角和 1 mm 圆角，
  但隧道内壁／板缝不设轮系碰撞，属于光学表示参考；轨顶物理接触另走分段高度场。
  交汇补片用于防漏光的背衬不可搬成密封通道封口或重复碰撞面。

据此，下一步先核对共网格与局部交汇拓扑，再分别核查真实棱边和光滑面法向，最后仅做少量
实际轮径接触／越缝样本。槽口保持 5 mm、深度保持 3–5 mm；该宽深比不能容纳贯穿深度的
双侧 45° 斜壁，不照搬其他项目倒角尺寸。若需小圆角，先限定截面误差及计算量再实施。

各表示记录 `e_h=max|h_collision-h_source|`、最大法向夹角 `e_n` 及沟槽通流截面误差；平面代理
也报告对源场的误差，不将它伪装成零误差。S0 冻结误差上限和独立测量方法，T0 核对实际加载
结果；分辨率按轮径、裙边接触带、贴合过渡带和最窄沟槽选取，不照搬道路网格或幅值。
采样与插值误差不得掩盖过渡或填平漏气通道，超限则调整表示或缩小并声明适用范围。

增加类似 `test_wall_world_matches_description.py` 的跨层契约测试，并用实际碰撞／射线或接触
测量作独立核查，拒绝源场、视觉、碰撞与插件查询之间的变换或几何失配。
轻微起伏工况主要验贴合、轮载变化与接触稳定；正常板缝单独验稳定通过，超出正常范围的沟槽再验漏气及失压边界。

规划安全区还须保证裙边在全部允许朝向和变形范围内留在墙内，按最不利裙边包络和余量内缩
运动区域；仅在能覆盖该包络时才用单一 `edge_clearance` 表示。

## 3. 驱动轮法向柔顺性

本节属于 M2；开发期间柔顺开关默认关闭，T3 通过后默认开启。显式关闭时生成原有刚性轮链路，不保留零刚度的自由移动关节。

借鉴 `Subway_scan_bot_sim` 的“车体—法向弹簧移动关节—轮轴—旋转轮”结构，作为轮胎压缩的
等效表示；轴向随本机贴墙法向定义，不直接复制轨道车的世界竖直方向。球轮的滚动支撑与安装
柔度分开处理，初版不无依据给钢球增加同样胎面弹性。

首版按用户“轮胎偏软”的描述，以**每轮法向载荷 150 N 时，实际压缩 1.0 mm**为名义目标，
0.5／1.5 mm 为少量敏感性对照。名义线性估计刚度约 150 kN/m，仅作标定起点，不直接当作
Gazebo 已实现的刚度。压缩是轮胎的等效法向变形，不引入大行程悬挂；钢制球轮保持刚性。
阻尼、压缩／回弹行程、标定载荷范围和容差在 T1 加载试验前冻结；至少覆盖耦合预测的正常
逐轮载荷包络，验证卸载回零、载荷—挠度曲线及回弹，无通过拉力保持轮墙接触的隐藏约束。
实测轮胎数据缺失，结果只代表该仿真柔顺档位；不按这三个档位展开全部工况笛卡尔积。

参考项目发现，在其 `1 ms` DART 工况下实际静挠度明显偏离 `N/k`，因此这里按新轮组质量、
法向载荷范围、阻尼和物理步长重新做隔离标定，记录载荷—挠度、回弹和行程限制。轮压用独立
接触测量复核，不仅由同一套 `kδ` 反推。不能把 URDF 接触 `kp/kd` 的存在当作柔性已经生效。

法向柔顺不自动给出真实接触斑、切向弹性和压缩后的有效滚动半径；这些影响按实际需求与
测量另行判断。现有 WheelSlip 描述的滑移与本节法向柔顺分别记录、分别验证。

轮胎压缩→车身离墙间隙／姿态→裙边压缩与开口→负压／载荷→轮胎压缩构成耦合反馈。
先分离标定，再验证耦合平衡与稳定性；不能先冻结刚性轮下的最终吸力，再把柔性作为外观补丁。
M1 的刚性轮吸力结论只覆盖其冻结配置，M2 按新耦合状态另行计算和验收。

## 4. 柔性贴合、残余漏气与稳定吸附

M2 的真机对应目标是“柔性贴合、允许漏气、仍能稳定吸附”：轻微起伏由局部压缩／回弹覆盖；
跨越正常板缝时允许存在非零残余漏气与腔压波动，不将“发现缝隙”直接判成失压。
固定三风机挡位下，以一致参考条件的质量流量求平衡 `ṁ_fan = ṁ_leak`，并报告满足逐轮需求的
最低压差处的流量余量；稳定后并非抽气量始终大于漏气量。正常板缝在冻结的参数与运动范围内
应保持 `F_pressure >= F_min(state)` 及逐轮载荷／摩擦裕量，不靠额外恒力、支撑或逐工况重调
风机曲线维持。记录跨缝前／中／后的残余开口、进出气量、腔压、轮载和姿态；选取确实贯通且
仍有残余开口的案例，验证“非零漏气而稳定”，不能全部以零漏气案例代替。
风机曲线、裙边贴合参数在标定集上冻结后，用留出缝位／方向／深度变化验证；缺乏实测曲线与
流量时只宣称符合用户定性现象，不宣称已定量复现真机。未达标时报告原因与边界，不强行压低漏气。

裙边沿周圈局部压缩／回弹，并保留机械载荷、压差唇口载荷及摩擦；只保留插件的一条施力路径，
不能同时由裙边碰撞重复施力。正则化裙边摩擦不计作静态保持力，滑动时计入拖曳。
沿用 [M1 第 4.2 节](SUCTION_PLAN.md#42-密封圈接触摩擦与漏气) 的反力／有效面积／压力中心一致性约束。
由局部实际间隙及贯通接触带的残余通道计算漏气；孤立凹点不自动计为贯通漏口。
贴合到开口、通道形成与闭合连续，阈值两侧双向扫描，并做物理步长及周圈采样收敛检查；
不能用平滑填掉真实槽口，不能将瞬时失载靠均值掩盖。

先按柔顺后的质量、重心、姿态、轮载及裙边反力重算逐轮需求和所需吸力，再审查风机工作点。
旧 400 N、M1 刚性轮解析值与原生经验下限均不能直接作为 M2 合格结论。
B 为同插件固定压力，C 为同插件风机／漏气压力模型，配对保持同一墙面、柔顺参数和裙边模型。

### 4.1 Review 后冻结的边界（2026-10-19）

- 风机保持当前三条等效曲线，不逐工况重调。按原刚性平墙需求 6.10 kPa，容许总等效漏口
  约 301.686 mm²；原正常受控漏口 180 mm²，剩余约 121.686 mm²。这是模型预算，不是实测。
- M2 保守初筛在上述 180 mm² 之外增加真实连通的沟槽通道，不静默占用原余量。5 mm 开口、
  4 mm 槽底的梯形，单处截面为深度乘 4.5 mm；直缝两处 27～45 mm²，十字四处
  54～90 mm²。最大组合稳态约 6.617 kPa，额外剩余约 31.686 mm²。
  共用漏口不重复叠加，实际贴合后的剩余通道由源面计算；裂缝、抬升、瞬态及软轮新载荷另验。
- ±2 mm 起伏可贴合属于用户经验支持的定性假设，不能直接折算成额外漏口；验收连续贴合失效
  过渡及耦合稳定性。6.10 kPa 是能力包络筛查，含同时出现的能力边界，不是任务轨迹实测需求。
  M2 重新计算逐轮需求；若改用实际限幅，必须先验证控制器执行该限幅并冻结，不能事后挑参数。
- 裙边达到最大压缩后，由四段无摩擦原生刚性止挡承担额外载荷；弹性项在最大压缩处饱和，
  不增加显式高刚度弹簧。止挡反力单独观测，不重复施加、不冒充驱动轮载荷或密封堵缝。
  负安装间隙、超出支持倾角、非有限值和求解错误仍显式报错；压到底本身不再锁死吸力。
- 表面高度／沟槽公式只有 C++ 一份；Python 通过 pybind 批量调用。离线 NumPy 仅负责既有
  随机种子实现，将八个实现后的模态序列化为 `resolved_yaml`，C++ 直接读取，不再次抽随机数。
  运行查询不做 YAML 解析、文件 I/O 或分配；迁移前冻结样本和独立 C++ 几何用例共同验证。
- 私有 ODE 暂仅供 M2 显式选择，M1 默认继续系统库。双精度、系统 libccd、各碰撞器开关及
  内部断言对齐 Ubuntu：尤其 `ODE_WITH_LIBCCD_BOX_CYL=OFF`。T3 再决定部署范围，缺库不回退。
- 旧的重叠高度场仅保留为失败诊断，未选作部署退路。已修正原 6～8 mm 重复支撑带：边界对齐
  粗／细网格，严格内部下沉，共用量化区间；几何契约检查不代表接触动态通过。如重新采用，
  必须另做原生接触验证，不继续投入球轮试错。

## 7. 验收合同与运行要求

数值是计划目标，不是通过记录。T0/T1 试验前冻结几何误差、坡度、布局、轮胎阻尼／行程、
误差容差、正常作业窗口及短时断触规则；调整须说明原因并重新冻结，不能看到失败后放宽。
标定与独立验证分开，留出起伏种子、缝位／方向／截面和运动工况。

| 验收项 | 判据与证据 |
| --- | --- |
| 结构与参数 | 三个风机、一个连通腔体、两个驱动轮在圈外、万向球轮在底部圈内；关键尺寸区分 CAD 标注／量取／假设；参数 NaN/Inf、非正容积、无效轮廓等被拒绝 |
| 轮压与吸力设计 | 新质量、重心、支撑几何和摩擦需求下，逐工况验证左右驱动轮各自 `N_actual >= N_required`，满足冻结的牵引／转向裕量；总吸力与目标负压由此推导，不固定为 `400 N`；M2 重算柔顺耦合后的需求 |
| 正常吸附 | 在预注册的正常运动与最不利允许漏气范围内，正常作业窗口逐时刻 `F_pressure >= F_min(state)`，并满足各轮摩擦／支撑约束；报告到零流量最高压差的裕度、可用流量余量和波动。吸力均值接近设计工作点只作标定检查，不作为独立验证 |
| 力与力矩 | 去除安装支撑后静止保持至少 `60 s`；均值法向平衡残差不超过吸附力 `2%`；报告左右驱动轮、内置球轮、裙边载荷及整机力矩残差，无持续倾斜或硬壳穿墙 |
| 数值稳定性 | `1 ms` 与 `0.5 ms` 下稳态压力／吸力差异不超过 `2%`；可解析的风机启停原始压差 `t10–90` 差异不超过 `2%`。时间分辨率不足或毫秒级开口事件改用更细 ODE 子步参考，试验前预定义绝对时间误差门限，不以物理步整数计数硬算百分比。裙边采样加密后关键指标差异不超过 `5%`，同时检查零点正则化误差 |
| 密封过渡连续性 | 对受控间隙及暂定贴合阈值两侧做双向扫描／缓慢升降；唯一稳定分支内的有效漏气面积、流量、腔压及裙边力连续并随步长／采样加密收敛，无阈值阶跃或数值分支抖动。物理滞后另行解释，误差容差预先冻结 |
| 轻微起伏假设范围 | 明示 H1 仅来自用户定性经验、无定量阈值；报告幅值、尺度、速度、轮载、压缩和姿态，以及贴合参数敏感性。基础漏气不变只作模型一致性检查，不作为真机贴合能力已验证的结论 |
| 正常板缝漏气下保持 | 5 mm 宽、3–5 mm 深缓变板缝下，选取非零贯通残余漏气的留出案例，固定三风机参数验证流量平衡、腔压波动、逐时刻所需吸力及逐轮裕量；不以零漏气、额外施力或重调风机曲线保证通过，定量真机一致性仍需实测 |
| M2 计算开销 | 同配置配对 M1 基线，双 GUI＋正常运动拍照整任务平均 RTF ≥0.95，报告 10 秒窗口及插件耗时均值／P95／P99；验证局部查询／加密不漏细槽，不降拍照精度或静默简化物理，明显回退须定位优化 |
| 深沟槽漏气 | 使用同源、已声明截面的沟槽，区分孤立凹点与贯通缺口，验证残余开口／通道及其连续形成过程；报告几何误差与压力响应，不从纹理推导漏气，也不用平面代理代替轮系沟槽接触验收 |
| 风机故障 | 复用 M1 既有故障证据，仅追加选定沟槽及耦合边界；报告保持裕量与失效边界，不预设少一台必然失压，区分关断压力与停机保压。 |
| 裙边行为 | 验证机械压缩项和压差载荷项；有效面积、加权压力中心与唇口传力由同一模型核算，反力与力矩不重复；正则化摩擦不计静态保持力，运动中不向滑动方向供能 |
| 轮胎柔顺与 TF | 新载荷／质量／步长下隔离标定，T1 预先冻结目标与容差，使用独立接触测量验证载荷，不仅以 `N/k` 或生成配置自证；报告挠度、回弹、行程及断触。新增移动关节状态完整桥接，动态轮 TF 与实际压缩一致 |
| 墙面与接触 | 同源配置、哈希、插值及变换契约通过；实际加载后的高度、法向、边界与预期误差达标，记录逐步断触、异常法向、穿透、接触力与冲量。M2 记录高度场／网格选择及误差，代理场景不能完成起伏整车验收 |
| 传感器 | 测量与物理真值分离；固定种子可复现；均值、方差、偏置、延迟、采样时刻符合配置；传感器故障不改物理状态 |
| 时间与启动 | 暂停不更新物理状态；从环境压力启动，按冻结的压力就绪／持续时间条件撤除临时支撑，超时保持支撑并报告未就绪。记录实际撤除时刻，正常作业测量前确认解除；reset 恢复初始支撑并重新启动，不残留旧状态。可评估 DetachableJoint；预充负压试验单列 |
| 默认兼容与开关 | 两个独立开关开发期间默认关闭，全部验收后默认开启并验证切换；显式关闭时保留 M1 平墙／刚性关节链，开发期默认配置完整回归。打开柔顺时检查移动关节及动态 TF；B/C 使用同一墙面与柔顺参数，不恢复已删除的旧几何／恒力路径。 |
| 运动与全链路 | 按影响复验控制、有效轮径、WheelSlip／里程计／EKF、曝光位姿与归档完整性；成像及拼接的非平面适用范围单列，不自动继承平墙 P2-06 通过结论。 |

保留 M1 现有控制、定位和采集门槛；柔顺改变有效轮径或侧滑时重新判断标定适用性，
不能为通过而静默放宽旧门槛。故障保持／失效边界单列，不要求完全失压后仍能贴墙。
准静态压力阶跃不能当作有限腔压响应时间；真值与传感器延迟分开，无可测响应时标不适用。

完整套件保持 `--executor parallel --parallel-workers 8`，新增 ROS 测试使用独立 domain。
长任务不与高负载拼接或完整套件同时运行，完整输出写唯一 `/tmp` 日志；结束先看退出码、
结果摘要和关键指标，异常才定向查日志，并确认进程正常收尾。

性能口径沿用 [S6 方法](SUCTION_S6_METHOD.md)：Gazebo GUI 与 RViz 同时实际打开，
正常运动并拍照，排除首 20 s 预热后整任务原生时钟平均 RTF ≥0.95；目标实时率 1、物理步 1 ms。
与 M1 基线差值、10 墙钟秒窗口和插件开销保留诊断，不额外要求追平旧模型；
明显回退必须定位优化。GUI 应显示瞬时实时率，截图／原始时序留在本地数据根。

## 8. 证据、清理与发布

- `results/` 仅纳入小型正式报告与摘要，包含提交、配置、假设、随机源、输入和结果哈希、
  任务结果与测量指标；大体积正式证据放本地数据根，普通诊断输出留在 `/tmp`。
- 不改写旧原图、标定、processed-run、母版或摘要。新机械几何、相机安装、规划包络或光度
  条件变化后，重新预检并冻结新任务；不要预设新任务仍有旧基线的 `680/660` 张图。
- 若涉及图像几何／光度变化，重新评估标定适用性，并用新采集验证后处理。完整离线拼接与
  GPU 验收显式使用 `--backend cuda`，核对 manifest 的 `execution.effective=cuda` 且 `execution.fallback=false`；
  CPU 仅作明确的基线或 A/B，不用 auto 回退作为 GPU 证据。
- 正常工况与故障工况分开给结论；未通过的项目保持打开。新确认的间歇缺陷按
  [INCIDENTS](INCIDENTS.md) 规则归档，不能以重跑通过关闭。
- 第一版证明的是给定假设下的仿真行为。获得真机负压、流量、压缩或摩擦测量后，再替换
  provisional 参数并进行独立校准验证。
- 实际墙面起伏会影响当前平面成像／拼接模型；先完成吸附与行走专项，再单列新成像几何的
  适用范围与验收，不把平墙 P2-06 自动扩展为非平面墙通过。
