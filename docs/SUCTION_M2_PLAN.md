# M2：起伏墙与柔顺轮

更新：2026-10-22。T0～T3 已收口；起伏墙与柔顺轮自 2026-10-20 起默认开启。
本页是 M2 设计、验证和后续工作入口；开发期间的计划、失败方案与门槛修订保存在
[M2 历史记录](archive/m2/README.md)，不作为当前默认说明。

## 1. 目标与范围

在三风机单腔负压底盘上加入同源起伏／沟槽、轮胎柔顺和裙边残余通道，验证能否在允许漏气下
保持逐轮支撑与牵引。风机、裙边、轮胎仍是暂定仿真模型；不模拟供电线缆载荷或压力闭环。

## 2. 墙面模型

当前配置与碰撞近似见[M2 模型](m2/MODEL.md#墙面与碰撞表示)。视觉、球轮、裙边保留真实板缝；
驱动轮采用仅含起伏的高度场，窄槽／裂缝的接触简化明确记录，不宣称驱动轮真实陷槽已验证。

## 3. 柔顺轮

采用隔离加载标定的法向移动轮轴、球面接触、预压和轮胎侧向弹性。参数与 450 N 复核见
[轮胎模型](m2/MODEL.md#轮胎与状态链)。刚性轮关闭选项不残留自由移动关节。

## 4. 压力与漏气

[负压基础](suction/PHYSICS.md)与[M2 耦合边界](m2/MODEL.md#裙边压力与耦合)共同定义唯一施力路径。
非零漏气不自动判失败，也不能以模型自身输出证明真机已定量标定。

## 5. 运行入口

正常入口与参数透传已实现；`wall_surface=undulating`、`wheel_compliance=true` 为当前默认。
关闭任一项用于显式对照，不恢复旧底盘或恒力路径。摩擦覆盖、私有 ODE、原生探针及轮载复算见
[M2 操作](operations/M2_PHYSICS.md)，公共话题见[接口合同](INTERFACES.md)。

## 7. 验收合同

## 8. 证据与清理

每轮保留协议、输入与源码摘要、失败原因和独立结果。大数据在本地；已授权清理的派生图像需
按配方重建，不能把哈希视为照片备份。实际保留范围只在[数据保留](DATA_RETENTION.md)维护。
