# 历史分册 2

### 7.5 分块融合

不得创建整幅强度、权重和不确定度的多层浮点画布。渲染按 tile 独立执行：

```text
取一个 tile
→ 查询与它相交的优化后照片
→ 按稳定顺序投影和加权
→ 生成灰度、覆盖次数与置信度
→ 压缩写盘
→ 释放临时数组
```

tile 计算可多进程并行，但一个有序写入器负责正式 TIFF，避免多个进程并发修改同一文件。
每个工作者使用有界 LRU 图片缓存；并行 tile 数由内存预算限制，而不是只由 CPU 数决定。
第一版使用边缘羽化和位姿置信度权重，不使用可能掩盖墙面缺陷的强局部亮度拉伸。

## 8. 缓存、恢复与确定性

计划的工作缓存为：

```text
work-dir/
├── features/
├── matches/
├── graph.json
└── cache_manifest.json
```

缓存键至少包含 processed image SHA-256、标定哈希、算法及参数、候选边规则和软件版本。
缓存不进 Git，也不等于正式结果。要求：

- 输入或相关参数变化时旧缓存必须失效；
- 修改纯融合参数时可复用特征、匹配和优化结果；
- 中断后可从最近完成阶段继续；
- 任务排序、随机种子、边排序和 tile 内图片归约顺序稳定；
- 不同 `--jobs` 不得改变图结构、接受边和优化语义；
- 并行异常、缺失 worker 结果或缓存损坏必须失败并说明，不能伪装成成功命中。

### P2.7a / P2.7b：诊断墙与 realistic 定位诊断数据

1. **诊断墙结构（已实现，2026-08-27）**：`tools/create_diagnostic_wall.py` 从不可变的
   `wall_025` DDS 基线生成新的墙面目录，使用 seed `20260827` 叠加少量非周期、可唯一识别的施工接缝、斜裂纹、深浅／

   图案。结构的墙面米制位置、尺寸、生成种子和贴图哈希必须进入 manifest；原混凝土墙继续
   作为真实弱纹理基线，诊断墙只用于肉眼错位与评价器灵敏度验证。
2. **双定位 profile（已实现，待实测校准）**：`precision` 保持当前 `12 Hz`、`1 mm` 随机测量噪声和 `10 ms`
   已知传输延迟；新增最小 `realistic`，仅组合以下两项。其一，`prism_extrinsic_error_robot_m`
   是实际棱镜到机器人参考点、相对 EKF 所假定外参的固定三维残差；仿真按真值 yaw 将其旋转至
   墙面坐标后加到全站仪位置，因此正反向扫描会出现物理可解释的相反投影。其二，
   `measurement_timestamp_bias_s` 与零均值 `measurement_timestamp_jitter_stddev_s` 只作用于
   观测 header stamp；它们模拟时钟／同步残差，不能与 `10 ms` 的送达延迟混为一谈。两项均有
   独立开关、单位、种子、真值记录和确定性测试。不能通过把全站仪白噪声直接放大到厘米级，
   也不能只增大协方差——协方差改变先验权重，不会制造真实位姿误差。低频漂移、短时丢测和
   载荷相关形变留作后续独立 profile，本轮不实现。
3. `realistic` 初始调试目标是曝光时刻 EKF 相机位置误差 P95 落在 `20～30 mm`，短时最坏
   约 `30～50 mm`；这是待实测校准的目标带，不是提前冻结的通过线。固定全局偏差只检验
   绝对位置，真正检验接缝恢复的误差必须包含跨扫描线不一致、航向相关和随时间变化的分量。
4. `realistic` 的初始参数不是验收门限：当前以机器人系 `[20, -10, 0] mm`（墙面内模长
   `22.4 mm`）棱镜外参残差、`20 ms` 时间戳偏差与 `2 ms` 小抖动开始；2026-08-27 单横向
   G2 的 10 张曝光实测 P95 为 `24.17 mm`（目标带 `20～30 mm`，非最终验收）。两组件均可
   独立 `enabled` / `disabled` 覆盖 profile，时间戳随机数使用独立 seed；下一步用新的横向／
   竖向正式数据复核。
   发布协方差只描述传感器声明给 EKF 的知识，隐藏系统偏差必须单独记录，不能事后篡改归档
   标签。机器人控制和照片标签都使用同一实际 EKF 输出，Gazebo 真值仍只允许独立验收器读取。
5. 用新任务 ID 重新采集横向、竖向各一组约 270 张原图，依次执行归档、预处理、匹配、
   优化和双路拼接；同时验收定位误差分布、控制稳定性、采集完整性、优化恢复比例及失效
   边界。`precision`、现有墙和现有数据不得覆盖或降级。

## 10. 验收制定原则
