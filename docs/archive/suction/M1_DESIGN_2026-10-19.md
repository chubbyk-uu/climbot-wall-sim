### 3.1 旧 400 N 的计算与测量依据

历史提交 `0128f01` 及[状态归档的摩擦饱和分析](../status-history/STATUS_2026-08-27.md)
记录了从 `220 N` 提至 `400 N` 的原因：

- 旧底盘质量为 `14.5 kg`，自重约 `142 N`，驱动轮摩擦系数为 `1.1`。
- 旧结构下驱动轮静态合计承担约 `66.7%` 总吸力。`220 N` 时轮压约为
  `45.8 + 100.9 N`，摩擦上限约 `161 N`，仅为自重的 `1.13` 倍；原地转向时载荷转移，
  某些航向下两驱动轮合计轮压降至约 `80.7 N`，摩擦上限约 `89 N`，不足以平衡自重。
- 按旧分配比例估算，静态最低吸力为 `mg / (1.1 × 0.667) ≈ 194 N`。选择 `400 N`
  后，旧底盘的静态总体摩擦裕量约为 `2.06`；计入 `2 kg` 巡检载荷的粗略核算约为 `1.81`。
- [400 N 载荷记录](../../../results/normal_loads_400N.csv) 的一个静态工况中，左轮、右轮和球轮
  分别约为 `105.781 / 160.885 / 133.334 N`，并非左右各承担 `133.3 N`。
  `133.3 N` 是当时用两驱动轮平均值表示的 WheelSlip 标称载荷，不是每轮所需轮压门限。
- [带相机的载荷复验](../../../results/normal_loads_g1_camera_2026-08-24_summary.json) 又覆盖了
  多航向、行驶、制动和转向；左右轮各自最低约 `84.194 N`，出现在不同转向工况。

这些数据解释旧参数的来历。新结构的内置球轮、裙边反力、质量与重心都改变载荷分配，不能
继续套用 `66.7%`、两轮均分、自重的一半或历史 `400 N` 作为新设计结论。
`2.06 / 1.81` 是相应旧配置的总体摩擦能力与自重之比，不能视为每轮裕量；较弱一侧以及载荷
转移工况可能先达到摩擦极限。

### 3.2 布局静力初筛与几何来源区分

在统一的驱动轴原点下记球轮 `x=-L`、压力中心 `x=-c`，重心距墙高度为 `h`，自重为 `W`。
不计裙边、平墙、驱动轴朝上的静止筛查为：

```text
α_drive = 1 - c/L
N_drive,total = α_drive F - W h/L
F_min,axial(S) = (S W/μ + W h/L) / α_drive
```

筛查式适用于 `0<c<L`；分担系数非正时应标记布局不适用，不能算出负吸力后继续选型。
`S` 表示该算例要求的逐轮摩擦裕量，左右对称时每轮承担一半轴向需求。这是轴向静止筛查，
不包含横向分配、静态偏航、裙边和动态载荷，不能作为全航向设计吸力。

当前仓库配置重算为 `m=16.5 kg`、`x_cg≈-0.052424 m`、`h≈0.109152 m`，取 `g=9.807 m/s²`、
`μ=1.1`。下表共用这套旧质量与重心，仅更换压力中心／球轮坐标以隔离几何影响；
CAD 尺寸不代表新质量分布已确定。

| 情景 | 压力中心 x / 球轮 x（m） | 驱动轮分担吸力 | 轴向 S=1 门槛 | 轴向 S=1.5 门槛 |
| --- | --- | ---: | ---: | ---: |
| 仓库当前旧结构 | `-0.110 / -0.330` | `66.7%` | `300.9 N` | `411.3 N` |
| 仓库旧压力中心＋圈内候选球位 | `-0.110 / -0.240` | `54.2%` | `407.4 N` | `543.2 N` |
| CAD 量取中心＋CAD 外伸球位 | `-0.141 / -0.410` | `65.6%` | `289.9 N` | `402.0 N` |
| CAD 量取中心＋圈内候选球位 | `-0.141 / -0.240` | `41.3%` | `535.0 N` | `713.3 N` |
| CAD 量取中心＋后移参照球位 | `-0.141 / -0.310` | `54.5%` | `374.3 N` | `509.3 N` |

`x≈-0.141 m` 的机身中心与 `x≈-0.410 m` 的旧图后置球位均来自第 2 节 CAD 按比例量取，
约 `±5 mm`，不是从分担比例或吸力门槛反推的参数。表中暂以对称腔体及对称压力权重假设令
`c≈0.141 m`；最终压力中心须由实际受压面和接触带压力权重重算。仓库旧 `c=0.110 m`、
球位 `-0.330 m` 仍按其原始配置引用，不能被 CAD 值覆盖。S1 应传播量取不确定度并扫描轮廓变化。

在 `c=0.141 m、L=0.240 m、F=400 N` 下，该轴向姿态每个驱动轮仅约 `45.7 N`，与 `80.9 N`
每轮重力需求不匹配。即使沿用仓库旧压力中心 `c=0.110 m`，也仅为 `71.5 N`，说明 B0 只能作失效／
载荷诊断。另取假设面积 `0.144 m²`，`400 / 535 N` 对应约 `2.78 / 3.72 kPa`；该面积尚未测量。
`S=1.5` 在 S0 冻结为首版逐轮工程目标，详见实验合同。上表仍只表示轴向静止筛查，
完整静态扫描还需计入侧向重力／偏航及横向分配，动态与新结构参数仍待 S1 核定。

忽略裙边时，全航向球轮正载荷的必要条件可先检查 `c F >= W h`；`400 N` 时 `c>=0.0442 m`。
设计应留额外裕量，并计入裙边和姿态力矩，不能让压力中心无限靠近驱动轴。S1 联合扫描 `c/L`、
球座净空与有效面积；需要前移压力中心时应调整腔体形状／位置，例如评估前部扩大，并同步重算
质量与压力面积，不得单独平移施力点制造轮压收益。

S0 的[旧质量静力诊断报告](../../../results/suction_s0_2026-10-17/REPORT.md) 已加入静态偏航与
逐轮摩擦圆，并对横向分配给出可行域下限／按轮压比例两种口径。按实际世界 `g=9.81`，
`c=0.141 m、L=0.240 m` 的 `S=1.5` 需求在后一假设下约 `834.1 N`，比轴向约 `713.6 N`
更高，最不利航向约 `53.6°`。这仍共用旧质量／重心且不含裙边和动态，只是补充诊断，
不是 S1 新结构的 `F_design`。不能以某个轴向算例通过代替全工况验证。

### 3.3 按每个驱动轮的需求重新确定吸力

1. 冻结新质量、重心高度、两驱动轮接触点、内置球轮位置、裙边支撑轮廓和压力作用中心。
   两驱动轮与球轮应形成有稳定面积的支撑布局，不能因为移入腔体而退化为共线支撑。
2. 对全航向静止、上／下／横向行驶、加速、制动和原地转向，计算或量测每个驱动轮的切向力
   需求 `T_i,required`，包含重力、惯性、裙边摩擦和球轮滚动阻力的影响。侧向姿态下还需平衡
   `x_cg W` 对应的静态偏航力矩；当前质量分布下每轮差动纵向力约 `±19.7 N`，即使没有转向
   指令也存在。不得把被动球轮或裙边承受的法向载荷当作驱动轮可用牵引力。
3. 使用明确的设计裕量 `S_required` 约束每个驱动轮的摩擦能力。第一轮筛查可用摩擦圆：

   ```text
   N_i,required = S_required × ||T_i,required|| / μ_i       i = 左驱动轮、右驱动轮
   N_i,actual >= N_i,required                              # 各工况分别检查
   ```

   `S_required` 及纵横向摩擦模型在 S0 固定并说明依据；旧总体裕量只作参考。转向时还需满足
   所需力矩和摩擦预算，不能仅用两轮法向载荷之和判定通过。刚体静力学不能唯一决定两轮横向
   力分配：先计算摩擦圆可行域，再明确采用的分配假设、保守边界；M1 与刚性轮接触结果核对，
   M2 加入柔顺性后重算。正则化裙边摩擦的静态保持能力
   不计入设计预算，运动阻力计入。
4. 联立整机力与力矩平衡、各接触点非负载荷及裙边机械／压差反力，求满足每轮需求的总吸力。
   M1 固定刚性轮几何，M2 再联立轮胎柔顺性并独立复核，不将 M1 设计值直接作为 M2 结论。
   将最不利工况与动态载荷转移纳入 `F_design`，再计算 `Δp_design = F_design / A_effective`，
   最后选择三个风机的等效曲线和固定工作档位。S1 给出初算，S3 实测后复核，在 S5 前冻结。
5. 若支撑位置或压力作用中心使某个轮子始终卸载，应先调整布局，而不是无限增加总吸力。
   内置球轮必须保持所需支撑裕量，同时避免过度分担驱动轮需要的轮压。

### 3.4 对照定义

| 组别 | 施力与用途 |
| --- | --- |
| A | 旧几何＋历史 `400 N` persistent wrench，复现历史基线 |
| B0 | 新几何＋历史作用方式的 `400 N`，仅作几何／载荷诊断，明确记录裙边是否禁用 |
| B | 新插件内的理想固定压差源＋同一套有效面积、压力中心、裙边及轮系配置；M1 为刚性轮 |
| C | 同一插件、同一机械参数，压力源改为三风机—漏气求解 |

B/C 的区别只在压力源模型；风机工作点、初始压力、墙面、轮胎、裙边、作用点和接触处理
逐项核对并记录。B 的理想压力源只用于受控对照，不能据此验收失压过程。A/B0 使用的旧施力
原点与新压力中心可能不同，不能声称它们也只改变一个变量。
B0 不要求强行完成正常任务，必要时只做静力预测或短时测量。A 组使用本分支内冻结的
`robot_geometry=legacy`；基线提交 `c2acf17` 只用于核对 legacy 配置与历史结果一致，不另维护
一份复制的机器人模型。M2 中每次 B/C 配对必须保持同一墙面和同一柔顺开关／参数，
不能把 M1 刚性 B 与 M2 柔顺 C 当作单变量对照。
