历史状态记录和外部参考资料。

归档规则：

- 保留原日期和文件名；
- 当前文档只链接到归档结论，不复制完整历史；
- 未跟踪的本地 review 和 PDF 也可迁入对应子目录，但迁移前先确认其是否应提交；
- 归档不等于删除。删除只适用于有明确可再生来源、且不再被证据或文档引用的文件。
