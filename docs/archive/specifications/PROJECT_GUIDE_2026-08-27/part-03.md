# 历史分册 3

### 9.3 输出路径

路径生成器输出按执行顺序排列的墙面二维路点和线段：

```text
扫描直线 → 原地转向 → 换道直线 → 原地转向 → 反向扫描直线
```

要求：

- 同时支持横向和纵向两种扫描方向；
- 扫描线与选定方向平行；
- 相邻扫描方向相反；
- 每条扫描线端点由扫描直线与有效区域边界求交得到；
- 扫描中心线位于均匀覆盖带的中心，区域边界各保留半个实际道间距由检测有效宽度覆盖；末道不得形成过窄的遗漏带，扫描间距应在不超过设定最大值的前提下均匀分配；
- 所有转向均在路点处完成；
- 第一阶段不做圆角、不切弯、不用曲线连接相邻线段；
- 路点顺序、路径总长度和预计覆盖范围可视化并可导出。

RViz 线型只表达一件事：**实线是当前操作/执行对象，虚线是背景约束**。固定约定为：

- 绿色虚线：`motion_region`，机器人 `base_link` 不可越过的绝对安全边界；
- 黄色半透明覆盖带：规划后由各条扫描线推导的相机预计覆盖并集；
- 橙色实线：用户点选的机器人任务可走区（接口字段仍名为 `coverage_region`）；
- 蓝色实线：规划并由控制器跟踪的 `base_link` 路径。

启动且尚未规划时只显示绿色安全边界；黄色必须等蓝线生成后才有定义。相机光心轨迹由
蓝线和固定外参推导，默认不另画一条中心线，避免增加易混淆的辅助线。

规划器发布的是名义覆盖路径。阶段 E 执行时，控制器允许在每次转向稳定后使用
EKF 实际位置重新生成当前 `TRANSITION` 的直线起点和方向；动态执行参考仍必须由
直线段组成，并单独发布供 RViz 和评价使用，不能静默修改名义 `/coverage/path`。

执行层必须能够区分以下线段语义：

- `SCAN`：有效检测扫描段，采集开启，直线精度要求最高；
- `TRANSITION`：换道和转向下坠补偿段，采集关闭；
- `RETURN`：任务结束后的返回段，采集关闭。

现有 `nav_msgs/Path` 只用于通用显示。第一版权威任务接口冻结为
`climbot_interfaces/msg/CoverageTask`，将路点、线段类型、覆盖区域、运动区域和
检测足迹放在同一条消息中原子发布；不得把 RViz Marker 当作控制输入。具体字段、
校验规则、QoS 和执行 Action 以 [当前接口合同](../../../INTERFACES.md) 为准。

## 10. 自定义轨迹规划与跟踪控制

### 10.1 总体原则

不接入 Nav2。覆盖路径被分解为多个两点直线运动，每段采用：

```text
停止 → 原地对准目标线段 → 直线闭环跟踪 → 到达并停止 → 下一段
```

机器人不得在当前线段尚未完成时提前转向下一段。方向改变必须主要发生在路点处的原地旋转阶段。

实际物理系统受扰动时不可能保证数学意义上的绝对零曲率，但控制目标是使每个执行段的真值轨迹尽量贴合规划直线，避免明显弧线、切角和蛇形振荡。

控制优先级固定为：

```text
安全 > 空间轨迹与终点验收 > 时间要求
```

“空间轨迹是硬要求”指必须满足 §14.3 的误差阈值，而不是声称物理系统能达到数学
意义的零误差；时间允许为满足安全和空间误差而延长。

横向为主和竖向为主的弓字形路径使用同一个线段控制器。控制器只根据任意线段
`A → B` 的单位切向、法向和段类型计算误差，不为横扫、竖扫分别编写控制分支；
扫描方向只影响规划器生成的线段顺序、段类型和重力前馈大小。

### 10.2 原地转向

- 转向时线速度严格设为零；
- 使用三角形或梯形角速度轨迹满足角速度和角加速度限制；
- 由目标航向轨迹与实际融合航向的误差闭环修正角速度；
- 航向误差进入容差并稳定后，才允许进入直线跟踪状态。

阶段 E 第一版 `ALIGN` 使用 `0.60 rad/s` 最大角速度、`1.00 rad/s²` 最大角加速度，
按转角自动选择三角形或梯形曲线。曲线结束后继续闭环收敛，航向误差必须保持在
`±2°` 内且角速度基本归零至少 `0.50 s`，才进入直线跟踪。直线跟踪中航向误差
超过 `12°` 时重新进入 `ALIGN`；恢复前进门限仍为 `10°`，两者形成迟滞，避免在
单一门限附近反复切换。重新对准前先按减速度限制把线速度降为零，禁止边走边转。

### 10.3 直线段几何误差

对线段 `A → B`，定义：

```text
t = (B - A) / |B - A|       线段单位方向
n = (-t_v, t_u)             线段单位法向
```

机器人当前位置为 `P`，则：

```text
along_track = (P - A) · t
cross_track = (P - A) · n
remaining   = |B - A| - along_track
```

控制器必须至少使用：

- 沿轨进度误差控制线速度；
- 横轨误差修正目标航向；
- 航向误差控制角速度；
- 终点距离判断当前线段是否完成。

### 10.4 重力侧滑补偿

直线跟踪采用串级控制：

```text
横轨位置误差
      ↓
外环 PI/PID
      ↓
目标航向修正量
      ↓
目标线段航向 + 修正量
      ↓
航向内环 PID
      ↓
角速度指令
```

当重力在当前线段法向上存在分量时，外环应自动生成向上的目标航向偏角。允许机器人机体朝向与规划线段方向存在小角度稳态偏差，只要其实际位置轨迹保持在规划直线附近。重力补偿必须按重力方向在当前线段法向上的投影统一计算：水平段最大，竖直段接近零，斜向段连续过渡，不按“横扫/竖扫”写两套算法。

可选增加基于已标定下滑速度的航向前馈，但闭环横轨误差必须保留，不能只使用固定补偿角。当前水平自然下降/前进比为 `10.56%`，对应的第一版水平向上航向前馈约为 `atan(0.1056) ≈ 6.0°`；该值只作为初值，并随线段方向投影、速度和横轨闭环修正。

阶段 E 的第一版实现把三类限幅分开：重力前馈最大 `±8°`，横轨 PI 反馈最大
`±8°`，两者相加后的最终航向修正仍受 `±12°` 总硬限幅保护。横轨初值为
`Kp = 1.0 rad/m`、`Ki = 0.30 rad/(m·s)`，积分状态限制为 `±0.10 m·s`；
仅在直线前进时积分，定位超时清零，并在反馈或总修正饱和且积分会加深饱和时
停止积分。前馈自身达到独立限幅时仍允许 PI 消除剩余横轨误差。

### 10.5 直线段空间速度规划

第一版不维护随时间推进的理论位置参考，避免定位延迟或壁面打滑时参考位置持续
领先机器人。线速度由实际剩余沿轨距离的制动速度上限与巡航速度共同确定，并在
输出端经线/角加速度和左右轮联合限幅；因此空间直线轨迹和实际终点状态始终高于
预计用时。任务时间只用于预计、显示和安全超时，不作为线段到达判据。

- 线段完成由实际终点位置、航向和停车状态共同判定，不由预定时间单独判定；
- 速度和加速度输出限幅；
- PID 积分限幅和抗饱和；
- 剩余沿轨距离不足时按制动能力减速；
- 定位延迟或打滑严重时不会产生无限超前的位置参考；
- 只有实际位置进入终点容差并且速度足够低，才切换下一段。

以后若增加三角形或梯形时间速度曲线，它只能作为软速度参考，必须显式限制参考
位置领先实际位置的距离，并保留上述空间完成和安全保护。

阶段 E 第一版在剩余沿轨距离小于 `0.10 m` 时进入 `FINAL_APPROACH`，线速度上限降为
`0.03 m/s`。单段完成必须同时满足：二维终点距离不大于 `0.03 m`、相对当前补偿
航向的误差不大于 `2°`、融合线速度不大于 `0.01 m/s`、融合角速度不大于
`0.02 rad/s`，并稳定 `0.30 s`。位置 `0.04 m` 和航向 `3°` 是候选状态退出门限，
用于抑制阈值噪声；真正发布完成的当前采样仍必须满足严格门限。完成状态锁存并持续
输出零速，不能因后续定位更新重新启动同一线段。

### 10.6 保持轨迹直线的约束

- 原地转向期间 `v = 0`；
- 航向未对准前不得前进；
- 正常直线段限制最大航向修正角；
- 对角速度和角加速度限幅，避免蛇形振荡；
- 横轨误差变大时降低线速度；
- 临近终点沿当前直线减速；
- 到达并停止后才转向；
- 不使用会主动切弯的跟踪方式；
- 不跨越或跳过中间路点。

横轨误差在很小幅值内因定位噪声反复过零是允许的，不能仅按过零次数判断蛇形或
触发停车。明显蛇形应结合横轨往复幅值、持续沿轨距离和航向左右摆幅判断；整段走成
大曲线则以真值最大横轨误差、RMS 和曲率趋势判定。

第一版区分共享描述中的绝对硬上限和正常覆盖作业限幅：

| 参数 | 正常作业初值 | 绝对硬上限 |
| --- | ---: | ---: |
| 扫描段线速度 | `0.20 m/s` | `0.45 m/s` |
| 换道段线速度 | `0.20 m/s` | `0.45 m/s` |
| 终点收敛速度 | `0.02～0.04 m/s` | `0.45 m/s` |
| 原地转向角速度 | `0.60 rad/s` | `1.20 rad/s` |
| 直线跟踪角速度 | `0.35 rad/s` | `1.20 rad/s` |
| 线加速度 | `0.20 m/s²` | `0.70 m/s²` |
| 线减速度 | `0.25 m/s²` | `0.70 m/s²` |
| 原地转向角加速度 | `1.00 rad/s²` | `2.20 rad/s²` |
| 直线跟踪角加速度 | `0.80 rad/s²` | `2.20 rad/s²` |
| 重力前馈航向角 | `±8°` | 最终修正仍受总限幅 |
| 横轨 PI 航向角 | `±8°` | 最终修正仍受总限幅 |
| 总航向修正角 | `±12°` | 可配置保护值 |

这些正常作业值是阶段 E 的保守初值。航向补偿初值已通过水平单段实验验证，仍需在
斜向、竖向和完整任务中继续验证；其他数值也必须通过对应单段实验再冻结。

硬上限是执行机构包络，不是工作点：两种跟踪模式都仍以 `0.20 m/s` 巡航、按相同的
额定加速度规划曲线，上限只决定修正量有多大余地。这一点在轮级饱和处尤其重要——
左右轮按相同比例缩放会把线速度和角速度一起压下去，线速度贴住上限时会连带压掉
最需要的航向修正。必须满足 `v_max ≤ 轮速上限 − ω_max·b/2`。

控制输出依次经过：

```text
轨迹前馈与反馈 → 速度/航向限幅 → 线/角加速度限制 → 左右轮联合饱和 → cmd_vel
```

前馈项按跟踪模式取值。`tracking_mode: distance` 时线速度是巡航速度与
`sqrt(2·a·剩余距离)` 距离制动曲线的较小者；`tracking_mode: time` 时线速度取自
按时间参数化的梯形/三角形曲线（Word 文档 §5.3 图29/30），前馈为该时刻的曲线
速度，反馈为该时刻应到达位置与实际位置之差。原地转向段两种模式相同，本就是
文档图27/28 的实现。角速度链路两种模式完全一致，不随模式切换。

时间模式下终点前 `final_approach_distance_m` 交回距离制动曲线：时间参考按计划
时刻停车，会把残余滞后原样变成落点误差（实测 `10.9~15.4 mm`），而距离曲线是
位置的函数，位置不到就不停（实测恢复到 `2.50~3.42 mm`）。

轮距为 `b` 时必须同时检查：

```text
v_left  = v - ωb/2          a_left  = a - αb/2
v_right = v + ωb/2          a_right = a + αb/2
```

任一轮速度或加速度超限时，应对左右轮指令按相同比例缩放以保持期望曲率，不得
独立截断单轮。每个控制周期还必须满足 `|Δv| ≤ a_limit·dt` 和
`|Δω| ≤ α_limit·dt`，防止 PID 输出突变造成轮墙反复刮擦和蛇形振荡。
轮缘速度和加速度上限来自共享描述 `climbot_description/config/robot.yaml`
的 `drive` 段，仿真的差速驱动插件和控制器由同一处取值，不得各自设定。第一版为
`0.30 m/s` 和 `0.40 m/s²`；引入时间参数化跟踪后抬到 `0.45 m/s` 和 `0.70 m/s²`，
巡航速度和规划曲线所用的额定加速度均未改变，抬高的只是修正余量。还必须检查共享
描述中的轮关节速度上限 `30 rad/s` 和力矩上限 `80 N·m`（`0.45 m/s` 对应
`5.6 rad/s`，余量充足），控制层不得修改这些机器人硬件属性。
