# 吸附专项 S0 实验合同

冻结日期：2026-10-17。适用于 `feature/pressure-suction` 的 M1；下列数值是仿真工程目标，
没有实机测量依据的参数仍是 provisional。设计范围由 [项目规范](../PROJECT_GUIDE.md) 定义，
阶段见 [实施计划](SUCTION_PLAN.md)，通过状态仅在 [验收矩阵](ACCEPTANCE.md) 更新。
本合同不表示负压模型已经实现或通过。参数变化必须记录理由、旧值、新值和影响，重新冻结后
再运行验收，不按失败结果事后放宽。

## 基线与输入

- A 组为 `c2acf17` 对应的旧结构、刚性轮、平墙及 `400 N` 恒力。冻结工具逐文件比较工作树、
  安装区和该提交，保存相同输入与渲染后的 SDF／URDF；不复制一份长期维护的旧模型。
- 当前世界重力实际为 `9.81 m/s²`。历史计划筛查的 `9.807` 保留原数值／来源，新增设计、
  计算与实验均读取对应世界配置，不把二者混为同一口径。
- CAD 标注、像素量取、用户结构确认及暂定假设依实施计划第 2 节分别记录；已登记的三个
  媒体文件 SHA-256 已重新核对。CAD 比例量取 `±5 mm` 是读图精度，不是真机制造公差。
- 新旧配置开发期与最终默认、B/C 对照、相机合同及线缆排除项依计划执行。独立贴图计划不在
  本分支实施，M2 不作为 M1 交付前置条件。
- A 组轮压复测沿用历史 24 个静止航向（15° 间隔），每姿态稳定 `0.5 s` 后采样 `2 s`；
  四方向 `0.15 m/s` 行驶 `5 s`、制动 `2 s`，顺逆各转一周，目标角速度 `0.6 rad/s`。
  其 `60 N` 球轮门槛仅复核旧合同；不得应用到新内置球轮。

## 逐轮设计与测量

| 项目 | 冻结规则与理由 |
| --- | --- |
| 牵引裕量 | 每个驱动轮 `μ_i N_i / ||T_i,required|| >= 1.5`。这是预留建模／工况误差的工程目标，不从旧 400 N 反推；同时报告 `S=1` 失效边界 |
| 静态摩擦模型 | 初筛各向同性摩擦圆，基准 `μ=1.1` 来源为旧仿真；敏感性至少覆盖 `0.8/1.1/1.3`，没有实机摩擦认证。实际 WheelSlip 作用单独量测 |
| 横向分配 | 同时报摩擦圆可行域下限与按两驱动轮法向载荷比例的横向分配；后者作为首版设计假设。S3 独立接触结果若不支持该假设，则重算，不能以可行域存在声称实际轮胎一定能做到 |
| 静态偏航 | 重心偏离轴产生的偏航力矩由左右轮差动纵向力平衡，任何航向均计入；球轮／裙边不提供静态切向保持预算 |
| 支撑裕量 | 新球轮静态／正常作业的法向载荷不少于 `10 N`，两驱动轮各不少于 `5 N` 且满足更严格的摩擦需求。这是绝对载荷目标，避免以吸力百分比把载荷过量分给球轮；S1 扫描球轮 `5/10/20 N` 敏感性 |
| 航向与动态范围 | 静态至少 1° 扫描并在极值附近以 0.1° 复查；运动按当前实际配置的速度／加速度边界及控制八工况登记，包含加速、制动、静态偏航和正反转向。静态结果不能命名为完整 `F_design` |
| 裙边 | 机械压缩、同源唇口压差载荷、压力中心和有效面积一起计入；静态裙边保持力不计，运动拖曳计入。未知参数先给区间，待 S2 标定、S3 轮压复核后冻结 |
| 正常窗口 | 从支撑实际撤除的首个物理步起检查轮压与支撑；不允许正常窗口中断触。稳态统计另取撤除后 `2–62 s`，不能用这 2 s 掩盖撤除即失稳 |
| 原始测量 | 逐物理步的接触力／法向／时间戳及独立真值；力单位 N，冲量为 `J=FΔt`，不混用。每段报告期望／实际样本、重复、缺失及零载荷；缺失采样不当作满接触，缺少有效时序则该项未验证 |
| 平衡残差 | 均值法向合力残差不超过压力法向力的 `2%`；均值力矩残差不超过 `0.02 F_pressure ℓ_ref`，`ℓ_ref=max(轮距, 轴到球轮距离)`。报告原始瞬时残差，不以均值取消逐轮约束 |

启动与故障窗口单列，正常运动验收期间仍需逐时刻满足 `F_pressure >= F_min(state)`。
`F_min` 是对应状态下联立支撑／摩擦／裙边得到的要求；非零切向需求下逐轮计算裕量，零需求
标为不适用而非输出无穷大。球轮、裙边摩擦／滚阻的动载荷不能伪装成驱动轮牵引。

## 启动、时钟与传感器

1. 初始与 reset 状态：安装支撑有效、腔压等于环境压力、风机转速为零；三台风机随后以各自
   冻结的一阶响应向固定档位启动。reset 清空就绪计时、超时、延迟队列与随机状态。
2. 启动就绪使用**物理压差真值**，不经过有噪声／延迟的传感器；这是初始化夹具，不进入
   正常控制。当前启动姿态需满足本合同逐轮裕量，阈值定义为
   `Δp_ready = 1.05 F_min(start_state) / A_effective(start_state)`，S1/S3 给出实际数值与配置哈希。
   `F_min` 已含 `S=1.5` 和裙边反力，额外 5% 为释放扰动预留。
3. 达阈值连续 `0.5 s` 仿真时间后撤除；间隙、姿态或阈值变化使条件不成立时清零计时。
   `10 s` 仿真时间仍不就绪，保留支撑并明确报告启动失败，不能无条件延时释放。
4. 记录支撑实际存在状态及撤除时刻。解除后的运动与力平衡确认没有夹具残余外力。
   暂停不推进压力、转速、就绪、超时和传感器延迟；reset 重新执行完整启动过程。
5. 所有正式压力记录给出 `p_a/p_c/Δp`、采样时刻及物理／传感器流的区别。传感器参数和种子在
   S4 标定前冻结；故障只改变测量，不改变物理压力。预充负压试验单列。

初始化实现可采用 DetachableJoint 或显式固定夹具，S3 选择后须测实际支撑反力与解除结果；
本合同不把 ROS 零速视为物理支撑，也不新增运行中的低压运动门禁或风机闭环调速。

## 标定、独立验证与失败边界

| 集合 | 预注册的区分方法 |
| --- | --- |
| 裙边标定 | 平墙隔离压缩／回弹、唇口载荷及少数受控通道；机械与压差项分开。不以正则化摩擦的静止保持当牵引来源 |
| 风机标定 | 由 S1 吸力／负压需求选择三条等效曲线；工作点吻合只是标定。固定档位，三机并联不叠加关断压差 |
| 独立正常验证 | 使用未参与参数拟合的通道面积和运动组合。S2 选定参考面积 `A_ref` 后，标定开口固定为 `0/1/2 × A_ref`；留出 `0.5/1.5/3 × A_ref`，冻结后不据此调曲线。3 倍开口可失败，应记录是否超出允许正常漏气范围 |
| 故障扫描 | 三台分别停一台、依次停机、全部停机；停转倒灌等效面积相对于单风机出口面积取 `0/0.01/0.05/0.2/1.0`，基础／受控漏气交叉扫描。零面积表示独立理想止回对照，不能作为默认真机事实 |
| 全停与零漏气 | 必须显式保存封闭气体状态或拒绝该参数组合；不能将非唯一准静态解静默设成环境压力 |
| 工作点裕量 | 正常允许漏气上限在风机拟合后、独立验证前冻结；逐工况报告驱动轮裕量、工作点／零流量最高压差、可用流量及相应假设，不要求故障全部通过 |

风机出口尺寸、`A_ref`、裙边材料参数等未测量项在对应阶段给出数值和区间；S0 冻结的是
选取规则与集合隔离，不能先猜一组“真机参数”。改变模型／参数版本后，标定和留出验证整体重跑，
旧失败与旧参数保留，不通过挑选单个场景移入标定集消除失败。

数值验收沿用计划的 `1/0.5 ms` 稳态压差／吸力 `2%`、裙边加密 `5%`。
风机 `t10–90` 在物理原始压差上以初末稳态变化量定义，线性插值阈值交点；采样不足时先细化，
时间收敛要求 `2%` 且绝对时间误差不超过 `0.1 ms`，测量时间分辨率须优于该绝对门限。
准静态开口阶跃不报告有限压力响应时间；快开口使用 ODE 参考，以 `0.1 ms` 初始子步再减半核对。

密封过渡先做受控开合的双向慢扫描。细扫描以过渡宽度 `1/1000` 为最大空间步；面积、流量、
压差、裙边力相邻变化各不超过整段变化量的 `1%` 加绝对数值底噪（分别 `1e-9 m²`、
`1e-9 kg/s`、`0.1 Pa`、`0.01 N`），减半扫描步与物理步后差异不得扩大，且往返唯一稳定
分支的稳态差异满足同一限值。若真实斜率要求更细扫描，先细化并记录，不能直接放宽限值；
有物理滞后时另报告滞回曲线与原因，不能以平滑隐藏阈值阶跃。

## M2 表面退路与误差预算

不在 S0 实现起伏场景。预定顺序为旋转原生高度场 → 同源误差受限网格 → 平面轮碰撞＋解析
裙边场的**诊断代理**；前两者未通过时，M2 整车接触／越障保持未验证。

- 实际加载的碰撞／查询高度误差上限为 `min(0.2 mm, 0.1 a_min, 0.1 w_transition, 0.1 d_groove)`，
  仅取当前试验存在的非零项；`a_min` 为最小待验起伏幅值，`w_transition` 为贴合过渡的高度宽度，
  `d_groove` 为最浅待验沟槽深度。不得用 RMS 误差代替最大误差。
- 光滑区域实际法向与独立源场导数夹角不超过 `2°`。沟槽折角处无唯一法向，分别核对两侧
  面与棱边位置，记录棱边接触，不用“法向不适用”跳过内部网格边缘异常。
- 贯通沟槽的有效通流截面最大误差 `5%`；闭合通道不得因离散变成贯通通道，零面积附近
  绝对误差上限 `1e-8 m²`。独立截面采样与碰撞射线／低速探针测量核对，不只比较生成器输入。
- 以本地法向为基准，独立接触法向偏差超过 `5°`、持续穿透超过 `0.2 mm` 或出现异常冲量时
  该表示不通过；动态探针的质量、入射速度、预载、参考冲量及容差在 T0 运行前冻结。
  力峰随步长变化时同时报告冲量，不因峰值变化独自断言物理失效或收敛。

H1 轻微起伏不额外漏气仅是用户定性经验；上述预算验证数值表示，不能验证真实裙边的贴合阈值。
